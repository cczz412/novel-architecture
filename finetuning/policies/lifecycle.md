# 微调实验状态口径

实验是否仍被使用，与文件存在哪里，是两件不同的事。

## 实验状态

- `running`：仍在施工；
- `sealed`：证据已封版；
- `superseded`：已经被新实验替代；
- `failed_retained`：失败但保留诊断价值。

## 存储状态

- `main_repo_thin_shell`：主仓只有薄壳；
- `lab`：重资产仍在隔离实验区；
- `external_archive`：重资产已按既有外置规则归档。

归档与删除分开处理。只有复制、逐文件校验、恢复验证和另行删除授权全部具备，才允许移除旧原件。

## 当前实验切换

注册、封版和切换当前是三个独立动作。目录存在或 MANIFEST 生成成功，都不代表它已经成为当前实验。

切换前必须同时满足：

- SPEC 使用现役 v2 合同；
- MANIFEST 能从实物逐字重建；
- MANIFEST 登记的全部工件大小与 SHA 仍一致；
- SPEC 中列出的验收票全部存在、SHA（若登记）一致、状态在允许值内。

任一条件不满足就硬停，原 CURRENT 不变。
