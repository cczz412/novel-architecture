# C2_UNIT 机械闸门合同 R01

这轮只验证一件事：不看答案时，程序能不能把原文稳定切成局部 `Bxx/Txx` 单元，并让每个编号反向回到原文的连续字符范围。

## 冻结边界

- EVALUATOR_R02 与既有成绩只读，不在本轮修改。
- 164 案人工语义盲审继续挂账；它不阻塞机械切分，但在以后判断语义胜负前必须完成。
- atomizer 只读已经去掉 assistant 的 `PROTOTYPE_QUESTIONS_GOLD_FREE.jsonl`。
- 覆盖审计是第二道程序。只有 unit map 写完后，它才读取 A answer，计算覆盖与额外带入字符；A answer 不允许反向改变切分。
- 原型固定 40 窗：30 个普通窗、10 个特殊窗；每个来源样本最多取一个窗；旧冻结 48 题交集必须为 0。
- 只允许内部训练与评测范围，不扩大权利。

## 全局切分规则

1. 普通窗按题面给出的左重叠字符数分出 bridge 与 target；特殊窗按两个明确区块分出 bridge 与 target。
2. bridge 与 target 分区独立切分，不能跨责任区边界造一个单元。
3. 每个区先按自然换行或强句末标点切，再按弱标点切；仍过长才按 Unicode 字符上限硬切。
4. 短于 8 个非空白字符的碎片只按统一规则与相邻单元合并，不能针对某条 gold 调整。
5. 单元字符上限 80；只显示紧邻负责区的最后 3 个 bridge 单元，编号为 `B01...`；负责区全部编号为 `T01...`。
6. 更早的 bridge 作为无编号只读上文。模型不能从它取证。
7. 稳定身份使用 `canonical_sample_id + local_id`；当前 `canonical_sample_id` 就是原 segment_id。

## 硬停

- 题面边界不能唯一解析；
- 同一 A evidence 在可取证原文中无法唯一定位；
- 任一 unit 不能反向逐字还原；
- 任一 A evidence 无法被可见 B/T 单元完整覆盖；
- 预注册的 100% 机械指标或证据粒度阈值失败。

硬停后只出票，不手工特切、不调金标、不进入 DEV_CORE、Z00、Z01、推理或训练。
