# DEV_CORE 旧选题 R01 作废票

结论：旧 R01 的 48 个窗口不再使用。它们不是被逐题修补，而是在统一污染规则写好后全部重新选择。

旧 R01 全文复读时发现四类来源污染：

- 《异常病理科》章节含“读者：”插入文字；
- 《1982：从西游剧组打杂开始》章节含“迟早药丸”站外插入语；
- 《女魔头》章节含编辑式评论“这本的主角依旧”；
- 《艺术家从监狱开始》章节含“本书首发／无错章节”等站点水印。

处理办法：

- 把站点水印、读者插入、编辑评论统一列入全局章节污染规则；
- 命中任一规则时整章排除，不手工删字后继续使用；
- 共享素材台账中旧 `DEVCORE-` 48 条全部标记为已释放；
- 用同一套无金标、无模型输出的稳定选择规则重建 `DEVCORE2-` 48 条；
- R02 两次独立构建的四份核心产物逐字节一致，污染扫描为 0。

旧 R01 文件只留作失败证据，不进入后续 Z00／Z01，也不进入训练。
