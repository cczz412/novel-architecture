# DEV_CORE 零训练盲审口径 R01

这张盲审只回答一件事：模型输出虽然没有和金标逐字相同，意思是否命中了同一条事实。

- 审查时只看随机化后的 `X / Y`，不读取 `BLIND_KEY.json`。
- 每个金标事实最多计一次召回；每个模型事实通常最多计一次精确命中。
- 如果模型把多个金标事实明确合成了一句，允许同一个模型事实承托多个金标事实，但精确率分子只计这一个模型事实一次。
- 只命中一部分意思、主体方向错误、把计划写成已发生等情况不算完整命中。
- 非法 JSON 仍然是格式失败；本文件不会把格式失败改判为通过。
- 本轮只有一轮本地人工精读，结果只能作为零训练因果诊断，不能直接宣布 A 或 C2 正式获胜。
