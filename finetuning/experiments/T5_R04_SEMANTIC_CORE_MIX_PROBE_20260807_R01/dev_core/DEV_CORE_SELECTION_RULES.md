# DEV_CORE 选题规则 R02

这批题只回答一个问题：同一段正文换成纯文本 A 或局部编号 C2 后，模型理解事实的能力有没有变化。

## 冻结分母

- 48 个正文窗口；
- 至少 30 位作者；本轮候选锁为 31 位作者、31 本书；
- 每本至少 1 窗，按稳定哈希选出的 17 本再取第 2 窗；
- 同一本书的两个窗口必须来自不同章节；
- 所有材料只用于内部评测，权利状态保持 `RIGHTS_PENDING_FOR_TRAINING`。

## 选题顺序

1. 先冻结书名、作者、来源目录和作者证据；
2. 只按正文长度、汉字比例、污染字符和稳定哈希筛章节；
3. 章节在整本可用章节中的前／中／后位置，由书名哈希决定；
4. 章节内起点和 600～800 字负责区只由稳定哈希与冻结 atomizer R02 单元边界决定；
5. 选题锁和正文窗口落盘后，才允许建立 CORE gold。

任何模型答卷、旧模型得分、gold 事实数量和 evidence 长短都不能参与前四步。

## 正文机械门

- 单章正文 1600～6000 个 Unicode 字符；
- 汉字比例至少 55%；
- 不含 `�`、NUL、网址、明显下载广告或连续 100 字符以上 ASCII；
- 整章出现站点水印、无错章节广告、脱离叙事的读者插话或编辑评论时，整章不用；不在窗内手删污染句；
- atomizer 固定为 R02：40 字上限、8 个非空白字符的短单元合并规则、最多 3 个可见 bridge 单元；
- 负责区目标 600～800 字，必须沿 atomizer 单元边界截取；
- 下文只读区固定取紧邻的最多 5 个单元；
- A 与 C2 使用完全相同的 bridge／负责区／下文，C2 只增加 `Bxx/Txx` 标记。
- C2 atomizer R02、position provenance contract、renderer 和 EVALUATOR_R02 在本阶段全部冻结；不得因具体题目回调。

## CORE gold 边界

- gold 只保存 `fact_sentences`，不含 evidence、status、speaker、B/T 编号；
- 只记录会改变人物状态、关系、目标、资源、规则、关键认知或章节走向的事实；
- 氛围、走位、一次性小动作、无后续影响的寒暄不强收；
- 自然空窗可以保留，但不能为了凑空样本换题或删事实；
- `FS02B-006-S01` 不属于本轮新选题分母；它的旧位置歧义继续只在 C2 位置证据分母隔离，不影响纯语义规则。
- CORE 评分分开保存事实能力、生成故障和表示负担，不生成可相互补偿的单一总分。

## 硬停

- 作者或书名命中旧训练、当前 41 题、旧 48 题或共同选材账；
- 同书两个窗口落在同一章；
- 选题脚本读取任何 gold 或模型输出；
- A/C2 正文不逐字同源；
- 同一规则连续运行两次不一致。
