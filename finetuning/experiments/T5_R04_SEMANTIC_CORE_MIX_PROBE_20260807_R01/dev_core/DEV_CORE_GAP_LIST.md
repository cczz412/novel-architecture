# DEV_CORE 当前缺口单

当前材料已经能证明“同一正文、同一语义答案”的 A_CORE／C2_CORE 考题可以机械生成，但还不能直接宣布某种表示更强，更不能开训练。

## 不阻塞阶段票、会阻塞后续结论的缺口

- **语义金标只有一次本地全文精读。** 48 题、95 条事实已经逐题读完，但还没有第二位独立审查者。可以做零训练诊断准备；若以后要用语义成绩拍胜负，这一轮独立复核必须补齐。
- **旧 EVALUATOR_R02 的 164 案人工语义盲审尚未完成。** 机器精确匹配不能代替语义判断；这不阻塞机械切题，但会阻塞正式语义结论。
- **题目权利仍是内部评测待确认。** 48 题只限内部 DEV，不具备训练或对外分发资格。

## 当前不能开跑的子臂

- **Z02 引用负担子臂只有题面。** 它可继续共用 CORE 语义答案，但还没有逐事实的唯一位置答案，因此不能计引用准确率。
- **Z03 跨单元负担子臂尚未成卷。** 要先补独立的事实位置审计，再按自然单单元／自然跨单元配对；不能为了配对回头改 atomizer 切点。

## 会阻塞任何新训练的缺口

- 还没有执行独立训练管线硬门：聊天模板与 EOT/EOS、EOS 是否进入 labels、截断或 mask、packing 边界、训练与推理的 `eos_token_id`、已有输出的最早有效前缀、尾部浪费和正常停止率。
- 还没有一对符合现行合同的干净 A／C2 父 checkpoint。旧 C 学的是字符坐标和锚字，不能冒充 C2_UNIT。
- C0／J5／S5 仍只是下一轮设计。J5 或 S5 的 5% 组稳定受益前，不开 10% 组。
- 普通／特殊教材的分层混训比例还没有按 assistant 目标 token 封账。

## 历史隔离项

`FS02B-006-S01` 继续维持旧 C2 训练层整行隔离。它没有被放进这次新 48 题；即使将来用于纯事实语义题，也不得进入要求唯一引用位置的分母。
