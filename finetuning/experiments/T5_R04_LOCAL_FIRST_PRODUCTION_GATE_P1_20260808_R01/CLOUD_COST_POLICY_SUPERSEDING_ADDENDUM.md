# 云训练成本覆盖条款

## 新的默认规则

`CLOUD_FINE_TUNING_BUDGET_MODE = MINIMIZE`

你可以直接理解成：**本地负责把方向试清，云端只确认已经筛好的一个方案。**

这条规则覆盖 P0 中“Mini A/C2 双微调是默认下一步”的执行建议，但不修改 P0 历史文件，也不否认当时的设计价值。

## 默认路线

```text
真实生产数据本地定版
→ 本地 REAL_A / REAL_C2 多 seed 对照
→ 本地单阶段 / evidence-first 决赛
→ 本地数据量收益验证
→ 冻结唯一生产候选
→ Mini BASE 小规模兼容性推理
→ 一次 Mini 正式微调
```

A 继续留作本地科学基线，但不会自动获得 Mini 微调资格。

## 云端明确不做

- A/C2 格式海选；
- D/E 复赛；
- 学习率、LoRA、batch 或数据比例网格；
- synthetic 数据量实验；
- evidence-first 架构探索；
- 为比较训练剂量重复启动完整任务。

## 费用权威

- 本地设计不能产生云训练执行权；
- Mini 微调前必须有 CZ 单独批准的人民币费用上限；
- 平台的最低计费、训练方式、可保存 checkpoint 和失败退款口径都要在执行锁中按当时账号实况登记；
- 任何失败都不能自动触发第二次云任务。
