# 本地真实数据规模验证计划

## 目标

在花 Mini 训练费前，判断高质量真实数据大约到哪里开始收益变慢。

## 设计

- 只对已经冻结的生产格式和架构做规模实验；
- DEV 永远固定；
- 使用按作者分层的嵌套 TRAIN 子集，小集包含于中集，中集包含于大集；
- 每个规模使用相同 seed 清单和相同训练口径；
- 增量优先扩大作者、题材和句式覆盖，不靠同书多抽堆行数；
- 普通／困难样本比例按 assistant target tokens 对账，同时另报窗口数。

## 报告

- semantic scaling；
- Schema、status、speaker、evidence scaling；
- 困难切片变化；
- TRAIN→DEV 差距；
- seed 方差；
- 每增加一批作者／事实得到的边际收益；
- 训练时间和本地内存。

## 停止线

连续两个规模档的语义收益都落入预注册噪声区，或困难切片不再稳定改善，就登记进入收益递减区。不得为了得到更漂亮曲线继续消费 blind，也不得转去开多个 Mini 任务。
