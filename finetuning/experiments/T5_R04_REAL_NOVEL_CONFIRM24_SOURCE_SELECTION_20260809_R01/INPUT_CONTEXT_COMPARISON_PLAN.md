# 24 题输入上下文公平对照｜极简纸面计划

当前只冻结未来怎样公平比较，不制作题面，不写答案，也不授权运行。

## 三种匹配输入

每道题先固定一个且只有一个**目标责任段**。三臂都把它放进只读范围一次，再在输入尾部以完全相同的编号形式重复一次，因此目标段在三臂里都出现两次。

| 臂 | 前部只读范围 | 输入尾部 |
|---|---|---|
| A｜仅目标段 | `{TARGET_TEXT}` | 同一个 `{NUMBERED_TARGET_TXX}` |
| B｜固定机械前后文 | `{FIXED_LEFT_CONTEXT}`＋`{TARGET_TEXT}`＋`{FIXED_RIGHT_CONTEXT}` | 同一个 `{NUMBERED_TARGET_TXX}` |
| C｜完整章节 | `{FULL_CHAPTER_TEXT}`，其中自然包含同一个目标段 | 同一个 `{NUMBERED_TARGET_TXX}` |

尾部目标段使用同一套 Txx 句子编号和同一份允许证据 ID 表。模型只能抽取尾部目标段里的事实，只能引用这些 Txx；前部只读范围里的其他内容不能成为新事实或合法证据来源。

B 臂的前后文长度现在不拍数值，只登记为：**运行前按统一机械规则固定，不看 gold、不看模型结果，也不得在看分数后修改。** 本计划不沿用微型样本“每侧 8 个字符”的旧数值。

## 公平边界

24 道题的三臂必须共同绑定：

- 同一个目标段和字符范围；
- 同一套 Txx、允许证据 ID、答案和评分题号；
- 同一条抽取指令、输出合同、模型 checkpoint 和解码参数；
- 目标段在模型输入中出现相同次数。

唯一允许变化的是前部只读范围：目标段、固定小邻域或完整章。长度只报告汉字粗计，不做精确 token 统计。

## 主分和姓名还原分开记

A／B／C 的共同主分只判断三件事：目标事实是否抽对、状态是否判断正确、证据是否来自尾部目标段。A 或 B 没看到人物姓名锚点时，不能因为它保留“她／那名住户”等表面称呼而扣主分，也不能要求它猜出不可见的姓名。

“能否把表面称呼或代词还原成明确姓名”另记一项很小的上下文诊断分，而且只在该臂输入确实提供了姓名锚点时评价。C 的完整章输入和未来的两阶段指代后处理可以利用这项信息；姓名还原只是把既有目标事实里的指代写清楚，不能冒充新增了一条目标段外事实。

同一套 CONFIRM24 要先让未微调的原始 Qwen 跑 A／B／C，再让对应 LoRA 跑同一套 A／B／C。base 错而 LoRA 对，才算明确训练增益；base 与 LoRA 都对，只算保住能力；base 对而 LoRA 错，要登记为训练后退化。

占位输入可以理解成：

```text
[共同规则：只抽当前目标段，禁止抽只读上下文里的其他事实]

[只读范围]
{A_TARGET_ONLY | B_FIXED_CONTEXT | C_FULL_CHAPTER}

[当前目标段：三臂逐字相同]
{T01 ...}
{T02 ...}

[允许证据 ID]
{同一份 Txx allowlist}
```

## 指代后处理是另一条路线

“先局部抽取，再读整章把‘他／她／这人’还原为人物名”单独记作两阶段后处理，不冒充第 4 个匹配 LoRA：

1. 第一阶段仍只抽同一个目标段；人物暂时不清时可以保留表面称呼或未决标记。
2. 第二阶段只读取整章来解析已抽事实中的指代。
3. 第二阶段只能改写既有事实里的指代，不能新增目标段外事实，也不能补一条第一阶段没抽出的事实。

这条路线以后另定评分规则，本计划不提前把它与 A／B／C 混算。
