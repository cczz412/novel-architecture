# 下一轮最小证伪计划

**状态：`CANDIDATE_PENDING_LOCAL_VERIFICATION`**

限制：最多 3 个实验；每个实验只改一个变量；不先重标、不扩训练轮数、不把多个修复捆在一起。

## 实验 1：只换 checkpoint，查阶段二是否遗忘/污染

**唯一变量：adapter checkpoint。**

- 对照：每臂第一阶段 checkpoint vs 当前最终第二阶段 checkpoint；
- 固定：同一 Qwen3-4B 基座、同一 41 题、同一题面、同一 greedy/2048、同一评分脚本；
- 分层看：正向 20、特殊 6、新未见 15；
- 主要读数：JSON 有效率、原始流复读、漏 fact/status、严格与归一化三元组、A evidence 合法、C 指针合法。

判定：

- 若 stage1 在正向/新未见显著更好，而 final 只在特殊题改善，支持阶段二遗忘；
- 若 final 主要增加 evidence-first/漏 fact，但语义覆盖变化不大，支持“格式先验污染”；
- 若几乎不变，阶段顺序不是主因。

这个实验不需要重新训练，只需本地仍保留阶段一权重。

## 实验 2：只改输出上限，查 2048 是根因还是终止器

**唯一变量：`max_output_tokens` 从 2048 改为 4096。**

- 只跑 A 当前 22 个触顶案例；
- 固定最终 adapter、题面、greedy、temperature 0、无重试；
- 记录首个重复对象出现位置、总独立事实数、重复次数、JSON 是否最终闭合。

判定：

- 若只是多复读约 2048 token 后再次触顶，证明上限只是终止器；
- 若多数案例在 2048 后自然停止并补全，且新增的是独立正确事实，才支持上限过小是主因。

不要在同一实验里再加 repetition penalty、temperature 或重试，否则无法知道是哪项起效。

## 实验 3：只改 C 题面范围标记，查“抄标题范围”捷径

**唯一变量：把输入标题中的责任范围从输出同形的 `@start:end` 改成自然语言。**

例：

- 原：`[CH0042-E031｜归属终点范围 @66:100]`
- 改：`[CH0042-E031｜证据终点允许落在第 66（含）至 100（不含）字符]`

保持编号单元正文、输出合同、金标、adapter、解码、41 题全部不变。

主要读数：复制标题范围的比例、整单元指针比例、严格指针合法率、语义覆盖。

判定：

- 若 header-range copy 从当前高位明显下降且合法率上升，输入外观冲突是重要病因；
- 若仍照抄整单元或坐标无改善，主瓶颈更接近精确坐标执行能力/训练不足。
