# 事实抽取实验决策账｜2026-08-10

## 我们到底要选什么

目标一直只有两个：

- 模型稳定输出约定的 JSON 格式；
- 模型把负责区里真正该留的事实抽准，事实多就多写，事实少就少写，没有就输出空数组。

4B 在实验里先负责便宜淘汰明显差的方案；调到可用后，也可以保留为低成本免费档候选。将来换 Mini 时，已经审好的 Gold、教材和格式合同继续是资产，但 4B 上的配方冠军仍要用 Mini 做小规模复验。

## 🔒 稳定规则｜不能被一轮小失败推翻

### R04-D01｜旧教材不因缺课被删

TRAIN72 里高密事实教材继续保留。发现模型不会空、不会短输出，处理方式是补足对应教材和修正训练计算，不是把原来的高密教材删掉。

### R04-D02｜教材只增补已确认的缺口

一次失败只能生成“待验证解释”，不能立刻改变教材比例。要增补某类教材，至少要同时满足：

- 冻结考题里出现同一类错误，不是单个题源或 Gold 写错；
- 独立语义审查确认缺的是能力，不是格式、截断、评分或训练器权重问题；
- 新增材料有自己的来源、Gold 和不泄漏检查；
- 旧材料原样保留，新材料单独登记，能够说清到底补了什么。

### R04-D03｜空题不是越多越好

空题只教“没有符合条件的事实时应为空”。不能拿来压制所有输出，也不能因为过抽取就连续追加。当前新 24 题的 `8 空 + 16 个 1～6 条事实` 只是一次课程候选，不是永久最优比例；reducer 诊断已经完成，在 TRAIN96 资格结果出来前不再增加空题。

### R04-D04｜高密和低密都要会

高密样本负责教穷尽抽取，低密／空样本负责教停止边界。两边都保留，不能用一边的失败去取消另一边。评估时分别看：空题是否真空、低密是否少而准、高密是否没有漏掉关键事实。

### R04-D05｜不再用 JSONL 行序当调参旋钮

TRAIN72 的原排序、`density-paired`、`zero-low-paired` 已经证明：同一批教材只换相邻配对，模型会从过抽取翻到过度归零，再翻回过抽取和复读。后面禁止第四种排序，也禁止用“把空题和谁放一组”控制模型行为。

### R04-D06｜先消掉训练器混淆，再评价教材

冻结 trainer 当前做的是：每个微批先按自己的 assistant token 数求平均，再把四个微批等权平均。短答案微批和长答案微批因此可能获得不合理的同等权重。新训练前必须使用派生 vendor 做“整个 optimizer 窗口按全部 assistant token 统一归一化”，并先通过分组不变性测试。旧 vendor 不原地改。

这项 token-weighted 修正已证明数学不变性，但 TRAIN72 和 TRAIN96 两次实跑都没有教会空题停止。它保留为已完成的数学纠错，不再冒充教材问题的解法。随后从原 vendor 派生的“每道题先求自己的 assistant token 平均 loss，再对 batch 内样本求平均”也已完成单次资格跑并失败；当前 TRAIN96／损失归一化 4B 配方到此停止。

### R04-D07｜一次只比一个家族

- READ 阶段固定答案格式，只比正文可见范围。
- OUT 阶段固定 READ 赢家，只比答案／证据写法。
- 正常不跑 3×3 九格；只有已有结果显示明确交互，才单独登记补格。

### R04-D08｜三种 READ 叫法按真实输入写

三格分别是：

- `TARGET+FOCUS`：只给目标段，尾部再给同一负责区；
- `HALO180+FOCUS`：给目标段前后各 180 个 Unicode 字符，尾部再给负责区；
- `FULL+FOCUS`：给整章只读正文，尾部再给负责区。

三格共同 Gold 只评分目标段事实。整章带来的姓名／指代恢复单列诊断，背景区事实泄漏属于硬错误。FULL 开跑前按真实 tokenizer 检查长度；若某题超上限，同一题从三格共同分母一起排除，不能只截 FULL。

### R04-D09｜教材和考卷永远分开

- 项目原创、审收通过的材料才可进入训练候选。
- L6 和 REAL24／CONFIRM24 只考试，不训练、不回流、不按答案调 Gold。
- 同一题若参与调课程或门槛，就不能再冒充最终未见考题。

### R04-D10｜外部报告提供依据，不直接替我们拍板

报告里的论文、大厂做法和建议要和本地代码、失败票对照。能解释现场且可做单变量验证的，登记为假设；与本地真源冲突的，以本地代码和回执为准。报告原文件和 SHA 已写进机器登记册，结论不会只留在聊天里。

## 🧪 当前假设｜允许验证，但不能提前当结论

### H01｜数学不变性成立，但不足以解决教材缺课

同 8 样本的两种配对和一个 8 样本参考 batch 已完成梯度／参数更新对照。新 reducer 的 A/B/reference、SGD 和 Adam 状态均在容差内一致，旧 reducer 的 A/B 明显不同；tiny MLX 模型也已走通真实 `default_loss → value_and_grad → step → Adam.update`。这证明同一个 optimizer 窗口内的数学计权混淆已经修正。

随后按冻结票完成 TRAIN72 density-paired 单变量诊断：训练与推理执行链通过，JSON／Schema／非空题／非法证据／复读／触顶／重复均正常；但 L6 六题预测为 `20/7/7/6/22/7`，两道空题都失败。失败票 SHA 为 `399c7eab1bf4f99cdf5012bf9ee027e15c798567d99a4082d5f15efdae57f62c`。所以 reducer 是必要的数学修正，但单独使用不足以解决停止边界缺课。

TRAIN96 也已按精确票用同一 token-weighted reducer 从原始 base 跑完：训练执行链通过，但 L6 为 `42/16/6/6/44/7`，JSON／Schema 各3/6，复读2题、触顶2题、重复事实60条。失败票 SHA 为 `b09f3d952c3ca7668236d1fa21dc4957d0225cf152f5849b5362986e5b527a77`，这个 bundle 已淘汰，不重试、不跑 REAL24。新24题只占全96题 assistant 监督 token 的6.2898%，其中8道新增空题合计48 token；这能解释空题信号很弱，但不冒充完整的梯度归因。

### H02｜新 24 题补的是长上下文下的 0～6 条事实判断

候选配额原计划为：自然空 3、硬空 5、1 条 4 题、2 条 4 题、3 条 4 题、5 条 2 题、6 条 2 题，共 24 题、46 条事实。它补旧 TRAIN72 缺少的稀疏／中低密课程，不代替旧 72。

R02 已把六个语义问题修正为49条，并把字数阈值捷径从22/24降到17/24；控制复核发现的自然段密度和逗号捷径已在 R03 用三处自然目标区调整消除。R03 保持 `8空 + 16个1～6条事实`、合计49条，三项固定单阈值最佳都为17/24；机械与独立语义审查均 PASS，R01/R02未回改。

### H03｜每道题一票的 sample-mean loss

验证的 loss 候选是：每道题的 assistant 有效 token CE 先在题内求平均，batch 再对两道题求平均，GA4 和 optimizer 循环不改。这样每个完整 optimizer 窗口的8道题各占1/8，不再由相邻 pair 的答案长度决定权重。NumPy 与 tiny MLX 预检均已通过。

资格跑随后从原始 base 按冻结票完成48个 microstep、12次 optimizer update。L6 Gold 条数为 `0/0/2/3/5/8`，LoRA 六题预测全部为 `0/0/0/0/0/0`：JSON 与完整 Schema 均为6/6，非法证据、复读、触顶和重复事实都是0，但四道非空题全部塌为空，因此机械门 FAIL。失败票 SHA 为 `90e461e52735193e75a56c59ed7544cf6ab187aa1941ffcf69c5473990061066`。执行链 PASS，实验 FAIL，硬停 PASS；未做盲审，也未运行 REAL24。

## ✅ 2026-08-10 新稳定结论

- reducer 数学不变性成立，训练执行链也通过，但它不能代替稀疏／停止边界教材。
- RECUT24 R03 已通过控制审查，可作为模型中立共同原料；它仍不是单独运行权。
- TRAIN96 + token-weighted reducer 已运行并在 L6 机械门失败，bundle 已淘汰且不重试。
- TRAIN96 + sample-mean loss 也已运行；格式完整，但四道非空题全部输出空数组，同样在 L6 机械门失败。
- 当前 TRAIN96／损失归一化 4B recipe 已停止：禁止第三种 loss、继续加教材、挪序、调学习率／步数／LoRA、扫 checkpoint 或 retry，也不得从本失败格进入 READ2／READ4／OUT／REAL24。
- 停止范围只限当前这套可调配方，不等于永久淘汰4B，也不决定 Mini。模型中立 Gold、TRAIN96、L6 与全部旧结果继续原字节保留。

## 🪦 已淘汰做法｜保留证据，禁止换名重跑

### X01｜失败 adapter 上续训同一批长 S/M12

Stage2 后零事实题仍输出 19／7 条，LC-L05 输出 46 条并触顶复读。说明这条续训路线没有补上停止边界，停止。

### X02｜靠三种相邻配对调答案密度

- 原 TRAIN72：L6 预测条数为 `19/7/6/6/12/7`；零题严重过抽取。
- density-paired：`0/0/0/6/0/9`；零题正确，但两道非空题塌为空。
- zero-low-paired：`19/7/7/6/44/8`；重新过抽取，且 LC-L05 触顶复读。

这三次不是“哪一种排序赢”，而是证明训练权重受固定 pair 干扰。禁止第四种排序。

### X03｜把新 24 题机械凑成长空题

如果空题显著更长、固定出现在同一种位置，模型可能学长度捷径而不是事实边界。当前 RECUT24 R01 只保留为候选证据，不直接渲染 TRAIN96。

## 👉 当前停点与下一步

当前 TRAIN96／损失归一化 4B recipe 已停止。sample-mean 已实跑并在 L6 机械门失败，不跑 REAL24，不再造第三种 loss，也不再通过新增教材、挪序或改超参缝补。

这不是“4B 永久淘汰”：现有另一个已经跑过的低剂量／格式配方能否承接 READ 对照，只能由控制窗另行核定。本工单不产生新运行权，不自动开启 READ2／READ4／OUT。

## 以后怎么改这份账

新结论不能静默覆盖旧结论。每次变化都要写四样：

- 哪条规则保留；
- 哪条假设被证实、被否定或仍未决；
- 用了哪张本地结果票／哪份外部证据；
- 下一轮只允许改变哪个变量。
