# 责任块 60／300／600 粗筛候选预检

✅ 这包只把同一批 REAL24 目标段机械切成约 60 字和约 300 字的小责任块，并把现有完整目标段记作 600 档。没有生成模型请求，也没有运行模型。

这里比较的是“每次让模型负责多大一块正文”，不是 Halo。未来若获授权，三档都覆盖同一份原目标段：60／300 档分别跑完所有小块后合并输出，再统一对原 600 段 Gold 评分；600 档直接复用现有结果。只读背景固定为已经选出的 H180，不做 `3×3`。

分块器只看原目标正文。它先认完整句和自然段边界，再把极短拟声词或独立短碎片并入邻接内容；约 60 档优选 40—90 个 Unicode 字符，约 300 档优选 220—380 个 Unicode 字符。它不读取 Gold 来挑边界。

边界冻结后才读取 Gold 做风险统计：有多少事实证据跨块、多少块没有一条可由本块完整承托的 Gold、多少块超出预期长度。跨块事实不会反过来触发挪边界，因此“连续两句共同表达一个事实”只能尽量靠自然边界保住，残余问题照实报告。
