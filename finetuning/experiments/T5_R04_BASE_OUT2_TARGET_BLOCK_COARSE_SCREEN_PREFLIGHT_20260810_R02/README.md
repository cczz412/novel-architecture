# 责任块粗筛预检 R02

✅ R02 只修正 R01 的证据顺序和用途登记，分块几何不靠 Gold 回调。

分块时只读取冻结来源索引和 Txx，先生成候选字节并计算候选 SHA；候选冻结后，才读取并核验 Gold，用它统计事实跨块情况。Gold 不参与挑边界。

三档现在这样处理：

- 约 60 字档机械退出本轮赢家筛选，模型调用为 0。它只说明责任区过小时会产生严重跨块压力，不能据此说模型失败。
- 约 300 字档是唯一 Stage1 候选，只准备八题 22 块。
- 原来的“600档”改称完整段档。它实际是每题 620—923 个 Unicode 字符，中位数 760；直接复用已经跑过的 H180＋OUT2 结果，不重跑。

本包仍是候选预检，没有运行权。REAL24 继续只作本地考试材料，不能回流训练。
