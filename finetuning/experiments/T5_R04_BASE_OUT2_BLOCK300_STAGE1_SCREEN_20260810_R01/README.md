# BLOCK300 Stage1 准备包

✅ 这包只准备八题、22个约300字责任块，不运行模型。

每块都重新生成自己的 `T01…`。映射表同时保存块内坐标、原目标坐标、原文章绝对坐标和逐字 SHA，所以不会再出现旧 T 编号被边界切开后无法唯一回映的问题。

模型以后看到的是：未微调本地 4B、每块左右各最多180个 Unicode 字符的只读背景、OUT2-IDLIST，以及只属于本块的新 T 编号。请求里没有 Gold、事实数、跨块统计或密度标签。

八题的22块输出只按块序直接拼接，不融合、不去重。跨块出现同一句预测是分块方案的真实代价，不作为机械故障：两次都留在预测分母，一对一最多奖一次TP，多出的自然成为FP，同时单列诊断。块内逐条重复、生成复读、格式、非法证据和截断仍会硬停。

原完整段的85条 Gold 全部保留：77条证据完整落在某一块内，可以成为合法TP；8条证据跨块，固定留作FN。模型若借Halo猜中这些跨块事实，只记责任区越界FP。

边界和请求字节冻结前只核来源、旧T编号、实际H180请求与R02候选；Gold以及含Gold审计结果的R02统计和回执，统一在冻结后读取。
