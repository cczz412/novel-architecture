# P4｜2×3 六臂零训练预注册

## 实验问题

同一份完整章、同一份冻结章级 gold 下，分别回答两件事：

1. 阅读完整章是否比固定局部 halo 更有帮助；
2. 责任区约 10／20／30 块时，事实质量、归因完整性和开销怎样变化。

本文件只预注册，不授权运行。

## 材料和配对

- 只用同一组 12 个或更多、已通过完整章资格闸的真实章节；
- 六臂逐章严格配对；
- 每章三种粒度都由同一冻结 splitter 机械产生；
- 每个粒度的 LOCAL/FULL 使用相同责任区与尾部编号；
- 同一章级 gold 在六臂之间不变；
- 任何一章缺 SHA、授权、切分前 gold 或绝对坐标，都不能进入分母；
- 开跑后不允许更换章节、切点、gold、Prompt 或 evaluator。

## 六臂

`LOCAL_READ / FULL_CHAPTER_READ × P4-GRAN-10 / 20 / 30` 全部运行。不能只跑四臂后把局部赢家写成全局最佳。

## 区级输出怎样合成章级答案

1. 保存每个责任区原始输出；
2. 单列 JSON／Schema 失败、非法 ID 和责任区外新事实；
3. 把合法 evidence ID 机械映射到原章绝对字符范围；
4. 用 `fact 规范化文本 + status + speaker + 绝对 evidence 范围` 作为精确去重键；
5. 同键只保留一条，保留重复来源区列表；
6. 按最早 evidence 起点、事实规范化文本、status、speaker 稳定排序；
7. 章级合并结果与同一章级 gold 评分。

不允许直接拿区级 F1 横比。语义近似但不满足精确去重键的对象，进入盲审队列，程序不得自作主张合并。

## 三层指标

### 固定分母 A：共同可抽交集

跨粒度比较时，只使用在所有被比较粒度下都完整落在单一责任区的 gold 交集。这个交集在模型运行前冻结，六臂共用同一 fact ID 列表。

LOCAL/FULL 在同一粒度配对时，可以使用该粒度预先冻结的 contained 集，因为两臂边界相同；一旦跨粒度比较，必须回到共同交集。

### 固定分母 B：整章 all-gold

每臂同时用同一份完整章全部 gold 计算章级语义 precision／recall／F1。当前 evidence 合同无法合法产出的跨区事实记为未召回，不能从分母删掉。这个指标回答“整套系统最终能用多少”，也是晋级硬门。

### 每臂自己的区内指标

只作边界诊断，不得用于跨粒度胜负或晋级。它可以解释哪种切法让多少事实变成跨区，但不能靠缩小分母把窄粒度写成更强。

### 干净能力与结构指标

在上面相应固定分母中报告：

- 章级语义 precision／recall／F1；
- status、speaker；
- evidence 绑定正确率；
- JSON／Schema；
- 非法 ID；
- 责任区外新事实；
- 合并前重复和合并后剩余重复；
- 空责任区误报；
- 合并后章级覆盖；
- 输入／输出 token；
- 本地冷／暖时延。

### 强制跨区诊断

- 跨区 gold 数和占全章 gold 比例；
- 跨区事实按多句、指代、说话人切片、关系／条件等类型分层；
- 六臂各自遗漏、部分命中、越权抽取；
- 如果只算干净主指标会隐藏多少事实。

跨区事实不进入共同交集胜负，但必须进入 all-gold recall／F1，不能从最终可用性报告删除。

### 故障面

- 截断、复读、空数组逃避；
- 非法 JSON、缺字段；
- max-token 停止；
- 单区输出过长；
- 同一章多区反复抽同一事实。

## 事前判定线

主比较单位是“每章合并后的语义 F1”，不是单区。

- 最小有意义差值：绝对 F1 差 `0.02`；
- 打平：绝对差小于 `0.02`，或配对 bootstrap 95% CI 包含 0；
- 候选方向：差值至少 `0.02`、95% CI 不含 0，且低分臂不存在反向的明显 gold 分母漂移；
- 跨粒度候选必须在共同交集上达到上面的候选方向，同时 all-gold semantic F1 和 recall 相对对应比较臂均不得下降超过 `0.02`；
- 全局诊断候选的 all-gold semantic F1 和 recall 还必须落在六臂最佳值的 `0.02` 以内；
- 任一臂 JSON／完整 Schema 低于 95%、非法 evidence ID 高于 1%、责任区外新事实高于 1%、触顶高于 1%，不能成为诊断候选；
- token 或时延收益不能补偿语义 F1 超过 2 个百分点的退化；
- 六臂都过不了结构／越权门时，结论是合同未成熟，不从中硬选赢家。

配对 bootstrap 使用章为重采样单位、固定 seed、10,000 次。小于 12 章不运行真实诊断。

## 多重比较

预注册五个主对照：

1. 每个粒度的 FULL - LOCAL，共 3 个；
2. 两种阅读范围平均后的 GRAN-20 - GRAN-10；
3. 两种阅读范围平均后的 GRAN-30 - GRAN-20。

五个主对照使用 Holm 校正，家族错误率 0.05。其余 15 个臂间两两结果只作描述，不产生晋级判定。阅读范围 × 粒度交互单列置信区间；样本不足时只能登记信号。

## holdout 和生产边界

六臂最多选出本地诊断候选。晋级前还需要：

- 独立冻结的完整章 holdout；
- 书、作者、来源与本轮诊断集隔离；
- 同样的完整章权利、gold 前置和绝对坐标闸；
- 不按本轮结果挑题；
- 在另行授权后由 Doubao Mini/Lite 验证。

本地 Qwen 结果不能直接改生产接口、生产 Prompt 或训练教材。
