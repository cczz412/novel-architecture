# 事实抽取实验总路牌 R13｜免训练候选模型筛选，停在选题准备态

✅ 下一条路线已经明确：本地未微调 4B Base 做基线，Agent Plan 中可用的模型做候选，所有模型使用同一套新考卷。只要有候选达到产品可接受线，就优先跳过微调，直接进入后续选型；如果全部不达标，这个负结果再作为 Mini 微调线是否有必要的证据。

本轮主考卷按 CZ 2026-08-11 的拍板，改用本地新抓取、且发布时间晚于候选模型知识截止时间的真实小说候选。这个许可只覆盖本次国内模型评测，不把正文升级成训练料、公开发布材料或生产真值。正式选题前仍要逐本绑定来源、抓取时间、发布时间和候选模型截止时间，不能只凭“看起来很新”判断无污染。

考卷固定为四本不同类型的小说，每本只取一整章；章节序号分别是第一章、第二章、第四章和第十章，每个序号只用一次。每一整章是一张独立考卷，拆成自然责任块给模型作答；整章总分由该章所有责任块的 TP、FP、FN 汇总重算，块级成绩同时保留。短拟声词、单独语气词和过短对白不会单独成为责任块，而是与相邻自然段合并。

切块沿用已经胜出的本机结构：自然责任块目标约 620–923 个 Unicode 字符，左右各最多 180 字只读背景。责任块不重叠，每条 Gold 事实只归一个块；章首、章尾可以自然短于目标区间，绝不为了凑字数补写正文。整章总分不是再把整章喂给模型跑一遍，而是把同章各块的结果汇总成一张总成绩。

产品过门线先放一版 Codex 提案，等 CZ 终审：严格 JSON、Schema、证据越界、重复、复读和触顶全部零容忍；四章合计 Precision 不低于 0.85、Recall 不低于 0.75、micro-F1 不低于 0.80；单章 F1 不低于 0.70、单章 Recall 不低于 0.65。达线只说明“免训练候选可以进入选型”，不等于生产晋级。
