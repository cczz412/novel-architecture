## 不能混淆的四组判断

1. **放得下 ≠ 用得好。** F的容量可行性与中段召回、输出截断、证据定位是不同指标。
2. **历史更短 ≠ 历史更真。** D/C2即使token更少，只要来自未经语义验证的模型预测，就有传播风险。
3. **3310条挂锚0丢失 ≠ 语义质量通过。** 这是确定性装配结果，不是新方案的指代与事实准确率。
4. **机械格式FAIL ≠ 上下文方案语义FAIL。** 40个空占位和7个字段层级问题应独立修复、独立验收。
