## 结论

建议把 24 道新增教材配成：

| 类型            |     道数 | 事实总数 | 主要教学目标                |
| ------------- | -----: | ---: | --------------------- |
| 自然真空题         |      3 |    0 | 普通长段也可以完整、合法地输出 `[]`  |
| 困难空题          |      5 |    0 | 有很强的候选事实，但证据合同不成立     |
| 其中：单条件失败的近似正例 | 至少 3/5 |    0 | 精确学习否定、实体、时间、条件、归属等边界 |
| 1 条事实         |      4 |    4 | 干扰很多时只抽一条，并在抽完后停止     |
| 2 条事实         |      4 |    8 | 同时控制漏抽和过抽             |
| 3 条事实         |      3 |    9 | 处理对白归属、跨句承托和多个拒绝项     |
| 5 条事实         |      3 |   15 | 从稀疏向中密度平滑过渡           |
| 8 条事实         |      2 |   16 | 明确告诉模型：事实确实多时不能暗藏输出上限 |
| 合计            |     24 |   52 | 新增集均值 2.17 条/题        |

这不是机械平均：

* 空题 8 道，占新增集 33.3%；
* 1～3 条稀疏题 11 道，占 45.8%；
* 5～8 条中密题 5 道，占 20.8%；
* 困难空题多于普通空题，但仍保留 3 道自然空题，避免模型把 `[]` 学成一种特殊“陷阱文体”。

精确的 `3/5/4/4/3/3/2` 是工程配额，论文没有证明它最优。若并入当前 73 道 P2 池，且旧池确实没有空题，合并后的段落级空题率只是 `8/97≈8.25%`，总均值仍约 7.05 条事实/题。也就是说，新增集的 33% 空题不会把整个教材改造成“经常不抽”。

## 证据强度

| 判断               | 证据强度   | 依据与边界                                      |
| ---------------- | ------ | ------------------------------------------ |
| 训练中必须出现真正的空输出    | 强      | KnowCoder、生成式事件抽取都直接训练空列表，并有明显消融收益         |
| 困难空题应多于明显空白段     | 中强     | SQuAD 2.0、IEPile、CodRED 都显示相关且貌似成立的负例更能教边界 |
| 漏标正例误作负例会严重伤召回   | 强      | Re-DocRED 的漏标与重标实验非常明确                     |
| 负例过多会增加误拒答、压低召回  | 中      | QA、RE 多项实验方向一致，但负例单位和任务不同                  |
| 旧高密教材保留，新增低／中密教材 | 中强，方向性 | 多项工作采用“保留正例、追加负例”，但没有中文小说多事实生成的删除对照实验      |
| 24 道的精确桶数        | 弱      | 合理工程推断，需要后续消融验证                            |
| 应按“空→稀疏→密集”排课程   | 证据不足   | IE 的 easy-to-hard 研究并不是按答案条数定义难度           |

一个重要口径：SQuAD 的负例单位是“段落×问题”，事件抽取经常是“文本×事件类型”，你们则是“一段长文只输出一次完整事实数组”。因此 SQuAD 的 33%、KnowCoder 的 5%、事件抽取的“每例 15 个负类”不能直接互换。

## 可迁移的研究经验

### SQuAD 2.0：空题要“相关而不被承托”

SQuAD 2.0 在原有可回答题上追加 53,775 个不可回答题。训练集空题为 43,498/130,319，约 33.4%；开发、测试集接近 50%，那是为了平衡评测和调拒答阈值，不是训练配方。

更有价值的是它对负例质量的要求：问题要与正文相关，正文中还要有一个类型正确、非常像答案的干扰项。简单 TF-IDF 或规则替换负例明显容易；模型在困难空题上误答时，大约一半会正中人工预先标出的“貌似答案”。人工复查依然发现约 7% 的所谓空题其实可回答。[[SQuAD 2.0 论文](https://aclanthology.org/P18-2124.pdf)](https://aclanthology.org/P18-2124.pdf)

迁移到小说抽取：困难空题中应保留“模型最想抽的事实”，然后让它因一个明确条件失败；不能只选完全无关的景物描写。

长文本 QA 还有一个贴近本任务的发现：切长文时，如果训练阶段丢弃“不含答案的自然窗口”，模型会遇到训练、推理分布不一致；加入这些自然空窗口后，长文本和域外表现稳定改善。[[MRQA 长文本负采样研究](https://aclanthology.org/D19-5829.pdf)](https://aclanthology.org/D19-5829.pdf)

### 信息抽取：显式空列表和相似负类能治“每类都抽”

KnowCoder 把 5% 句子改成 fully-negative，目标直接是空列表；去掉这部分后，零样本 NER 平均 F1 从 57.8 降到 55.7。它还给正类搭配少量未出现类，去掉这类监督后降得更多。[[KnowCoder](https://aclanthology.org/2024.acl-long.475.pdf)](https://aclanthology.org/2024.acl-long.475.pdf)

IEPile 指出，只展示正 schema 会诱导模型给每个查询标签都生成答案；它加入语义相近的困难负 schema，例如裁员、辞职、解雇之间的混淆，并进行人工复查。[[IEPile](https://aclanthology.org/2024.acl-short.13.pdf)](https://aclanthology.org/2024.acl-short.13.pdf)

这与当前过抽问题高度相似：`[]` 和“候选很多但只抽少数”必须在教材里成为显式、自然的正确行为，不能靠输出上限或重复惩罚代替。

### 关系抽取：实体错配和远距似相关可以直接借鉴

CodRED 构造了两类很贴合本任务的困难 NA：

* 把正例中的实体替换成一个“仅看实体名就会被模型高置信判正”的错误实体；
* 在跨文档路径中选择共享实体最多、看起来最相关、但并不承托目标关系的路径。

每条路径至少由两人判断正文是否真的支持，分歧交第三人；只有所有路径都没有正证据才判 NA。作者甚至避免把一部分人工 NA 放入开放域测试，因为可能还有未发现的正路径。[[CodRED](https://aclanthology.org/2021.emnlp-main.366.pdf)](https://aclanthology.org/2021.emnlp-main.366.pdf)

这可以直接转成“实体不匹配”和“远距离上下文看似相关、目标责任区却不承托”两类教材。

### 事件抽取：否定、假设和承诺不能只靠关键词识别

TALOR-EE 专门生成否定、拒绝、假设、相信、承诺、希望等近似事件文本；移除负向增强后，事件论元分类平均下降约 7.5%。[[TALOR-EE](https://aclanthology.org/2024.findings-naacl.275.pdf)](https://aclanthology.org/2024.findings-naacl.275.pdf)

另一项生成式事件抽取工作为每个原训练例追加不存在事件类型、期望输出为空的样本。ACE 的 argument-classification F1 从 29.73 升至 61.96；RichERE 从 25.32 升至 31.56。[[ACL 2025 生成式事件抽取](https://aclanthology.org/2025.findings-acl.677.pdf)](https://aclanthology.org/2025.findings-acl.677.pdf)

这些论文支持“加入负极性和空输出”，但不支持把所有否定词、假设词或承诺词自动判空。

## 三类空题分别教什么

* 自然真空题教“没有值得保留的事实也是完整答案”。应覆盖气氛、常规动作、无后效对白等自然文本，但不能全是短景物段，否则模型会学长度和文体捷径。

* 困难空题教“文本相关、语义像事实，并不等于满足责任区与承托条件”。每题至少应有两个审计时能说清楚的强候选。

* 近似正例是困难空题中信息量最高的一类：尽量只让一个条件失败，例如主体错、时间错、尚未发生、只是某人声称。它也最容易被误标，所以建议至少占 5 道困难空题中的 3 道。

七种边界都应同时出现“拒绝样本”和“相同表面线索下应接受的稀疏正例”：

| 边界       | 空题／排除项教什么               | 配套正例防止什么捷径             |
| -------- | ----------------------- | ---------------------- |
| 否定       | 被否定的事件不能当已发生事件          | 否认、拒绝本身若影响后续，仍可能是事实    |
| 条件／假设    | 条件未满足，不抽假想结果            | 条件、约定、承诺本身若持续有效，应抽     |
| 说话人归属    | “甲说乙做过”不能直接写成“乙确实做过”    | 可抽“甲声称／相信某事”，但保持归属     |
| 时间不匹配    | 未来、回忆或其他时期不能冒充目标时段事件    | 过去建立且当前仍有效的关系不能因过去时被漏掉 |
| 实体不匹配    | 同名、近名、错误代词不能串到目标实体      | 别名、指代被可靠解析时应正确合并       |
| 气氛／一次性动作 | 无后效描写不因生动而入选            | 一次动作若造成持久变化，仍应入选       |
| 远距上下文    | 背景区只能帮助理解，不能替目标责任区产生新事实 | 目标区确有承托时，可用背景协助消歧      |

七类不用机械地各做一题，可以重叠；最低要求是每类至少出现一次“拒绝”和一次“接受”。

## 空答案比例太低或太高

太低时，模型会学到“每段必有答案”的先验，随后从候选中挑最像的一条，或者给每个 schema 都强行生成。SQuAD 1.1、IEPile 和生成式事件抽取都观察到了这种现象。

太高时会出现：

* 1～3 条事实题被误判成 `[]`；
* precision 上升而 recall 下降；
* 模型利用短输出、否定词、段落长度或特定文体识别空题；
* 只要金标存在漏标，负例越多，错误的“不抽”监督越强。

Re-DocRED 发现原 DocRED 平均约有 64.6% 的关系三元组漏标；修订标注后，训练所得召回由 32.07 升到 69.40，而精度接近。负采样增加时总体呈现 precision 上升、recall 下降；标注不完整时，把全部未标实体对当负例尤其有害。[[Re-DocRED](https://aclanthology.org/2022.emnlp-main.580.pdf)](https://aclanthology.org/2022.emnlp-main.580.pdf)

因此，没有可信证据支持一个通用空题比例。建议把 8/24 视为“专项增补批次配额”，最终仍按合并后的段落级空题率、各事实数桶，以及实际目标 token 权重监控。若训练代码按目标 token 平均 loss，空数组样本很短，它的有效训练权重还可能远低于行数占比；这一点属于工程推断，应检查实际实现。

## 怎样避免假空题

空题不能以“第一位标注员没找到”为成立条件。建议采用：

1. 两名标注员独立枚举全部候选事实，而不是一人标、一人只检查。
2. 为每个候选记录 `接受／排除／不确定`，排除项必须写明实体、时间、条件、归属、责任区或重要性中的失败原因。
3. 所有分歧交第三人裁决；仍不确定的样本隔离，不得强制写成 `[]`。
4. 审核者查看模型实际能看到的完整输入，检查别名、代词、对白说话人、跨句改写和远处上下文。
5. 对 8 道空题运行多个候选模型或提示生成“可能遗漏的事实”，再由人复核；模型只能提供召回候选，不能自行批准空题。
6. 每条入选事实必须有目标责任区内的确切证据；背景区可以消歧，不能单独承托新事实。
7. 训练后把模型在空题上高置信抽出的内容送回复审。若内容其实成立，应修金标，不能把正确抽取当幻觉。

SQuAD 2.0 的严格流程仍有约 7% 假空题；Re-DocRED 两轮模型候选加双人复核，说明对高价值小样本，候选枚举与仲裁比提高空题数量更重要。

## 是否保留旧高密教材

建议保留，并与新增 24 道混合打散；若从旧 checkpoint 续训，应回放旧高密教材，不要只连续训练这 24 道。

支持这一方向的先例包括：

* SQuAD 2.0 保留原有可回答题，再追加不可回答题；
* KnowCoder 在原数据中追加 fully-negative 与负类；
* 生成式事件抽取保留原事件样本，再追加空输出查询；
* IEPile 在正 schema 旁增加困难负 schema。

这支持“补缺失行为，不用负例替换已学会的正能力”。但没有论文对中文小说“0～多条事实生成”做过“删除旧高密 vs 完整保留”的受控实验，所以只能标为中强的工程路线。保留也不等于免检：若旧金标存在漏抽、重复或责任区错误，仍应修正。

也没有证据支持按答案条数排课。较稳的默认做法是新旧 union 后按密度分层打散；课程顺序、分层采样、按例归一 loss 另开消融。

## 最小验收表

| 检查项   | 最低通过条件                                                                                     |
| ----- | ------------------------------------------------------------------------------------------ |
| 配额    | 精确满足 `3/5/4/4/3/3/2`；困难空题中至少 3 道为单条件失败                                                     |
| 事实证据  | 100% 金标事实有目标责任区内的确切承托；无背景区单独承托                                                             |
| 空题真实性 | 8/8 双人独审、全部分歧仲裁、无未决候选                                                                      |
| 困难度   | 5/5 困难空题每题至少 2 个貌似成立候选，并保存排除理由                                                             |
| 稀疏停止  | 11/11 的 1～3 条题每题至少 1 个强干扰候选                                                                |
| 边界平衡  | 七类边界各至少一个拒绝样本和一个接受样本                                                                       |
| 防捷径   | 空／非空在长度、对白比例、题材和实体数量上有重叠；TRAIN／DEV 按书、作者、来源隔离                                              |
| 独立评测  | 另建未参与训练的分层 DEV；不能拿这 24 道训练回放证明改善                                                           |
| 语义指标  | 分别报 empty precision/recall、`false-empty@1–3`、各密度事实 P/R/F1、exact-count 或 Count-MAE、每题无依据事实数 |
| 非退化   | 空题正确率提高；1～3 条误判空率不升；5～8 条及旧高密召回不超出预先规定的多随机种子波动带                                            |
| 机械行为  | 合法 JSON/EOS 100%，无截断、无重复、无命中最大输出；这些只算格式门，不代替事实正确性                                          |

核心论文的结论来自方法、实验表格和相关附录核读，没有用只读摘要的论文支撑关键判断。最缺的证据仍是：中文小说长文本、一次生成完整事实数组、尤其是小模型 LoRA 条件下的密度配额消融。因此，24 道配额应当视为一个有证据约束的起始设计，而不是固定教材定律。
