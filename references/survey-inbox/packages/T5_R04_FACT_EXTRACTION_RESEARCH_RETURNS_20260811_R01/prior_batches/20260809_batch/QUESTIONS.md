## Q01｜为什么只换样本配对，模型会在“疯狂多抽”和“全部不抽”之间跳？

```text
请做一次深度技术调查，审查“小模型 LoRA/SFT 中，batch 内样本长度与答案密度配对会不会显著改变训练结果”。

共同产品说明已经在本窗口背景中，不需要索取额外材料包。

当前现场：
- 模型是本地约 4B 参数的指令模型，做中文小说事实抽取。
- 输出是严格 JSON；目标段事实可能为 0 条，也可能为 1～20 多条。
- 同一份 72 道教材、同一 base、同一学习率、同一训练步数，只改变相邻样本如何组成 batch：
  - 稀疏样本和高密样本配对时，模型严重过抽；
  - 两个空答案集中配对时，模型又会把部分非空题答成空；
  - 空答案与 1～2 条事实样本配对时，又重新过抽并出现复读。
- 当前训练器是 decoder-only SFT；batch 内按 assistant token 计算损失，梯度累积会把多个 microbatch 合并。

请查清：
1. 这种现象在论文、官方训练框架或大厂技术报告中有没有直接先例。
2. token 平均、样本平均、microbatch 等权、序列长度差异、EOS 学习分别可能怎样影响空答案和长答案。
3. data packing、动态 batching、长度分桶、随机重排，会缓解还是放大问题。
4. 对小数据 LoRA，应该优先：
   - 改教材多样性；
   - 改 loss 权重；
   - 改 batch_size；
   - 改 gradient accumulation；
   - 还是只做充分随机化。
5. 有没有办法让“事实多就多抽、事实少就少抽、没有就不抽”稳定共存，而不是依赖某一种样本排列。

请优先阅读论文全文、官方源码和官方训练文档。不要用泛泛的“大模型训练建议”代替这个具体问题。

交付时必须给：
- 已读全文／只读摘要的区分；
- 支持和反对各自的证据；
- 对我们现象最可能的机制，按可信度排序；
- 最多 3 个低成本修正方案；
- 推荐的唯一下一步小实验，并明确只改哪个变量；
- 哪些做法现在不该碰，避免把 Demo 扩成超参数工程。
```

## Q02｜短输出、空答案和中等输出，到底应该怎样配教材？

```text
请深度调查“长文本事实抽取中，空答案、稀疏答案和中等密度答案应该如何设计训练教材”。

共同产品说明已经在本窗口背景中，不需要索取额外材料包。

我们的任务不是普通问答，而是：
- 给一段中文小说正文；
- 抽取会影响后续理解的事实；
- 事实多就应多输出，事实少就少输出，没有符合条件的事实就输出空数组；
- 不能靠缩短最大输出或重复惩罚掩盖过抽问题。

当前教材已经充分教过高密度输出，但长文本中的自然空题、1～3 条题、4～8 条题明显偏少。我们考虑保留旧教材不删，再新增 24 道长文本低／中密度教材。

请研究：
1. SQuAD 2.0、信息抽取、关系抽取、事件抽取中的 no-answer／negative examples，对本任务有哪些可迁移经验。
2. 普通空白段、困难负例、近似正例但条件不成立，三者的教学价值有什么不同。
3. 空答案比例太低或太高分别会产生什么问题。
4. 怎样避免把漏标的正例误当空题，导致模型学会“不抽”。
5. 稀疏正例应该怎样覆盖：
   - 否定；
   - 条件；
   - 说话人归属；
   - 时间不匹配；
   - 实体不匹配；
   - 只是气氛或一次性动作；
   - 远距离上下文看似相关但目标段并不承托。
6. 是否有证据支持“旧高密教材保持不动，只增补多样的低／中密度教材”。

请给出一个可直接用于 24 道新增教材的推荐配额，例如：
- 真空题多少；
- 困难空题多少；
- 2、3、5、8 条事实各多少；
但不要为了数字好看机械平均。

最终请给：
- 推荐分布及证据强度；
- 每一类教材应该教什么；
- 金标审核最容易犯的错误；
- 一张最小验收表；
- 如果论文证据不足，请明确说哪些只是合理工程推断。
```

## Q03｜4B 小模型到底该加教材，还是多训几轮？

```text
请深度调查“小规模、高质量 SFT 数据下，4B 左右模型做结构化事实抽取时，数据量、训练遍数与 LoRA 稳定性的关系”。

共同产品说明已经在本窗口背景中，不需要索取额外材料包。

当前现场：
- 项目原创教材从 24、36、48 增长到 72 道；
- 每道题的答案长度差异很大；
- 训练集很小，曾出现训练 loss 持续下降，但实际测试发生复读、触顶、过抽或归零；
- 我们不想做庞大的超参数搜索；
- 当前倾向是保留旧 72 道，再新增 24 道有针对性的教材，从原始 base 重新训练；
- 目标既是挑结构，也是尽量把 4B 调到可用，未来可能作为低成本免费档模型。

请查：
1. 小数据 LoRA 中，一遍、两遍、多遍训练分别有什么已知风险。
2. 学习率、训练遍数、LoRA rank、dropout，哪些变量对过拟合和遗忘最敏感。
3. 训练 loss 在这种场景下为什么可能完全误导。
4. 增加真正不同的教材，与重复现有教材相比，哪种更可能改善泛化。
5. 数据顺序影响很大时，怎样区分：
   - 数据不足；
   - loss 权重问题；
   - 训练步数问题；
   - 模型容量不足。
6. 对 96 道教材，应该优先一遍高学习率，还是两遍较低学习率；请给可解释的区间，不要假装存在通用神奇参数。

最终只给最多 3 个候选训练配方，并推荐其中 1 个。每个配方写清：
- 从 base 还是续训；
- 大约看几遍教材；
- 学习率；
- 总更新次数；
- 为什么；
- 什么结果出现后必须停止继续加教材或调参。

请优先找 3B～8B 指令模型、LoRA、小数据结构化生成的直接证据。
```

## Q04｜只给目标段、给前后文、给整章，怎样做最干净的对照？

```text
请深度调查“长文本事实抽取中，目标段、局部上下文和整章上下文三种输入范围应如何公平比较”。

共同产品说明已经在本窗口背景中，不需要索取额外材料包。

我们计划比较：
A. 只给目标负责段；
B. 给目标段加固定长度的前后文；
C. 先给完整章节作为只读背景，再在结尾重复一次同一目标段，要求只抽目标段事实。

我们真正关心的是：
- 更多上下文能否帮助指代还原、身份确认和状态理解；
- 更多上下文是否会诱发抽取目标段外事实；
- 哪种结构训练后在格式正确与事实准确之间最好。

请研究：
1. 长上下文信息抽取、needle/context distraction、lost-in-the-middle、局部窗口和全文输入的直接研究。
2. “全文一次＋结尾重复目标段”是否有类似做法，它会帮助定位还是造成重复注意。
3. FULL 与 LOCAL 公平比较时，哪些内容必须完全相同。
4. 共同主分是否应该只评目标段表面可见事实；姓名还原、跨段指代是否应单列附加分。
5. 哪些题型能真正区分三种方案，哪些题无论给多少上下文都一样。
6. 是否必须做 3×3 全组合，还是可以先选正文范围赢家，再在赢家上比较输出格式。

最终请给一套不超过 3 个训练臂＋1 个 base 对照的最小实验，并明确：
- 每臂唯一变化；
- 共同评分；
- 上下文专属诊断分；
- 泄漏与越界抽取门；
- 什么时候可以判断 FULL 没有额外价值。
```

## Q05｜4B 的赢家能不能迁移到 Mini？最小“排名桥”怎么做？

```text
请深度调查“在一个 4B 本地模型上筛选出的 SFT 数据结构和 Prompt 结构，能否迁移到更强的商用 Mini 模型”。

共同产品说明已经在本窗口背景中，不需要索取额外材料包。

项目角色需要分清：
- 4B 不是白训：若调到可用，可作为未来免费档候选。
- 但 4B 也承担低成本淘汰器角色，先排除明显差的训练结构。
- 真正准备给 Mini 微调时，各路线保留下来的教材和格式合同都可能继续使用。
- 我们不能默认“4B 排名第一的结构，在 Mini 上也排名第一”。

请研究：
1. 不同模型规模、预训练底座、指令能力之间，数据配方排名能否稳定迁移。
2. 哪些东西通常比较能迁移：
   - 清洗后的教材；
   - 金标；
   - 输出 Schema；
   - 输入模板；
   - 样本比例；
   - 学习率和训练遍数。
3. 哪些东西最不能直接迁移。
4. 小模型适合作为淘汰器的证据和边界是什么。
5. 怎样设计一座最低成本的“排名桥”：在 Mini 上只复验少量候选，就能判断 4B 排名是否保持。
6. 如果 4B 已经达到可部署水平，如何同时保留其免费档价值，又不让它的结果冒充 Mini 的终局结论。

最终请给：
- 可迁移资产／必须重测参数两张清单；
- 最多 4 个 Mini 复验格；
- 推荐的题量和训练量级；
- 什么情况下 4B 的淘汰结论可以保留；
- 什么情况下必须推翻 4B 排名。
```
