# 58 份外部回包消化稿

## 一句话结论

这些报告没有推翻我们现在的方向。它们最稳定地支持的是：**Prompt 保持极简、目标责任段保持自然完整、前后文只读、证据权只属于目标段；教材和训练器问题分开查，4B 只负责本地筛选和免费档候选，不能替 Mini 选终局冠军。**

外部报告里给出的具体配比、最佳字数、学习率或训练轮数，只能当候选起点，不能直接变成项目规则。

## 2026-08-11 A／B／C 对照前置三包，哪些继续有用

- **API 与微调不是二选一**：先让多步 API 管线证明质量，再看成本、时延和人工灰区是否形成明确瓶颈；只有某个窄步骤标签稳定、可独立验证且有回本空间时，才考虑把它微调进 Mini／Lite。
- **模型筛选不能只排总 F1**：先过结构、截断、证据、时延和成本硬门，再按主抽取、补漏、验真的不同岗位看错误互补。报告给出的具体模型名单早于 A／B／C 和最终筛选，只能当历史候选，不能照单保留或淘汰。
- **多步管线值得测，但尚未被证明**：克制主抽取与盲补漏先形成候选并集，验真器逐条判证据和字段，程序做去重与门控；同模型看旧答案后整表重写不作为默认路线。
- **验真器要看整条管线的净效果**：证据是否支持、产品是否应抽、系统是否自动放行要分开；开发集、校准集、未见确认集也要分开。只看验真器自身 F1、两个模型一致或输出更自信，都不能证明产品改善。
- **数据回流必须保留血缘**：模型与验真器一致只能叫银标候选；只有人工证据裁决或确定性机械检查能升为 Gold。开发集、校准集和未见确认集不能一边选型一边回流训练。

## 2026-08-11 停点15两份方法审查，怎样落到下一步

- **短名单只能用确定性上下界**：已完成块用人工精确整数；未审块只用冻结 Gold 分母、有效预测数和机械确定误报形成最坏／最好边界。机器 strict／lenient 分、部分人工进度和“看起来像命中”的判断一律不进边界。
- **第二块必须整块闭锁**：C01-B03 没有完整派生回执前，局部 200/337、250/337 或后续分波都不能拿来排名。两块仍分不开时，最多补一块预先选定的高信息块，再分不开就转未见确认。
- **失败条件不能从候选表消失**：26 个条件全部保留；人工语义可写 N/A，交付账另记未交付、格式、运输、截断和全部尝试成本。同一模型多个调用档位只占一个短名单席位。
- **A／B／C 首块和格式门要冻结**：所有模型、所有 Prompt 共用同一个首块；格式门只做解析、Schema、最终正文和截断等机械判断，失败臂保留计划行与 N/A，不从总表删除。
- **36／48／60 是真实请求尝试硬顶**：运输失败和授权重试也计数；底层自动重试必须关闭或能逐次回读。B－A 只能解释为例子整包效果，C－B 只能解释为显式尺子整包效果，不能声称纯语义因果。
- **外部建议仍待本地冻结**：具体角色阈值、调用轮换公式、第三块信息价值算法和成本字段没有自动变成项目规则；它们只能进入尚未冻结的短名单派生规则和 A／B／C 派生执行票。

## 2026-08-11 判别卷、调用账与确认卷三份顾问回包

- **`DISCRIM4` 是强淘汰卷，不是头部排名卷**：章节才是独立统计单元，同一章里的块、事实条目和重复调用不能把独立样本数做大。只有 4 章时，两侧精确配对检验即使全同向，最小 `p` 值也约为 0.125，不能声称得到常用 0.05 水平的头部显著性结论。
- **逻辑题目与真实请求必须双账**：每个计划内题目条件记一条 `task`，每次真实发网记一条不可覆盖的 `attempt`；每次重试新建 `attempt`，失败和重试都计真实成本。套餐跨平台比较不能把边际实付 0 元写成成本 0；价格、套餐规则和实际 endpoint 要在运行前重新核验。
- **同一版 `CONFIRM4` 最多一次有决策意义的预登记开封批次**：不能边看边改 Prompt、候选、评分器或门线。披露后按信息粒度降为 `USED_GATE`、`USED_AGGREGATE`、`BURNED_DETAIL` 或 `RETIRED_TO_DEV`；当前没有开封权限，继续封存。

顾问建议中的 12 章确认、业务差异 `ε=0.02`、候选集合在 90% 配对 bootstrap 中稳定、阶段一保留约 5～8 个且最多 10 个条件，都会影响后续草案，但都没有得到 CZ 拍板。其中 12 章方案也超出当前只授权 8 章的范围，不能自动执行。

## 2026-08-12 DISCRIM17 部分盲审试选方法回包

- **默认机械续审继续停止**：225／916 条已接收后，应先算确定性可达边界；不能因为试选器尚未完成就恢复 Wave06～21。
- **重复预测要分“出现数”和“唯一容量”**：两行相同预测不能占两条 Gold。最好成绩必须同时受剩余 Gold、未审出现数和不同预测容量约束，重复出现留下的额外行仍算 FP。
- **三主单元要算同一个可达世界**：不能把不同补全世界里的最好 Precision、Recall 和 F1 拼成一个实际不存在的模型结果。任一主单元交付失败，整组主质量保持不可比较；安全诊断单元不进主分。
- **候选看角色的可能前沿**：综合平衡、克制高精度、补漏高召回、已观察交付／资源四类角色分别算可能前沿与稳健前沿；只有可能前沿的唯一模型组并集恰为 3～5，且外部组都有硬淘汰证书时，才可另提开发候选。
- **缺阈值或费用不是语义问题**：角色门槛、第五席规则、费用或时延账没冻结时，应写非语义阻塞，所有语义行的信息价值为 0；多审几百行不能修好缺账。
- **定向补审不能泄露选中原因**：只有反事实上可能改变候选关系的行才可进入新微批；新审者只看新盐生成的不透明编号，不看模型、臂、角色、聚合或选择理由。
- **报告不等于执行票**：它支持把 R01 试选器退修成 R02，但不授权读取密封映射、真实派生、候选、排名、A／B／C、API、训练或生产晋级。报告里的“累计 R05 尚不存在”已经被随后生成的本地 R05 更新，不能当当前状态。

## 补回历史批次后，多沉淀出的几条

- **评分必须拆层**：语义有没有抽到、JSON／Schema 能不能交付、生成有没有复读或截断，必须分别记账。后续本地实验已经按机械门与盲语义评分分开做，证明这条不是纸面讲法。
- **特殊教材不能只看“缺什么就猛补什么”**：阶段式 SFT 报告早就提醒，第二阶段集中塞特殊样本可能制造近期偏置。它支持的是“保留旧教材、补真正缺课并做混合覆盖”，不是狂加空题或高密题。
- **证据表示是三件事**：证据定位、事实语义、输出格式不能混成一个变量。ID 列表、范围、逐字证据和细单元各自会改变负担；当前 OUT2 ID List 只是本机 DEV 守擂结构，不是通用定论。
- **短块、整章与历史记忆很早就被当成不同路线**：2026-08-02 上下文策略整包已经把短段滑窗、多轮历史、检索与整章输入分开。当前本地结果进一步把它收窄为“完整自然责任段＋只读 Halo”，不是重新发明了一套问题。
- **旧价格和平台能力不当现状引用**：7 月底报告里的 API 缓存门槛、折扣、模型可用性和部署成本全部只作历史材料；真要花钱或选平台时必须重新联网核验。

## 外部报告提出、但被本地结果缩小或否掉的内容

### “8～10 条短规则可能是最佳点”

早期两份报告把短规则书当成有希望的先验，这在当时合理；但项目自己的两轮结果都显示规则增加后召回和 F1 明显下降。现在不再围绕规则条数继续找峰值。除非模型、任务或证据出现实质变化，否则不要重开 R5／R10／R15 梯度。

### “短责任块可能让模型更准”

本地结果已经否定固定短责任块作为默认路线。BLOCK300 只有 8/85 条 Gold 跨块，主要失败并不是切断事实，而是小责任块让模型局部判断失真、漏抽和误报一起增加。BLOCK60 是机械结构退出，不是模型实验失败。

### “只修 loss 就能救 TRAIN96”

本地已经分别跑过按有效 token 聚合与按样本平均，两端出现相反塌陷：一个继续过抽／复读，另一个六题全空。当前 TRAIN96 的 loss／数据／顺序／剂量组合已经停止，不能把报告里的第三种配方、更多轮数或密集 checkpoint 扫描接着补上去。

### “报告给出的教材比例可以直接照抄”

不能。旧教材不该因一次失败被删掉，但新增教材也不能机械凑 75/25、固定空题比例或固定事实数。报告的数字只是工程建议；本地必须先按真实来源、权利、长度、事实密度和 Gold 质量建账，再决定缺什么。

## 仍然开放、值得只做一次的最小问题

当前只剩 EX0 对 EX1：不给示例，和固定放一组两个都正确的对比例。

外部回包帮助修正了 EX1 材料：

- 两个成员应各有多个局部一一对应的状态翻转，不能 A 全是不确定、B 全是已确认；
- 旧示例太短、事实密度太高，容易把输出数量锚到 5；
- 两边应补相同的中性载体文字，让密度接近 DEV24，同时保留同样 5 条事实；
- 反复制门除了禁专名，还要拦“预测事实与示例正文连续 12 个 Unicode 字符重合”。

这只允许做一次材料修订和一次 EX1 的 24 题诊断。无论输赢，都停止继续扩 Prompt 结构，不开示例顺序、示例位置、第三例或动态检索等新臂。

## 长期保留的设计原则

1. **三层分开**：检索块负责找材料；责任核心决定哪里有权产事实；只读 Halo 只帮助理解。
2. **证据防火墙**：人物卡、别名、前态和整章背景可以消歧，不能自己变成当前事实或证据。
3. **自然边界优先**：句子通常不切；自然段、完整句、对话轮只是候选边界；“咚”“嗯”“……”等极短段可并入相邻容器，但保留原坐标和说话人。
4. **一次只改一个变量**：报告可以提出机制，但不能让下一跑同时改教材、顺序、loss、学习率和 LoRA 参数。
5. **4B 与 Mini 分工**：Gold、清洗后的教材、Schema 和证据合同是可迁移资产；4B 上的配方排名、学习率和最佳比例必须在 Mini 上用小规模排名桥复验。
6. **开发集和确认集分开**：DEV24 用于淘汰与晋级；等候选结构全部冻结后，只用一次未见 CONFIRM 做最终确认。
7. **报告不产生权限**：论文、调查报告和聊天建议都不能授权正文使用、训练、API、Notion、Git 或生产晋级。

## 以后遇到相似问题怎么查

- Prompt 规则越加越差：先读 2026-08-10 Q01，再看 RULE 本地结果；不要重开规则数量搜索。
- 示例怎么设计：读 2026-08-08 Q02 与 2026-08-10 Q02；当前只剩固定双成员对比例一次诊断。
- 小说怎么切块：读 2026-08-10 Q03；默认完整自然责任段，不把 RAG 检索块直接拿来当事实责任块。
- 空题、稀疏题、训练塌陷：读 2026-08-09 Q01～Q03；先检查训练器 reduction 和数据账，不凭一次输出狂加空题或高密题。
- 24 题成绩能说明什么：读 2026-08-10 Q04；把它当 DEV 晋级门，不叫生产证明。
- 4B 结论能否给 Mini：读 2026-08-09 Q05 的原问题和本稿；该批当时没有直接回包。另一组产品调查确有“4B→商用迁移”报告，只能作交叉参考，不能倒填成这次 Q05 的回包。
- 多步 API 还是微调：读 2026-08-11 前置 Q02；用质量门、全成本和回本量判断，不因“模型能训”就开训。
- 主抽取、补漏和验真怎么分工：读 2026-08-11 前置 Q01；把三步架构当待证候选，不把具体模型名单当当前结论。
- 验真器怎样证明有效：读 2026-08-11 前置 Q03；看共错、误杀、漏放、拒答和端到端 P/R/F1，不看自信度签票。
- 四章判别卷能说明什么：读 2026-08-11 判别设计回包；只把 `DISCRIM4` 当强淘汰卷，不用同章事实条目虚增独立样本数。
- API 费用、Token、时延和重试怎样留账：读同批双账回包；主对象是不可覆盖的 `attempt`，不是一题只留最终成功结果。
- `CONFIRM4` 何时算用过或烧掉：读同批封存／开封回包；当前仍封存，任何披露与开封都要另有预登记和明确授权。
