再后续三份回包返回于 `FRESH-DISCRIM4` 权利门审查期间，早于任何 `DISCRIM` 正文开封或新的 API 调用。它们会影响判别设计、调用双账和确认卷协议的后续草案，但不自动改路线；`CONFIRM4` 继续封存。

2026-08-12 的一份方法回包审查了 225／916 条裁决下怎样安全停审和试选。它支持继续停止默认机械续审，也要求修补唯一预测容量、可达世界、角色阈值、资源缺口和盲态隔离；它不等于候选已经产生。

## 怎么用

1. 平时先看 [总消化稿](02_RETURNS_DIGEST.md)，这里已经写清哪些结论被本地实验支持、哪些后来被否掉。
2. 要追某个问题，去 [批次索引](BATCH_INDEX.md) 找对应 Prompt 和完整回包。
3. 只有在核论文原句、检查报告是否被误读、或出现新证据冲突时，才重读完整报告。
4. 外部报告只能提供候选解释。训练、模型调用、修改 Prompt、改教材或生产晋级，仍要看现役路线和本地结果票。
