## 结论

你们的结果与已知现象高度一致，但最准确的诊断不是笼统的“提示太长”，而是：

1. **当前原子化规则造成了强烈的 constraint interference 与 over-decomposition。**
2. 它把“事实怎样表达”的局部规则，错误地提升成了“应该抽取哪些内容”的搜索策略。
3. **prompt-induced verbosity 在你们实验中确实出现了，但更准确说是“条目增殖”**；没有总 token 数，尚不能证明普通意义上的冗长。
4. **salience bias 是很合理的机制假设，但还不是你们数据已直接证明的因果。**
5. 当前只能确认“原子规则严重有害”。**不能确认状态规则有害**：它叠加后反而小幅修复了第一条规则。

行动优先级是：

> **撤下当前原子规则 → 审计粒度与 FP 类型 → 补状态规则单独臂 → 测极简合同＋2–4个边界示例 → 测一条改写后的整合规则 → 最后才考虑微调。**

## 先看你们数据真正说明了什么

金标总数三组都是 `TP+FN=280`。

| 提示版本   | 预测条数 | Precision | Recall |     F1 |
| ------ | ---: | --------: | -----: | -----: |
| 极简基线   |  247 |    37.65% | 33.21% | 35.29% |
| 加原子规则  |  324 |    16.98% | 19.64% | 18.21% |
| 再加状态规则 |  315 |    18.73% | 21.07% | 19.83% |

原子规则相对基线：

* 输出条数增加 31.2%
* TP 减少 40.9%
* FP 增加 74.7%
* F1 相对下降 48.4%

这不是“保留原有正确结果，再多输出一些”。它说明新增规则还让模型**重写、拆坏或替换了原本能够命中的事实**。

但第三臂相对第二臂：

* TP：55 → 59
* FP：269 → 256
* 输出：324 → 315
* F1：增加 1.62 个百分点

所以严格的因果结论是：

* 当前“每个 fact 一个核心断言、不同动作/状态分开”写法明显有害。
* 状态规则在原子规则存在时具有轻微纠偏作用。
* 因为缺少“基线＋状态规则”臂，不能判断状态规则单独是好是坏。
* FN 增加只是 `280−TP` 的代数结果，不是一条独立证据。

## 为什么正确规则会变成错误行为

语言模型不是先生成候选、再用规则进行逻辑验证的符号系统。提示中的每条规则都会改变整个输出分布，包括：

* 它注意哪些谓词；
* 它认为多少条输出才算“充分完成”；
* 它怎样划分命题边界；
* 它如何解释状态、否定与嵌套命题；
* 它优先满足“抽取准确”还是“表面上遵守拆分规则”。

一个典型失败链是：

> 原文：“甲承诺明天离开。”

合理的完整事实是：

> “甲承诺明天离开。”

无条件强调“动作、状态分开写”后，小模型可能输出：

1. “甲作出了承诺。”
2. “甲明天离开。”

第一条失去了承诺内容；第二条把“承诺的内容”升级成了已成立事实。如果金标只有完整的承诺事件，这会同时产生：

* 原金标未命中：1 FN
* 两个不完整或错误碎片：2 FP

这正好解释“输出更多，TP 却更少”。在语义学上，计划、承诺、相信、误信、否认、条件等都是作用于嵌入命题的算子；把算子和命题拆开，经常会破坏作用域。

第二条状态规则可能略微修复了这种“嵌入命题被升级为事实”的错误，因此第三臂比第二臂稍好。

## 规则长度、位置、正负措辞与字段怎样互相干扰

### 1. 长度不是核心变量，“独立控制目标的数量”更重要

最新的自明约束实验做了等长控制：冗长但不增加新控制目标的改写几乎不伤任务；真正加入约束才显著降低核心任务保持率。因此“极简”应理解为：

> **减少需要模型同时优化的独立决策，而不只是减少字符数。**

[[On the Paradoxical Interference between Instruction-Following and Task Solving](https://arxiv.org/html/2601.22047v1)](https://arxiv.org/html/2601.22047v1) 还发现，约束满足率可以超过 94%，同时核心任务保持率只有约 84%——模型可能“看起来更遵守规则”，实际答案却更差。该论文是 2026 年预印本，任务不是抽取。

### 2. 规则位置确实重要，但不存在通用最佳顺序

[[Order Matters](https://aclanthology.org/2025.findings-acl.646/)](https://aclanthology.org/2025.findings-acl.646/) 在 Qwen2.5-7B、Llama3-8B、Mistral-7B 等模型上，仅改变七条约束的顺序，就能产生约 5–7 个百分点差异；但不同约束类别存在例外。

所以不能直接照搬“重要规则放最前”或“难规则放最后”。对你们更合理的是：

* 任务的**选择边界**只出现一次，放在最前；
* 示例紧跟选择边界；
* 字段与序列化格式放后面；
* 候选提示确定后，再单独做一次前置/后置 A/B。

### 3. “正向命令优于禁止命令”不是小模型抽取中的定律

你们两条失败规则本身已经是正向命令。现有可控研究不足以证明正向措辞在所有小模型抽取任务上更好；[[C-ICL](https://aclanthology.org/2024.findings-emnlp.590.pdf)](https://aclanthology.org/2024.findings-emnlp.590.pdf) 反而表明，在 CodeLlama 7B/13B/34B 的 NER、RE 中，正确示例配合 hard negative 示例优于只给正例。

因此应优化的是：

* 条件是否可操作；
* 是否定义了完整命题边界；
* 是否给出正反最小对照；

而不是机械地把“不要”全部改成“必须”。

[[OpenAI](https://developers.openai.com/api/docs/guides/prompt-engineering)](https://developers.openai.com/api/docs/guides/prompt-engineering) 和 [[Anthropic](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices) 都建议展示期望输出和少量多样示例，但这是大厂工程指导，不是针对未微调 4B 的受控科学结论。

### 4. 字段说明会隐式定义候选空间

当提示反复列出“计划、承诺、推测、误信、否认”时，小模型可能把这些类别理解成“应该主动寻找并输出的五类对象”，而不只是“遇到时保留作用域”。

这是 salience/candidate-expansion 假设，目前尚无完全同构论文直接证明。不过你们三臂的字段和格式相同，因此字段本身不能解释组间差异；它只能与新增规则发生交互。

机械工作应尽量交给程序或约束解码：

* JSON 是否合法；
* 字段是否齐全；
* 枚举值是否合法；
* 重复项和明显格式错误。

模型提示主要保留“什么值得抽、一个完整事实怎样定义”等语义合同。这也与现有项目中“模型负责语义选择、程序负责格式与证据检查”的职责划分一致。

## 下一步最合理的实验顺序

### 1. 立即撤下当前原子规则

生产候选先回到极简基线。这个决定来自你们自己的同模型配对实验，比任何外部论文都更直接。

这不是否定“原子事实”的概念，而是否定当前这句无条件拆分指令。

### 2. 先审计 FP，不要把 FP 全叫“幻觉”

至少区分：

1. 原文完全不支持；
2. 原文支持，但不属于登记范围；
3. 重复输出；
4. 一个金标事实的拆分碎片；
5. 主体、动作或对象被改坏；
6. 计划、否认、误信等被升级成已发生事实。

建议同时报告三套指标：

* 严格合同 F1：保持当前一对一粒度；
* 重组后内容覆盖：允许多个碎片共同覆盖一个金标；
* 原文支持精确率：判断输出是否真正有正文证据。

如果重组后覆盖明显恢复，说明 evaluator 粒度放大了损失；如果仍然很低，才是实质语义能力下降。

### 3. 只补一个“状态规则单独”臂

当前实验是一个缺一格的 2×2：

|       |   无状态规则 |         有状态规则 |
| ----- | ------: | ------------: |
| 无原子规则 |   已有：基线 | **缺失：状态规则单独** |
| 有原子规则 | 已有：原子规则 |        已有：两规则 |

补这一臂后才能判断状态规则的主效应和两条规则的交互。

### 4. 测“极简合同＋2–4 个 minimal-pair 示例”

不要把示例追加到旧规则堆上。以基线为起点，示例至少覆盖：

* 复杂句但应保持一个完整 fact；
* 真正包含两个独立事实、应该拆分；
* 计划/承诺/否认/误信与已发生事实的最小对照；
* 一个有很多动作词但应输出空集或极少事实的 hard negative。

例如：

* “林舟计划明天离城。” → 一条“林舟计划明天离城”，不可另写“林舟明天离城”。
* “次日，林舟已经离城。” → 一条已发生事实。
* “林舟交出钥匙，并告诉阿禾暗门密码。” → 若两者都符合登记标准，拆为两条。

### 5. 如果保留文字规则，改成“先选后拆”

可测试下面这条整合规则：

> 先按登记标准决定抽取哪些事实，再组织输出。每条 fact 必须是正文支持的完整主张；计划、承诺、推测、相信、否认等限定与其内容保留在同一条。只有两个部分能分别独立判真，并且各自都应登记时，才拆成两条。

它与原规则的关键区别是：

* 抽取集合由任务目标决定；
* 拆分只是表达方式；
* 拆分不得创造新的事实候选；
* 状态算子和嵌入命题保持作用域。

然后做 `改写规则 × 示例` 的 2×2：

|       |    无示例 |   有相同示例 |
| ----- | -----: | ------: |
| 无改写规则 |     基线 |  示例单独效果 |
| 有改写规则 | 规则单独效果 | 规则＋示例交互 |

### 6. 微调排在最后

现在不建议因为这 24 题直接进入微调：

* 金标事实粒度还没有被审计；
* 状态规则的单独效果未知；
* 当前 24 题已经成为 prompt 开发集；
* 用不稳定合同微调，会把当前歧义固化进模型；
* 低量、低多样性的 guideline 训练本身可能继续降分。

微调的进入条件应是：

* 事实单位和 scorer 政策已经冻结；
* 极简＋示例在独立盲测集上仍稳定失败；
* 错误集中在可重复的边界类型，而不是随机格式问题；
* 训练数据包含正例、空例、近似负例、模态最小对照和过度拆分反例。

训练目标应是完整的“正文→正确输出”映射及 hard negatives，而不是让模型背诵更多孤立规则。GoLLIE 支持“专门训练后规范可以有效”，但不支持“给当前 4B 再堆规则就会自然学会”。
