## 结论

**强假设不成立，弱假设成立。**

| 假设                                                   | 判定                     |
| ------------------------------------------------------ | ------------------------ |
| 主流 LLM 认识 Big Five、MBTI、依恋、自恋等常见术语     | ✅ 基本成立               |
| 一个标签能让模型短篇、单轮地表现出可辨认的人格风格     | ⚠️ 部分成立，且容易刻板化 |
| 一个标签能稳定决定跨场景、跨关系、长行为链             | ❌ 现有证据不支持         |
| 可直接用心理标签判定角色行为“一致/崩人设”              | ❌ 假阳性风险很高         |
| 标签配合触发情境、动机、历史选择和例外，可提高推演质量 | ✅ 这是更可靠的路线       |

因此，你当前产品里“**标准标签可解析，当行为约束**”这句话建议改成：

> **标准心理标签是模型可识别的软先验和编辑索引；只有展开后的情境—动机—行为规则，以及角色已经做过的选择，才参与行为推演和一致性检查。**

## 1. LLM 到底懂不懂心理学与人格

需要区分四个能力层级：

1. 知道概念定义；
2. 会填人格量表；
3. 能写出“看起来像某人格”的短文本；
4. 能跨情境、长程地维持同一角色的因果逻辑。

目前证据在前两层较强，到第四层明显下降。

| 研究                | 测了什么                                               | 关键结果                                                     | 对产品的意义                                                 |
| ------------------- | ------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| CPsyExam            | 22,000 道中文心理学题、39 个学科，分别测知识与案例分析 | GPT-4 等模型的心理知识成绩明显高于案例推理；心理学专门微调也没有稳定消除应用差距。[COLING 2025](https://aclanthology.org/2025.coling-main.745/) | “知道理论”不等于会把理论用在复杂人物上。                     |
| ConceptPsy          | 1,383 个心理学概念、4,573 道题，覆盖人格、异常、咨询等 | GPT-4 在人格心理学选择题上表现较高，但不同章节差异很大；题型也不是行为生成。[论文](https://arxiv.org/abs/2311.09861) | 可以证明模型有概念储备，不能证明行为链稳定。                 |
| PersonaLLM          | 用一句 Big Five 人格提示让 GPT-3.5/4 填量表并写故事    | 人格量表变化很大，但故事经常直接复述人格词：GPT-3.5 为 96.56%，GPT-4 为 31.87%；说明其中相当一部分是表面标记和刻板表达。[NAACL 2024](https://aclanthology.org/2024.findings-naacl.229/) | 单标签容易得到“像某标签的文风”，不一定得到深层行为逻辑。     |
| Nature 人格测量框架 | 18 个 LLM、Big Five 测量与人格塑形                     | 部分中大型指令模型可以可靠地向单一人格维度调节；小模型、多特质同时控制更弱。论文也明确提醒量表结果不等于真实行为。[Nature Machine Intelligence 2025](https://www.nature.com/articles/s42256-025-01115-6) | Big Five 是目前最可控的标准词汇，但控制能力有模型和配置依赖。 |
| BIG5-CHAT           | 10 万条人类人格表达对话                                | 用人类行为数据训练的方法优于只靠人格描述提示，后者容易失真、表面化。[ACL 2025](https://aclanthology.org/2025.acl-long.999/) | 示例和历史行为比标签本身更值钱。                             |
| BehaviorChain       | 1,001 个文学人物、15,846 个行为、每条链 10–20 步       | 即使输入详细人物档案和历史，最好模型的平均链分仍低于 0.62，整链累计分低于 0.21；前一步选错还会造成后续滚雪球。[ACL 2025](https://aclanthology.org/2025.findings-acl.813/) | 这是对“挂标签即可稳定跑剧情”的最直接反证。                   |
| LifeChoice          | 1,401 个小说关键选择                                   | 单靠人物描述约 60%；加历史记忆约 71%；检索与当前情境相关的人格记忆后约 77%。[EMNLP 2025](https://aclanthology.org/2025.findings-emnlp.813/) | 当前情境和相关记忆比更抽象的人格标签更能预测选择。           |

现有 persona consistency 基准包括：

- **InCharacter**：32 个角色、14 套心理量表、18,304 段访谈。平均单维匹配约 78.9%，但完整人格画像只有约 58.5%；其输入是丰富角色描述和记忆，不是裸标签。[ACL 2024](https://aclanthology.org/2024.acl-long.102/)
- **CharacterEval**：77 个中文角色、1,785 组多轮对话、13 项指标，检查知识、风格、行为和角色一致性。[ACL 2024](https://aclanthology.org/2024.acl-long.638/)
- **PersonaGym**：200 个人设、10,000 个问题，分别测预期行动、行动理由、语言习惯、一致性和风险控制；模型更大更新并不保证 persona 更好。[EMNLP 2025](https://aclanthology.org/2025.findings-emnlp.368/)

**没有找到**把 Big Five、MBTI、九型、依恋、临床标签放在同一批小说情境、同一模型和同一指标下做的可信横向实验。封闭模型的训练语料分布也未公开，因此不能把“网上 MBTI 内容多，所以模型最懂 MBTI”写成实证结论。

## 2. 哪套体系最值得用

这里要分别看“心理学效度”和“LLM 可操作证据”。

| 体系                    | 心理学效度                                                   | LLM 实测覆盖                                           | 推荐用途                                                     |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------ | ------------------------------------------------------------ |
| **Big Five**            | 最强，适合描述长期平均倾向，但不能决定一次具体行动。[BFI-2 验证](https://pubmed.ncbi.nlm.nih.gov/27055049/)、[特质—情境研究](https://journals.sagepub.com/doi/abs/10.1111/j.0963-7214.2004.00280.x) | 最丰富                                                 | **主骨架首选**。用连续分值和关键细分面，作为概率先验。       |
| **依恋焦虑 × 依恋回避** | 有实证基础，但应当是两个连续维度，不是硬分四型；研究者明确指出不存在天然、唯一正确的分类线。[ECR-R 官方说明](https://labs.psychology.illinois.edu/~rcfraley/measures/ecrr.htm) | 少而且表现不均；InCharacter 中依恋焦虑明显比回避难复现 | **关系专用模块**。必须绑定恋人、父母、导师等具体对象。       |
| **MBTI**                | 四个连续量表能捕捉部分人格差异，但“16 个真实类型”和硬二分缺乏支持。[McCrae & Costa](https://pubmed.ncbi.nlm.nih.gov/2709300/) | 模型通常认识，量表和文本分类研究很多；长程行为证据弱   | 保留作**用户展示、检索和创作快捷词**，不能作真值或硬约束。   |
| **九型人格**            | 104 个独立样本的系统综述发现可靠性、效度证据混合；因素分析通常得不到九个因素，也没有聚类自然推导出九型。[系统综述](https://pubmed.ncbi.nlm.nih.gov/33332604/) | 几乎没有可靠的标签→行为基准                            | 九型编号不进执行层；把其中的“核心恐惧/欲望”拆成角色自己的动机。 |
| **临床倾向/NPD 等**     | 诊断要求长期、广泛、僵化并造成痛苦或功能损害；同一诊断内部差异很大。[AMPD 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC7529724/)、[NPD 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC10187400/) | 模型认识术语，但容易把黑暗人格压成同一条“坏人轴”       | 默认不用诊断名驱动剧情；改为羞耻敏感、夸大、权利感、寻求赞赏、低共情等可观察维度。 |
| **精神分析概念**        | 更像解释框架，概念的可检验性和流派差异较大                   | 未找到可靠的“精神分析标签→角色行为”基准                | 可选作作者灵感，如否认、投射、反向形成；必须展开成具体触发和反应。 |

一句话排序：

> **机器实测基础：Big Five ≫ MBTI ＞ 依恋/黑暗人格 ＞ 九型与精神分析。**
> **科学效度：Big Five ＞ 依恋维度 ＞ MBTI/九型；临床诊断不属于普通创作标签。**

这里的“Big Five 第一”是指**证据最多、最可审计**，不是指裸 Big Five 标签已经可以稳定生成剧情。

## 3. Character.AI 类产品实际怎么做

成熟实践普遍采用“结构化骨架＋自然语言行为逻辑＋示例”，而不是纯标签。

Character.AI 2026 年官方指南建议：

- 身份、人格、说话方式、行为规则、形成性经历、关系和示例对话分开写；
- “友好、复杂、焦虑”等形容词不够，要写具体如何思考和反应；
- 一段好示例比一段形容词更能教会模型；
- 用 2–3 段紧张、日常、意外情境的不同示例；
- 把规则与例外写在一起；
- 情绪逻辑通常比“永远不得……”更稳定；
- 重要内容放前面，集中而清楚的定义优于无限堆字。[Character Definition](https://support.character.ai/hc/en-us/articles/50609183646875-5-Character-Definition)、[Templates and Examples](https://support.character.ai/hc/en-us/articles/50609592926235-9-Templates-and-Examples)

官方对格式的结论也很明确：纯 PList 容易机械、扁平；纯示例难编辑且可能过拟合；**短结构字段＋散文逻辑＋对话示例的混合形式最可靠**。[官方模板说明](https://support.character.ai/hc/en-us/articles/50609592926235-9-Templates-and-Examples)

SillyTavern 的实现也说明了运行时差异：

- `description/personality/scenario` 通常每轮常驻；
- 开场只出现一次；
- 示例会随着上下文变长被挤出去；
- 可在靠近最新消息的位置重新注入关键行为；
- 角色卡越长，占用的对话记忆越多。[SillyTavern Character Design](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)

社区常见的 `PList + Ali:Chat` 原则——属性表存硬信息、示例展示性格如何变成语言和动作——可以参考，但不是受控实验。[Pygmalion 社区指南](https://wikia.schneedc.com/bot-creation/trappu/creation)。目前没有可信证据证明 W++、JSON、伪代码或纯散文在所有模型上普遍最好。

即使角色卡写得很好，漂移、遗忘、重复、最近对话覆盖旧设定以及模型版本变化仍然存在；Character.AI 官方也把这些列为固有限制。[测试指南](https://support.character.ai/hc/en-us/articles/50609303987099-6-Refining-and-Testing-your-Character)、[限制说明](https://support.character.ai/hc/en-us/articles/50609614596251-10-Troubleshooting-and-Limitations)

## 4. 推荐的“角色心理字段”

建议拆成七层：

| 层       | 字段                                                 | 用法                             |
| -------- | ---------------------------------------------------- | -------------------------------- |
| 展示标签 | `INFP`、`九型4`、`焦虑型`                            | 仅用于作者输入、检索、筛选和解释 |
| 人格基线 | Big Five 0–100＋2–4 个关键细分面                     | 软先验，描述角色长期平均倾向     |
| 动机引擎 | 核心欲望、核心恐惧、要保护的自我形象、禁忌、长期目标 | 决定角色为什么行动               |
| 关系模式 | 对目标角色的依恋焦虑、依恋回避、信任、权力差         | 按角色 ID 存，不能全局化         |
| 情境签名 | 触发→解释→眼前目标→默认反应→升级→缓和→例外           | 真正供行为推演使用               |
| 行为证据 | 已发生选择、原文锚点、作者确认、反例                 | 优先级高于理论标签               |
| 动态状态 | 当前情绪、知情范围、受伤、债务、关系变化、眼前困境   | 每个场景重新编译                 |

统一写法可以规定为：

> **维度＋强度＋适用对象/情境＋角色如何解释＋眼前目标＋可观察行为＋升级/修复路径＋例外＋历史证据。**

例如，不要只写：

```text
INFP；焦虑型依恋；NPD 倾向
```

应写成：

```text
展示标签：INFP、焦虑型依恋（仅检索）

人格基线：
负性情绪 80；外向 25；尽责 70

关系模式：
对 CH-002：依恋焦虑 80，依恋回避 20

核心动机：
想被确认不可替代；最怕在重要关系中被悄悄放弃。

情境签名：
触发：CH-002 冲突后迟迟不回复。
解释：把模糊沉默理解为准备离开。
眼前目标：确认关系仍然存在。
默认行为：先发试探消息，再主动道歉；仍无回应时转为指责。
语言表现：不说“我害怕”，而说“你是不是早就不想来了？”
例外：工作关系中不会出现同等强度；涉及弟弟安全时会直接开口。
证据：第 12 章发生过一次相同选择，作者已确认。
```

## 5. 一致性检查怎么判

不要输出“符合 INFP／不符合 INFP”。建议输出四档：

1. **有既有事实或选择直接支持**
2. **符合当前情境下的默认倾向**
3. **属于可解释偏离，但需要补充压力、诱因或角色成长**
4. **与作者确认规则或已发生事实硬冲突**

执行优先级应是：

> 世界事实与角色知情范围 ＞ 已发生且确认的选择 ＞ 当前目标和关系状态 ＞ 情境签名 ＞ Big Five 等特质 ＞ MBTI/九型等展示标签。

**任何单一心理标签都不能独立触发“硬冲突”告警。**
角色偶尔“反常”本来就是正常人格现象；人格研究认为特质更接近长期行为分布，而非每一次行为的固定规则。[Whole Trait Theory](https://pmc.ncbi.nlm.nih.gov/articles/PMC4472377/)、[CAPS 情境签名理论](https://pubmed.ncbi.nlm.nih.gov/7740090/)

这也意味着角色成长、伪装、极端压力和有意反常不能被系统误判为“人设崩了”。

## 6. 上线前的最小实测

建议做四臂盲测，而不是继续凭理论判断：

- A：标签名；
- B：标签＋一句通俗定义；
- C：连续人格维度＋核心动机＋情境签名；
- D：C＋两条历史选择＋一条例外。

对同一批角色使用：

- 日常、利益冲突、亲密关系、公开羞辱、突发危险等未见场景；
- 至少三个模型家族、三个随机种子；
- 单步选择和 10 步连续行为链；
- 作者盲评，不让评审看到采用了哪种卡。

核心指标：

- 不同种子、不同模型是否得到相近的行为逻辑；
- 是否根据情境合理变化，而不是机械重复一个人格动作；
- 长链中一致性衰减速度；
- 刻板化率；
- 作者认可度；
- 一致性检查的误报率。

依据现有研究，预计 **A 能生成“像标签”的短文本，C/D 才可能对剧情选择有实用价值**；尤其是 D 中的相关历史选择，会比再增加几个心理标签更有效。[BIG5-CHAT](https://aclanthology.org/2025.acl-long.999/)、[LifeChoice](https://aclanthology.org/2025.findings-emnlp.813/)、[BehaviorChain](https://aclanthology.org/2025.findings-acl.813/)

最终拍板：

> **保留心理标签字段，但把它降级为展示层和软先验。执行层采用“大五连续维度＋关系专属依恋维度＋核心欲望/恐惧＋情境签名＋历史选择”；MBTI/九型只作作者语言，临床诊断名默认不进执行提示。**
