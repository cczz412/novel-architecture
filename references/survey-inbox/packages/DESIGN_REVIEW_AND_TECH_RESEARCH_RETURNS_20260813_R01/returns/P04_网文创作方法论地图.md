# 网文创作方法论地图 R01

> 用途：AI 辅助网文创作产品“写作技巧插件”的内容原料库  
> 调查日期：2026-08-13  
> 范围：中文长篇网文，重点参考起点／阅文、番茄、17K；用叙事学与通用商业小说方法补足底层原理  
> 边界：只给结构、触发条件、检查项和抽象正反例，不生成可直接拼接为书稿的示范句

## 先看结论

1. **不存在业内公认的“30 种爽点标准目录”。**可核实的材料采用不同维度：17K 编辑课分“反击、获取、荣耀、感动”，论文分“占有、畅快、优越、成就”，各题材课再分打脸、马甲、团宠、系统奖励等。本报告的 30 类是跨来源重组的教学地图，不是伪造的行业标准。
2. **伏笔没有通用的“几章必收”规则。**回收期取决于它是章末问题、局部线索、阶段谜团还是全卷承诺。网上常见“3—5 章收小伏笔”可以拿来做测试默认值，不能标成平台定律。
3. **“同时挂几个悬念”也没有经验证的网文数字。**更稳的做法是前台维持“1 个主问题＋1—2 个近端问题”，其余长线进入后台，靠阶段提醒重新升温。这是产品启发式，不是由“工作记忆 3—4 块”直接推导出的科学结论。
4. **2000—4000 字更接近常见发布单位，不是剧情结构单位。**一章可含一个场，也可含多个场；关键是本章让读者感到目标有推进、情绪有变化，并留下明确的下一步。
5. **“三章一小爽、五章一大爽”查不到权威首创者。**目前可追到的较早公开文本是 2017 年玄派文章，原文也只称“网文中有一种说法”。公开作者经验还存在“每章小反馈、十章大爽”“每天小高潮、每周大高潮”“10 万字小高潮、20—30 万字大高潮”等明显冲突的变体。
6. **版权上可以学习方法，不能搬课程表达。**通用思想、步骤概念通常不由版权垄断，但课程文字、图表、案例、独特命名、选择编排和练习可能受保护。商业插件不应把“教学用途”当作当然免责。

## 标注说明

**来源强度**

- `A`：直接来源——平台官方／编辑指导、作者本人公开课或第一人称访谈、法律与权利人页面。它能证明“该主体明确这样说”，不自动证明全行业都适用。
- `B`：可靠二手——学术论文、正规出版社资料、专业媒体或叙事学资料。
- `C`：可追溯经验——平台承载的个人作者课、公开社区经验；适合作为候选经验，不宜包装成共识。
- `D`：网络流传或本报告综合推导——可试验，不可写成事实定律。

来源编号（如 `A02`、`FS7`）只是稳定检索键，首字母不代表证据等级；以每条“强度”和来源目录中 `｜A/B/C/D｜` 的显式标注为准。

**版权处理**

- `🟢`：通用原理或多源独立归纳，可用自己的结构和原创例子重写。
- `🟡`：有明确提出者、独特名称或成体系模型；应归因，不能复制其目录、图、原例和练习。
- `🔴`：完整课程、讲义、视频、逐字稿、付费内容或独特编排；未经许可不要直接改编进商业插件。

以下所有正反例均为本报告原创的抽象例子，不摘录小说原文。

# 一、爽点类型学：30 个可独立教学组件

## A. 反压、纠偏与公正释放

### S01 当众打脸

构成要件是对方先作出可理解但错误的判断，主角随后用事实、能力或证据推翻判断，而且原见证者能看到结果。铺垫要建立被轻视的原因与公开评价场。正例：被嫌资历浅的人现场解决全组难题；反例：陌生人无故辱骂，主角亮张卡，全员立即下跪，像作者摆拍。  
来源：`A01` 17K 编辑课、`A03` 阅文期待感作者课；强度 A+C；版权 🟢。

### S02 扮猪吃虎

核心是实际能力被低估、对手据此轻敌、读者知道或怀疑主角更强，并存在合理的隐藏动机。爆发最好只暴露解决当前问题所需的部分。正例：为查内鬼暂装新人，危机时显露一项专长；反例：明明一招能解决，却故意挨骂十章，只为拖到露脸，主角反显得愚蠢。  
来源：`A02` 阅文专项作者课、`B01` 海南大学论文；强度 B+C；版权 🟢。

### S03 绝境反杀

先让失败可能、倒计时和资源短缺都真实成立，再让主角调用此前出现过的能力、情报或地形完成翻盘，并支付相称代价。正例：退路被封后利用早先发现的结构弱点；反例：写到必死时突然天降神器或陌生高手。没有前置因果的“反杀”只是机械救场。  
来源：`B02` 中国作家网爽感分析、`C02` 阅文高潮课；强度 B+C；版权 🟢。

### S04 多层打脸／靠山反转

小反派失利后调用更高权力，冲突从个人争执升级为制度、资格或阵营判断；更高层又验证主角的位置或证据。每层必须带来新风险和新信息。正例：争议逐级上报，终审人认得关键旧案；反例：五个角色轮流喊“你知道我是谁吗”，只有人数增加，没有矛盾升级。  
来源：`B02` 中国作家网爽感分析；强度 B；版权 🟢。

### S05 复仇清算

需要明确的伤害、责任主体、未结债务和与伤害相称的回收；最好同时改变人物关系或旧秩序。正例：受害者逐步取证，使幕后者失去其靠不公获取的权力；反例：先把主角虐至失去人格，再随手杀光所有敌人。只有酷刑升级、没有价值重建，容易从解气滑向猎奇。  
来源：`A01` 17K 编辑课、`B02` 中国作家网；强度 A+B；版权 🟢。

### S06 洗冤昭雪

先写清冤案造成的资格、关系或名誉损失，再设置证据缺口与阻挠者。回收应由证据链、公开裁决和现实补偿共同完成。正例：旧账、证人和时间线互相印证；反例：真凶忽然良心发现，一句认罪便让所有人忘记此前伤害。昭雪若没有公共纠偏，只是私下知道真相。  
来源：`A01` 17K 编辑课；强度 A；版权 🟢。

### S07 罪有应得／规则反噬

爽感来自反派被自己利用的规则、谎言或贪欲反噬，而不是主角任意施虐。正例：造假者最终因伪造数据失去强抢来的项目；反例：轻微过错配上极刑，或主角伤及无辜仍被文本叫好。惩罚与过错不相称时，读者会把道德债转记到主角头上。  
来源：`A01` 17K 编辑课、`B01` 爽感论文；强度 A+B；版权 🟢。

### S08 身份揭露／掉马

前文应通过能力、关系、称谓或异常反应留下可回看的线索；揭露既解决眼前冲突，也增加责任、敌人或关系变化。正例：匿名专家在危机中被迫实名；反例：主角有十几个毫无因果的顶级身份，遇事就掉一个。身份若只是无限通行证，很快会取消所有难题。  
来源：`A04` 番茄马甲赛道指导、`A01` 17K 题材课；强度 A；版权 🟢。

### S09 越级挑战

先让等级差与强敌可信，再说明越级凭据是克制关系、情报、环境、一次性资源或高代价技能。正例：弱者抓住规则漏洞，以不可复用的手段险胜；反例：世界反复强调差一级如天堑，主角却靠“更愤怒”随手取胜。规则一旦为主角让路，后续升级也失去意义。  
来源：`A05` 17K 玄幻课、`A06` 老鹰吃小鸡访谈；强度 A；版权 🟢。

### S10 智谋反转／智性破局

决定性线索应在读者视野内，只是当时被解释成别的含义；回收时重组已知信息，而非补发秘密设定。正例：主角利用公开流程让对手自行暴露；反例：结尾才说主角早有一位从未出现的同伙。公平信息下的再解释带来智性爽感，藏住答案只像作者耍赖。  
来源：`B05` 悬念／惊奇叙事学、`A07` 番茄钩子课；强度 A+B；版权 🟢。

### S11 暗爽／迪化误会

读者知道真相，配角却依据自身知识把普通行为误解为高深布局，由信息差制造喜剧和优越感。误会必须符合配角的利益、经验与证据。正例：随口提醒正中对方隐秘焦虑；反例：所有聪明人长期把常识当神谕，只负责吹捧主角。误会若不能自洽，就是集体降智。  
来源：`C03` 阅文期待感／作者经验、`B02` 中国作家网；强度 B+C；版权 🟢。

## B. 成长、能力与掌控

### S12 废柴逆袭

先建立低起点、被排除的具体机会和可持续成长机制，再用多个阶段结果验证变化。正例：无法使用通用术式的人找到另一条训练路径，先赢小考再进核心赛；反例：第一章受辱、第二章无敌，之后只能不断更换更蠢的反派。没有过程的逆袭只剩身份翻牌。  
来源：`A05` 17K 玄幻课、`B01` 海南大学论文；强度 A+B；版权 🟢。

### S13 升级突破

升级不只是数值变大，还应解锁新能力、资格、地图、责任或选择成本。正例：突破后终于进入此前看得见却进不去的区域，同时承担新规则；反例：境界名称不断上涨，战斗方式和处境完全不变。等级通胀、频繁重置和换地图再装新人都会稀释成就。  
来源：`B01` 爽感论文、`B03` 升级机制研究、`A05` 17K 玄幻课；强度 A+B；版权 🟢。

### S14 实力碾压／无敌展示

适合在长期铺垫后快速兑现，让读者确认此前建立的强大真实有效。正例：高手面对已熟悉的低阶问题干净解决，并让剧情转入更高难题；反例：每战一招结束，所有对手只负责震惊。碾压过密会消灭危险、策略与成长，只能偶尔当结算，不宜当全书发动机。  
来源：`A01` 17K 爽点课、`B02` 中国作家网；强度 A+B；版权 🟢。

### S15 专业能力封神

通过具体任务展示主角比合格同行高明在哪里，过程须能被读者理解，同行也要基本称职。正例：医生从矛盾症状中排除错误诊断，并承担治疗风险；反例：堆一串术语便宣布主角天下第一，同行全是外行。专业爽依赖可验证的判断链，不依赖作者封号。  
来源：`A06` 老鹰吃小鸡访谈、`A01` 荣耀爽点课；强度 A；版权 🟢。

### S16 事业崛起／发财

建立市场、资源、竞争和阶段目标；财富或事业成果到手后应立刻改变人物能做什么、不能做什么。正例：第一桶金买到关键设备，也引来更强竞争者；反例：系统账户每天多几个零，人物生活、关系和风险毫无变化。只有“得到”没有“使用”，很快会变成财务报表。  
来源：`A01` 获取爽点课、`A08` 番茄神豪课；强度 A；版权 🟢。

### S17 夺冠登顶／成就达成

预先给出清晰目标、评价标准、可信对手与主角短板，胜利才有重量。正例：主角针对短板调整策略，以微弱优势完成阶段目标；反例：比赛临时改成主角唯一擅长的项目，评委集体失去判断。荣耀要由可信制度或重要关系授予，不能靠旁白宣告。  
来源：`A01` 17K 成就／荣耀课；强度 A；版权 🟢。

### S18 改写命运／弥补遗憾

重生或先知优势用于修正旧选择、救回重要关系或避开灾难，同时世界会因干预产生新变量。正例：主角知道灾难将来，却必须重新说服不信任他的人；反例：按前世清单抢光资源，旧敌仍照剧本排队送头。未来不发生变化，所谓改命只是在复读攻略。  
来源：`B02` 中国作家网、`A09` 17K 古言／重生邻近题材指导；强度 A+B；版权 🟢。

### S19 基建／群体改善

爽点落在普通人生活的前后对照：安全、食物、交通、组织效率等真实改善；主角提供方法，群体也参与、质疑和付出。正例：水利工程让村民首次不必旱季迁走；反例：主角念出现代名词，古人立即造出完整工业体系并齐声歌颂。只有宏大指标，没有人的变化，就不落地。  
来源：`B04` 中国作家网作者自述、`B01` 种田／升级讨论；强度 B；版权 🟢。

## C. 获得、占有与信息优势

### S20 金手指觉醒

明确能力、触发条件、限制、代价及它与主线的关系；能力最好制造新选择，而非替人物取消选择。正例：能力只能读取物品一次过去，主角必须挑使用时机；反例：系统随时提供答案、战力、金钱和复活，冲突一出现就被抹平。好的金手指生产故事，不是关闭故事。  
来源：`B01` 海南大学论文、`A10` 17K 脑洞开篇课；强度 A+B；版权 🟢。

### S21 系统即时奖励

基本循环是目标—行动—反馈—奖励—再利用，奖励要能改变下一步选择或引发新成本。正例：完成救援得到一次定位机会，主角必须决定救谁；反例：每章弹窗发十件道具，入仓后再不用。提示音只是包装，读者真正等待的是奖励如何兑现、组合和反噬。  
来源：`A08` 番茄系统／神豪课、`A01` 获取爽点课；强度 A；版权 🟢。

### S22 奇遇／传承

偶然相遇后仍要有选择、考验、限制或代价，才能从掉馅饼变成情节。正例：获得残缺传承，却必须在三条互斥道路中择一；反例：走路捡神器、落崖遇祖师、睡醒得血脉连续出现。好运过密会让努力、判断和世界规则都不再重要。  
来源：`C04` 阅文网文入门经验、`B01` 爽感论文；强度 B+C；版权 🟢。

### S23 寻宝捡漏／稀缺资源

先说明资源为何稀缺、解决什么问题、还有谁在争，并在获得后尽快展示用途。正例：不起眼的旧零件补上设备唯一缺口；反例：作者只说“万年难遇”，但无人争、无人识、拿到也没用。稀缺性要由世界行动证明，“获取”本身只是兑现的准备阶段。  
来源：`A01` 17K 获取爽点课；强度 A；版权 🟢。

### S24 信息差先知／穿越优势

交代知识从哪里来、在哪些条件下有效，并让世界在主角干预后发生偏移。正例：主角熟悉旧历史，但第一次改变事件后未来开始失真；反例：现代人凭常识全面碾压古代所有专业者。信息差若靠贬低整个世界维持，只会让胜利显得廉价。  
来源：`B02` 中国作家网、`A09` 17K 古言／重生邻近题材指导；强度 A+B；版权 🟢。

## D. 社会回馈与情感满足

### S25 群体认可／荣耀

铺垫要建立评价者、评价标准和主角真实贡献；认可最好改变信任、资格或责任。正例：原本怀疑他的团队主动把关键位置交给他；反例：主角做件普通小事，陌生群众便自发欢呼。17K 把这类爽点概括为“被认可、被喜欢、被需要”，但不能把原课整套表达直接搬入插件。  
来源：`A01` 17K 编辑课；强度 A；版权 🟡（抽象原则可用，课程表达不可搬）。

### S26 众人震惊／围观见证

这是爽点放大器，不宜单独当剧情。围观者应因专业、利益和旧立场不同而产生不同反应。正例：同行沉默复盘、旧对手改变态度、外行后知后觉；反例：每次都“全场死寂、倒吸凉气、集体跪拜”。重复震惊会把配角写成观众席道具，也让主角的成就失去刻度。  
来源：`A01` 17K 过稿／荣耀课、`B02` 中国作家网；强度 A+B；版权 🟢。

### S27 团宠／独特偏爱

爽感来自稳定归属与稀缺情感，要写清每个人为何爱、如何爱、主角如何回馈。正例：不同家人因不同共同经历形成各自保护方式；反例：全世界初见主角就送资源、替他违法。团宠若没有关系史、人物差异和边界，只剩集体降智与无条件供养。  
来源：`A11` 17K 幻言课、`A12` 番茄言情指导；强度 A；版权 🟢。

### S28 护短／救场守护

先建立被保护者与主角的真实关系，再设置越界伤害与保护成本。正例：主角为遭不公的队友承担公开申诉风险；反例：自己人明显作恶，主角仍破坏规则包庇。护短作为独立“标准爽点”的高等级证据较弱，更适合标为网络通行经验，并加上正义边界检查。  
来源：`A01` 保护／感动邻近材料、`D01` 圈内通行词；强度 A+D；版权 🟢。

### S29 恋爱被选择／追悔补偿

核心是稀缺偏爱、尊重和关系地位变化。正例：曾忽视主角的人理解伤害、长期修复，而主角保有接受或拒绝的权利；反例：施虐者流泪便获原谅，或所有优质角色无理由爱上主角。没有主体选择权，甜宠会变供奉，追悔会变再次强迫。  
来源：`A12` 番茄言情课、`A13` 17K 古言课；强度 A；版权 🟢。

### S30 感动／英雄担当

先用日常细节建立人物的恐惧、愿望和关系，再让他在关键时刻主动承担代价。正例：一向怕事的配角为熟悉的人站出来；反例：刚登场的角色忽然牺牲，旁人集体痛哭。感动不能只靠事件严重性，需由人物积累托住，也不适合无铺垫地充当开篇爽点。  
来源：`A01` 17K 编辑课；强度 A；版权 🟡（原课案例与三点结构不可直接改编）。

# 二、伏笔与悬念：26 个可独立教学组件

> 本节交叉使用两组标签：“载体”回答伏笔埋在哪里，“读者问题”回答悬念为什么生效。它们可以叠加，不是互斥的学院派目录。

## A. 伏笔的显隐与载体

### F01 直接预示／公开警告

把灾祸、预言、期限或失败条件直接告诉读者，悬念从“会发生什么”转为“如何发生、能否阻止”。正例：规则先说明第三次违规将永久除名，后文不断逼人物接近第三次；反例：预言含义任意变化，事后怎样都能解释。公开承诺必须有稳定边界，兑现时可偏转，不可赖账。  
来源：`FS1` 俄勒冈州立大学叙事教学、`FS2` EBSCO；强度 B；版权 🟢。

### F02 道具／物证伏笔

让一个可携带、可损坏或可查验的物件提前进入因果链，后文成为证据、钥匙、武器或关系证明。正例：早先卡住的旧锁决定逃生路线；反例：镜头反复特写玉佩，回收时只说“它果然重要”。道具必须改变选择或结果，单纯再次出现不算兑现。  
来源：`FS3` 特拉华大学教学材料、`FS4` Writing Excuses 契诃夫之枪课；强度 A+B；版权 🟢。

### F03 对话／口误／称谓伏笔

借异常用词、知识越界、回避回答或称谓错位留下线索；第一次读要像人物自然说话，回看又能重释。正例：陌生人无意使用只有旧部才懂的称呼；反例：角色为埋线突然念出完整谜语。对白若只服务作者而不符合说话者目的，会显得刻意。  
来源：`FS3` 特拉华大学教学材料、`FS5` 番茄信息差课；强度 A+B；版权 🟢。

### F04 行为／习惯／能力伏笔

用怕火、惯用手、检查顺序、专业反射等可观察行为，提前证明人物能力、创伤或身份。正例：角色总在进门前看出口，高潮时因此最早发现封锁；反例：前文从未表现会开锁，危急时突然宣布精通。行为要至少自然出现一次，回收才像因果而非补丁。  
来源：`FS3` 特拉华大学材料、`CS6` 爱潜水的乌贼访谈；强度 A+B；版权 🟢。

### F05 履历／关系缺口伏笔

用被删去的一年、互相冲突的回忆、不合年龄的熟悉感或关系人沉默制造可追问缺口。正例：两人都说第一次见面，却对同一旧伤反应过度；反例：作者只写“他的过去无人知晓”，数十章不给任何可验证线索。缺口要逐步缩小，不是永久保密。  
来源：`FS5` 番茄信息差课、`FS6` Sternberg 叙事兴趣模型；强度 A+B；版权 🟢。

### F06 环境／空间伏笔

把反常气味、封死的门、停摆的钟、路线盲区等置入场景，使环境后来参与因果。正例：仓库常年潮湿解释了证物为何失效；反例：每逢坏事先写乌云和冷风，却与事件无关。环境若只表达气氛，是暗示或意象；要称伏笔，回收时须提供行动条件或证据。  
来源：`FS1` 伏笔定义、`FS3` 线索载体教学；强度 B；版权 🟢。

### F07 意象／梦兆／童谣伏笔

通过重复颜色、梦、童谣或仪式，把未来事件和主题情绪连接起来；每次重现应增加一层具体信息。正例：童谣逐段补全失踪路线；反例：梦境高度抽象，结局后才被作者万能解释。象征可保留歧义，但关键事实不能只靠象征提供，否则读者无法公平推理。  
来源：`FS1` 俄勒冈州立大学教学、`FS2` EBSCO；强度 B；版权 🟢。

### F08 文件／记录／规则伏笔

把合同条款、账册、门规、系统限制或实验记录提前作为正常信息交代，后文让人物利用或受制于它。正例：不起眼的自动续约条款改变所有权；反例：高潮才补一句“规则其实允许例外”。规则型回收尤其忌临时增补，因为它会破坏世界信用。  
来源：`FS4` 显著细节承诺、`FS7` Sanderson 承诺—进展—兑现；强度 A+B；版权 🟡。

### F09 微型事件／低风险演示

先在小事件中展示能力、缺陷或世界规则怎样运作，高潮再放大同一因果。正例：小故障先证明备用电源只撑十分钟，围困时期限自然成立；反例：低风险演示与高潮解法毫无关系，只像教程插播。前置演示应当既完成当下事件，也为后续建立可信条件。  
来源：`FS4` 契诃夫式叙事承诺、`FS7` 进展与兑现；强度 A+B；版权 🟢。

### F10 缺席／空白／异常伏笔

不直接放入线索，而让应当存在的东西缺失：无人签字、监控恰少一段、家谱跳过一人。正例：所有交接都有双签，唯独事故日只有一份；反例：任何资料缺失都被说成伏笔，作者需要时再补答案。异常必须先有“正常基线”，否则读者看不出它异常。  
来源：`FS6` 追溯性好奇模型、`FS5` 信息差教学；强度 A+B；版权 🟢。

### F11 重复—变形—升级

同一线索分次出现，每次换语境并新增含义：看似习惯，后成破绽，再成为选择代价。正例：角色三次避开某地，原因从害怕逐步升级为保护他人；反例：每隔五章原样提醒“玉佩发热”。重复若不增加证据、缩小解释或提高代价，只是在替读者背诵。  
来源：`FS7` 承诺—进展—兑现、`FS8` 番茄长线闭环指导；强度 A；版权 🟡。

### F12 红鲱鱼／误导线索

用真实但可多解的证据引导读者形成错误假设，答案揭开后旧证据仍成立，只是因果解释改变。正例：嫌疑人的隐瞒确有其事，却是在掩护另一秘密；反例：为了反转伪造视角事实，或让角色故意不想他必然会想到的内容。误导可以误解，不能篡改事实。  
来源：`FS6` 惊奇与重释研究、`FS7` “意外而必然”的兑现原则；强度 A+B；版权 🟡。

## B. 悬念按读者问题分类

### F13 前瞻悬念：结果会怎样

读者知道目标、风险和若失败的代价，但结果被延迟，例如“能否在午夜前救人”。推进中应让概率或方案发生变化。正例：每次尝试都换来新路径和更高代价；反例：连续切场景，只是不肯回答。有效延迟包含进展，纯拖延只消耗作者信用。  
来源：`FS6` suspense／curiosity／surprise 模型、`FS7` 进展原则；强度 A+B；版权 🟢。

### F14 追溯好奇：过去为何如此

先给结果或异常，再延迟原因，如尸体、断裂关系、失落身份。每段调查应排除一种解释或补充一块证据。正例：事故已发生，证词逐次改变责任判断；反例：反复强调“当年另有隐情”，却没有线索增量。谜团可以长，认知不能原地踏步。  
来源：`FS6` Sternberg 等叙事兴趣研究；强度 B；版权 🟢。

### F15 重释惊奇：原来理解错了

新信息让读者重写此前事件的意义，同时保留旧事实的真实性。正例：一直被当成背叛的行为其实在转移追踪，但它确实伤害了同伴；反例：作者到结尾才新增决定性双胞胎。好反转带来“意外＋可回看”，坏反转只证明信息被故意扣住。  
来源：`FS6` surprise 研究、`FS7` “意外而必然”原则；强度 A+B；版权 🟡。

### F16 戏剧反讽：读者知道、角色不知道

提前让读者看见危险、误会或真实身份，再观察角色接近答案，动力来自“何时发现、发现后怎么办”。正例：读者知道桌下有装置，谈判者仍在拖延；反例：角色长期无视显眼证据，只为延长担忧。信息优势须与角色视野合理匹配，不能靠降智维持。  
来源：`FS5` 番茄信息差课、`FS9` Oxford dramatic irony；强度 A+B；版权 🟢。

### F17 谜面扣留：角色知道、读者不知道

可以隐藏计划细节，但要让读者知道目标、限制和可检验结果，才能形成问题。正例：主角说服团队执行分工，读者暂不知最后一步；反例：连续写“他笑了，已有办法”，高潮靠未展示资源解决。扣留答案不等于扣留全部条件，否则是作者作弊。  
来源：`FS5` 番茄信息差课、`FS6` 信息安排研究；强度 A+B；版权 🟢。

### F18 倒计时／损失递增

给目标设置可感知期限，并让等待本身带来损失：人质转移、窗口关闭、名誉持续下降。正例：每次延误都减少可用路线；反例：倒计时归零后世界毫无变化，或作者随意加时。期限不是数字装饰，它必须改变方案优先级和人物选择。  
来源：`FS6` 悬念的结果延迟研究、`FS10` 番茄章节前推课；强度 A+B；版权 🟢。

### F19 两难选择钩

章末不只问“打不打得过”，而是迫使人物在两个有价值且都要付费的选项间选择。正例：救一名证人会暴露整个据点；反例：一个选项显然正确，另一个只为显得残忍。选择钩同时推动情节和人物弧，比无条件危机更耐用，也能显露价值排序。  
来源：`CS8` McKee 人物与压力选择、`FS10` 番茄钩子经验；强度 A；版权 🟡。

### F20 小答＋大问的章末钩

本章先兑现一个局部问题，再让答案自然产生更高层问题。正例：找到失踪者，却发现他主动隐藏；反例：每章都在开门前、挥刀前硬切，连续三章不让动作完成。局部闭环给读者获得感，新问题才有借贷信用；钩子是局面改变，不只是断句。  
来源：`FS10` 番茄追更／章节指导、`FS7` 兑现再承诺；强度 A；版权 🟢。

## C. 埋设—进展—回收管理

### F21 六态伏笔生命周期

产品可将伏笔状态设为“埋设→微提醒→局部进展→转义／升级→因果兑现→余波”。正例：旧钥匙先被见到、后证实不匹配、再发现对应另一扇门，开门后改变阵营；反例：埋完沉睡百章，结尾突然拿出。六态是本报告对多源原则的产品化重组。  
来源：`FS7` 承诺—进展—兑现、`FS8` 长线闭环、`D01` 本报告重组；强度 A+D；版权 🟢（字段结构为本报告原创）。

### F22 回收时机：按承诺层级，不按统一章数

即时钩应在下一章给部分兑现；单元谜团在该事件结束前结算核心问题；卷级承诺在卷末兑现并产生余波；全书谜底可跨卷，但每阶段须新增证据或缩小范围。反例是拿“长线”当无限延期。公开平台材料强调进展与闭环，没有规定普适的 N 章。  
来源：`FS7` Sanderson、`FS8` 番茄神启指南；强度 A；版权 🟡。

### F23 数字模板：只能作报警器

若产品必须预置，可测试“章末钩次章变局、短线约 3—10 章、中线约 10—30 章、长线按卷管理”，超期则提醒作者升温或回收。正例是题材、章长与更新频率可覆盖默认值；反例是自动在第十章插入答案。该区间为编辑启发式，不是平台规则或实证结论。  
来源：`FS11` 2014 年出版经验提供旧参照、`D01` 本报告综合；强度 B+D；版权 🟢（必须显示“可调默认值”）。

### F24 长线伏笔升温

长线不必频繁点名，但应周期性完成一种变化：新增证据、排除解释、提高代价、让另一人物注意到，或改变读者判断。正例：每卷补一块身份谜团且各自推动当卷行动；反例：五十章只重复“他的身世不简单”。提醒不是复读标签，而是让悬念资产增值。  
来源：`FS7` 进展原则、`FS8` 番茄长线闭环；强度 A；版权 🟢。

### F25 悬念栈：前台 1＋1—2，后台不限但要登记

建议此刻突出一个主问题和一至两个近端问题，其余长线进入后台；数量按题材和读者测试调整。衡量点是读者能否说出“眼下最想知道什么”，而非总坑数。反例是援引工作记忆研究宣称“科学证明最多四个悬念”；心理实验的 chunk 不能直接等同故事问题。  
来源：`FS12` Cowan 仅证明认知资源有限、`D01` 产品启发式；强度 B+D；版权 🟢。

### F26 伏笔账本与公平性验收

每条记录对象、首次章、读者问题、可见线索、最近进展、计划回收层级、兑现结果和余波。验收问三件事：回看能否找到依据，回收是否改变选择／局势，角色是否被迫忘记合理信息。正例是旧线索获得新含义；反例是靠新增事实或人物降智制造反转。  
来源：`FS6` 公平重释原理、`FS7` 承诺兑现、`D01` 本报告字段设计；强度 A+B+D；版权 🟢。

# 三、节奏理论：25 个可独立教学组件

## A. 2000—4000 字章节的内部功能

### R01 发布单位不等于叙事单位

2000—4000 字主要受更新、计费、移动阅读和作者产能影响；一章可能是一场，也可能含数场，不能从字数直接推出剧情结构。正例：短章完成一个高压决策，长章容纳追逐与余波；反例：为凑三千字硬添解释，或到字数便拦腰切断。插件应检查功能闭合，而非强制长度。  
来源：`RS1` 阅文社区章长经验、`RS2` 起点活动更新单位、`RS3` 光明日报行业观察；强度 A+B+C；版权 🟢。

### R02 章长稳定与有意变速

常态章长相对稳定可建立阅读预期，重要转折可有意缩短以加速、拉长以容纳因果，但变化须服务内容。正例：追逐用多个短章，审判用较长章完整兑现；反例：同一作品章长从数百跳到上万且没有功能差异。稳定是生产建议，不是“每章必须同字数”的平台规则。  
来源：`RS1` 阅文作者社区建议、`RS3` 行业观察；强度 B+C；版权 🟢。

### R03 开头再入场：承接变化

新章应尽快让读者知道上一章后局面变成什么、人物此刻在哪里、最紧迫的问题是什么；必要回顾只保留影响行动的信息。正例：从上一章失败造成的新限制切入；反例：每章先复述前情、天气和人物简历。连载读者需要重新定位，但不需要重复观看上一章。  
来源：`RS6` 番茄整体设计与断章课、`RS9` 承诺—进展—兑现；强度 A；版权 🟡。

### R04 本章微目标

给主要视角一个能在本章推进或改写的具体目标，例如拿到证词、说服同盟、撑过考核；它应服务阶段目标。正例：大目标是翻案，本章只争取调阅权限；反例：人物在场景里聊天、回忆、走路，却没有想改变任何事。微目标让信息和描写获得取舍标准。  
来源：`RS4` Swain 场景方法、`RS5` Scene／Sequel 公开解释；强度 B；版权 🟡。

### R05 阻力与递增代价

阻力最好来自有意志的对手、规则限制或资源冲突，并在尝试后改变；不能只是重复拒绝。正例：第一次申请被拒后，人物换证据，却暴露了证人；反例：门卫连续三次说“不行”，强度只靠嗓门增加。推进感来自策略—反馈—代价变化，不来自事件数量。  
来源：`RS4` Goal—Conflict—Setback、`RS18` 阅文节奏诊断；强度 B+C；版权 🟡。

### R06 本章状态改变

章末至少发生一种不可忽略的变化：得到、失去、发现、决定、关系重排或风险升级。正例：证据没有拿到，但人物确认盟友说谎；反例：三千字争执后双方立场、信息和处境都回到原点。状态变化可以小，却必须影响下一章选择，避免“忙而不进”。  
来源：`RS4` 场景／后续场景方法、`RS7` 番茄追更课；强度 A+B；版权 🟡。

### R07 局部反馈／小兑现

每章不必都大爽，却应给读者一种收益：回答小问题、验证能力、关系前进一步、危险阶段解除或情绪得到承认。正例：主线谜团未破，但本章排除一个嫌疑人；反例：连续多章只承诺“快了”。局部兑现为新悬念提供信用，也能避免全书只靠章末断刀。  
来源：`RS9` 兑现原则、`RS7` 番茄追更指导；强度 A；版权 🟡。

### R08 章末前拉力

可用新威胁、新信息、新选择、期限、身份变化或“小答引出大问”，核心是让局面向前。正例：人物拿到名单，却发现自己也在上面；反例：每章固定在抬手、开门、说“其实……”处截断。机械断章会让读者预判套路，且因长期不回答而损耗信任。  
来源：`RS6` 番茄直播总结、`RS7` 番茄追更课；强度 A；版权 🟢。

### R09 行动场与反应场交替

行动链可概括为目标—冲突—受挫，反应链则处理情绪—困境—决定；两者可同章也可跨章。正例：战败后用短反应段让人物接受代价并选新方案；反例：连续战斗不给情绪吸收，或连续内耗没有新决定。网文适配时应用功能，不照搬原书章节配方。  
来源：`RS4` Dwight V. Swain、`RS5` 公开释义；强度 B；版权 🟡（完整体系不可复刻）。

### R10 快节奏不是删掉情绪

节奏快意味着有效变化密、决策快，并非只保留事件摘要；节奏过快时应补足反应、关系和代价，过慢时才考虑压缩重复或增加钩子。正例：大战后用一个具体选择呈现创伤；反例：人物刚失去亲人，下一段便兴奋领奖。没有情绪结算，事件越多越轻。  
来源：`RS8` 番茄改单章课；强度 A；版权 🟢。

### R11 过渡章也要发生变化

换地图、休整、赶路和信息汇总可以降低强度，但仍需完成关系调整、资源结算、目标重设或隐患暴露。正例：旅途中因分配物资重排团队权力；反例：整章列景色、商店和设定，只为把人送到下一城。过渡不是空白带，而是把旧后果接到新行动。  
来源：`RS19` 番茄转场指导、`RS9` 进展原则；强度 A；版权 🟢。

### R12 信息密度与场景化

新设定只在人物要据此行动时展开，并用选择、后果或冲突验证。正例：规则在考核中逐条变成限制；反例：角色停下讲完整组织史，听众早已知道。若删除一段说明不影响本章决定，就应后移、压缩或拆散。信息有用不等于此刻就该交付。  
来源：`RS18` 阅文节奏诊断、`RS20` 番茄高频雷点；强度 A+C；版权 🟢。

### R13 张弛波形而非恒定高音

紧张、释放、余波、再蓄压构成可辨波形；高潮后让结果落地，读者才知道高潮改变了什么。正例：胜利带来短庆祝，同时暴露更大代价；反例：每章都比上一章更危险、更震惊，数十章后只能继续膨胀。持续高刺激会抬高阈值，也压扁真正高潮。  
来源：`RS17` 番茄题材课、`RS8` 番茄节奏修改课；强度 A；版权 🟢。

## B. 单元、卷与高潮层级

### R14 卷首承诺

一卷开头要建立阶段目标、主要阻力、成功收益和失败代价，让读者知道这一卷大致等待什么兑现。正例：本卷目标是拿到入场资格，主角也会因此暴露身份；反例：只换新地图、堆新人名，却没有阶段方向。卷承诺不必直说，但应能被动作和限制推断。  
来源：`RS9` Sanderson 大小情节承诺、`RS7` 番茄剧情稳定课；强度 A；版权 🟡。

### R15 尝试—反馈—升级单元

卷中用若干小单元循环：人物尝试方案、世界反馈、目标或代价升级。每轮应改变至少一个变量。正例：争取盟友失败，却得到对手内部情报；反例：换三个地点重复同一场打脸。小高潮不是日历闹钟，而是一次阶段尝试的有意义结算。  
来源：`RS9` 进展模型、`RS18` 节奏诊断；强度 A+C；版权 🟢。

### R16 中段不可逆变化

卷中段可安排一次改变问题性质的事件：目标升级、盟友倒戈、身份公开或退路关闭，使后半卷不能复用前半策略。正例：调查从找凶手转为证明制度共谋；反例：所谓中点只是更强敌人登场，人物仍按同一流程闯关。不可逆变化能防止长卷中段原地打转。  
来源：`RS9` 情节进展公开课、`RS4` 受挫与新决定；强度 A+B；版权 🟡。

### R17 小高潮：局部目标结算

小高潮应兑现一个可辨的短期目标，同时改变主线条件；可以是胜利、失败、发现或关系决裂，不必都叫“爽”。正例：主角赢得资格，却因此进入对手视野；反例：为了满足“三章一次”，临时制造陌生炮灰来被打脸。铺垫不足的高潮只会像插播。  
来源：`RS10` 千幻冰云旧模板作历史参照、`RS17` 番茄相对原则；强度 A+B；版权 🟡。

### R18 大高潮：集中兑现与代价

大高潮汇合本卷主要目标、关键关系和前置伏笔，让人物作不可逆选择；结果后还要展示制度、资源和情绪后果。正例：胜诉同时失去隐藏身份，下一卷条件重置；反例：打完终极敌人立即切地图，所有伤亡与承诺消失。规模来自汇线和代价，不只来自战力数字。  
来源：`RS9` Promise—Progress—Payoff、`RS7` 番茄剧情课；强度 A；版权 🟡。

### R19 高潮余波与下一卷桥

高潮后用短余波确认谁得失什么、关系如何改变，再由未解决后果提出下一卷承诺。正例：庆功时发现胜利使资源供应中断；反例：刚结算便凭空降下更强敌人。桥接问题最好由旧结果产生，这样升级是因果扩展，不是作者换服务器。  
来源：`RS17` 番茄“大高潮后引出更大剧情”、`RS9` 再承诺；强度 A；版权 🟡。

### R20 数字化高潮模板的正确用法

2014 年《别说你懂写网文》给过约 1 万／3 万／6 万字的小／中／大高潮个人模板，按 2—4 千字机械换算约 3—5／8—15／15—30 章。它可作“多久未反馈”的报警线，不能称平台标准。题材、章长和连载年代变化时必须重新标定。  
来源：`RS10` 千幻冰云著作、`RS11` 出版信息；强度 B；版权 🔴（只引用事实与短原则，不改编整套课程）。

## C. 经验口诀、出处与变体

### R21 “黄金三章”：任务共识强于步骤共识

未找到可信首创者。2018 年媒体记录过“冲突—金手指—打脸”，2026 番茄课写成“核心冲突—金手指—短期目标”，阅文女频材料强调尽快输出爆点。可教的共同核是尽早建立冲突、差异与追读理由；反例是各题材都机械塞金手指和打脸。  
来源：`RS12` 上观新闻、`RS20` 番茄官方课、`RS21` 阅文女频指导；强度 A+B+C；版权 🟢（版本出处须保留）。

### R22 “三章一小爽、五章一大爽”：出处未证

没有找到可验证的大神首创、起点规则或番茄规则。当前能追到的较早公开页面是 2017 年玄派转载文，其自身也只写“网文中有一种说法”，证明当时在流传，不证明由该文发明。插件只能标“网络经验／待考”，不可标“行业公认”或自动插入爽点。  
来源：`RS13` 2017 玄派公开文、`D01` 溯源核查；强度 D；版权 🟢（不可搬付费教程解释）。

### R23 互相冲突的节拍变体

公开材料同时出现“每章小反馈、十章大爽”“每天小高潮、每周大高潮”“八章小、十章大”“10 万字小、20—30 万字大”等，计量单位也从章、天到字数不一。它们只能说明作者会设反馈周期，不能互证某个数字正确。反例是挑一条写成平台算法。  
来源：`RS12` 上观新闻、`RS14` 阅文作者经验、`RS15` 叶非夜访谈、`RS16` 中国作家网；强度 A+B+C；版权 🟢。

### R24 题材与渠道适配

悬疑更依赖证据增量和单元闭环，升级文重阶段能力验证，感情文重关系状态变化，群像与慢热作品则需更长积累；免费移动端也可能更强调开篇识别度。正例是保持“承诺—进展—反馈”功能而改变频率；反例是把男频升级节拍硬套细腻关系线。  
来源：`RS7` 番茄追更课、`RS18` 阅文节奏诊断、`D01` 跨题材综合；强度 A+C+D；版权 🟢。

### R25 产品化：事件驱动参数而非硬编码

插件应记录章长中位数、更新频率、题材、当前阶段、最近局部反馈、最近大兑现及读者留存，再给“可能过久未进展”的提醒；作者可覆盖阈值。正例是同一组件在短章与长章采用不同周期；反例是系统每五章强塞高潮。数字是可测试参数，不是创作真理。  
来源：`RS1` 行业章长经验、`RS9` 进展原则、`D01` 本报告产品适配；强度 A+C+D；版权 🟢。

# 四、人物塑造：27 个可独立教学组件

## A. 网文人物弧光的简化模型

### C01 旧因—误信—想要—需要链

过去伤害让人物形成有偏差的信念；他追逐的外部目标能暂时缓解痛苦，却不一定满足真正需要。正例：拼命争第一，实际害怕被抛弃；反例：结局忽然一句话想通，前文没有代价和选择证据。插件应把四项分别记录，不能只填一段“悲惨身世”。  
来源：`CS1` 番茄人物课、`CS7` K. M. Weiland、`CS10` Story Grid；强度 A+B；版权 🟡。

### C02 正向改变弧

开局用有代价的行为证明旧信念；冲突让旧办法失效，中段尝试新选择，低谷逼人物在旧安全感与新价值间二选一，结尾用行动证明改变。正例：控制狂最终把关键决定交给伙伴；反例：只升级战力、财富和身份，心理与关系处理方式原封不动，却被旁白称作成长。  
来源：`CS1` 番茄人物课、`CS7` Weiland；强度 A；版权 🟡。

### C03 平直／测试弧

人物开局已持有核心价值，故事测试他在巨大损失前是否仍坚持，并由其影响周围人或制度。适合职业强者和信念型主角。正例：资深医者在舆论压力下仍守程序；反例：从头无敌、永不怀疑、众人自动折服。平直弧仍需损失、疑惑与策略调整，不等于无弧。  
来源：`CS7` Weiland 平直弧、`CS8` McKee 人物原则；强度 A；版权 🟡。

### C04 负向改变弧

可写为面对真相却失去希望、明知旧信念有害仍加深，或从正确价值逐步被利益和恐惧腐化。每次退步最好带来短期收益。正例：一次越界救下组织，人物此后更相信越界正确；反例：被刺激后突然黑化，只靠童年悲惨解释全部恶行。沉沦也需要选择链。  
来源：`CS7` Weiland 负向弧；强度 A；版权 🟡（其三分体系不可整套换皮）。

### C05 压力选择显形

外貌、口头禅和自评只是表面，真正性格在两个都要付出代价的选项中显露。正例：自称重情的人必须在救友与保全家族间选择；反例：作者反复说他善良，只安排无成本施舍。压力越大，选择越能说明人物；选择后还要承担后果，不能下一章复位。  
来源：`CS8` Robert McKee 官方资料；强度 A；版权 🟡（原句、课程图示不可复制）。

### C06 用动作、行为与选择表现状态

创伤、胆怯和责任感要体现在回避、过度准备、错误判断及关键选择中，而非只靠旁白诊断。正例：受过背叛的人总预留退出路线，因而也错过合作；反例：人物说自己痛苦，所有决定却不受痛苦影响。爱潜水的乌贼复盘时也强调以动作和选择呈现状态。  
来源：`CS6` 爱潜水的乌贼访谈；强度 A；版权 🟢。

### C07 记忆锚点—重复—增层

先用一两个鲜明锚点帮助连载读者识别角色，再在不同事件里变形：同一“谨慎”可表现为留后手、怀疑盟友，也可导致错失机会。正例是标签产生不同后果；反例是不断添无关标签，或每次出场机械重复口头禅。锚点负责记忆，变化负责立体。  
来源：`CS1` 番茄人物课、`CS5` 中国作家网人物研究；强度 A+B；版权 🟢。

### C08 长篇阶段弧

百万字角色可按卷循环“旧办法暂时成功—边界暴露—局部调整—新问题”，同时保留一条跨卷核心缺陷。正例：每卷检验“是否信任伙伴”的不同层面；反例：每卷都把成长清零，重新学同一课，或第一卷改变后数十万字再无心理变化。阶段弧必须累积，不是重启。  
来源：`CS1` 番茄人物课、`CS5` 人物研究、`CS7` 角色弧；强度 A+B+D；版权 🟢（长连载适配为本报告重组）。

## B. 配角功能类型学

### C09 独立欲望：重要配角的底座

先写配角与主角无关的欲望和行动计划，再判断何时合作、冲突或错位。忠臣也可能想保全家人，导师也可能维护名声。正例：搭档帮助主角但拒绝牺牲故乡；反例：唯一愿望是“帮助主角”，需要时出现、用完消失。功能类型不能代替人物自身发动机。  
来源：`CS1` 番茄人物课、`CS4` 阅文配角课、`CS7` Weiland；强度 A；版权 🟡（课程案例不可搬）。

### C10 同盟／搭档型

补主角能力盲区、分担行动、提供对话面，并让读者看到主角在亲密关系中的另一面；至少一项原则应与主角不同。正例：技术搭档支持目标，却反对主角的冒险手段；反例：全程赞美服从，只做信息查询和情绪安慰。没有独立立场的搭档只是主角外置工具。  
来源：`CS11` 角色原型整理、`CS12` Dramatica；强度 B；版权 🟡。

### C11 导师／守护者型

提供规则、技能、资源或道德警告，但不替主角完成核心选择；导师可以过时、犯错或有所隐瞒。正例：导师教方法，却让主角决定是否越过伦理线；反例：每遇难题就给唯一正确答案，或为逼主角独立而无铺垫强行写死。指导越强，限制与盲区越要清楚。  
来源：`CS11` Final Draft 原型资料、`CS12` Dramatica；强度 B；版权 🟡。

### C12 怀疑者／反方参谋型

质疑计划、指出风险，把读者可能提出的问题提前放入剧情；其反对要有事实和自身利益。正例：众人要冒险救援，军需官指出会切断全军补给；反例：每次只说“不行”，最后永远被主角证明愚蠢。好的怀疑者提高决策质量，不是供主角训斥的悲观标签。  
来源：`CS12` Dramatica 反向推动功能；强度 B；版权 🟡。

### C13 镜像／岔路型

与主角有相似起点，却因关键选择走向另一结果，展示“主角若选另一条路会怎样”。正例：两人都被制度抛弃，一人改革、一人报复；反例：为了衬托主角，把配角写得无能恶毒且无可比条件。镜像应共享伤口、能力或欲望，分岔才有解释力。  
来源：`CS8` McKee、`CS9` John Truby 访谈；强度 A；版权 🟡。

### C14 信使／世界接口型

把新威胁、任务、规则或社会层级带入主角生活，也可成为读者认识新地区的窗口。信息必须符合身份与知情范围。正例：基层联络员只知道执行层变故；反例：路人突然掌握全局机密，讲完设定便退场。接口角色也要有目的，不能只是一张会走路的百科卡。  
来源：`CS11` 原型功能、`CS5` 网文人物研究；强度 B；版权 🟡。

### C15 门槛守卫／阶段测试型

负责检验主角能否进入下一层级，可在失败或被击败后转为盟友、竞争者或观察者。正例：考核官迫使主角证明真正学会了协作；反例：每个区域守卫都是同款嚣张炮灰，只负责被打脸。守卫的标准应体现新阶段规则，而非只提高数值。  
来源：`CS11` 门槛原型、`CS4` 阅文反派课；强度 A+B；版权 🟡（直接改写阅文课程结构则 🔴）。

### C16 不稳定盟友／变形者型

忠诚、身份或目标暂不确定，通过利益选择留下可回看的阵营线索。正例：盟友每次摇摆都在保护同一隐藏对象；反例：作者为制造惊吓临时换阵营，旧行为无法解释。此功能可由情人、下属或竞争者承担，不等于“性格反复无常”。  
来源：`CS11` 变形者原型；强度 B；版权 🟡。

### C17 情感锚／代价承载型

让宏大目标落到具体生活和关系：守一座城的意义，由一个普通家庭的选择与损失承载。正例：被保护者也主动决定留下或撤离；反例：亲友没有人格，只等被绑架、被杀来刺激主角。情感锚必须能行动和拒绝，否则只是剧情按钮。  
来源：`CS5` 人物研究、`CS8` 压力与关系原则；强度 A+B+D；版权 🟢。

### C18 诙谐者／秩序扰动型

用误解、讽刺或越界行为释放张力，说出正剧人物不便说的话，并扰动僵化关系；喜剧动作仍应推动信息、关系或决定。正例：玩笑无意揭穿团队禁忌；反例：大战前插入无关段子，或角色为搞笑突然智商归零。笑点若取消危险，就会破坏主线信用。  
来源：`CS11` Trickster 原型资料；强度 B；版权 🟡。

## C. 反派塑造的层次论

### C19 先分对抗功能，不先分善恶

反派首先是阻挡主角目标的对抗者；他可能道德上更正直，恋爱双方也可能互为阻力。先写双方互斥目标，再决定价值评价。正例：两人都想救城，却争夺唯一指挥权；反例：因为需要坏人，临时安排陌生人无故作恶，冲突只靠辱骂和挑衅。  
来源：`CS7` 角色弧资料、`CS9` Truby 访谈；强度 A；版权 🟢。

### C20 短期功能反派与长期重要反派

短期反派制造局部障碍、展示规则或完成一次反馈，设定宜清楚；长期反派需持续目标、资源、人格矛盾和跨阶段影响。正例：区域守卫一场内完成制度测试，核心对手跨卷适应主角；反例：每个炮灰都有长篇身世，终极反派却仍只会嚣张。  
来源：`CS4` 国王陛下阅文课程；强度 A；版权 🔴（只取抽象命题并多源重写，不复刻课程结构与案例）。

### C21 同一稀缺目标竞争

强冲突常来自双方争夺同一权位、资源、真相解释权或某人的选择；一方前进会直接压缩另一方空间。正例：改革者与权臣都需要同一中立派支持；反例：反派笼统想毁灭世界，却与主角的日常目标长期不相交，只能靠作者安排偶遇。目标接触面决定冲突频率。  
来源：`CS9` John Truby 本人访谈；强度 A；版权 🟡。

### C22 主动计划与适应能力

重要反派在主角出现前就有目标、资源、期限和方案；主角破局后，他会根据损失调整策略。正例：发现正面压制无效便争夺主角盟友；反例：明知主角成长，仍依次派出刚高一级的手下，自己从不调查、联合或变招。能适应的对手才会迫使主角真正成长。  
来源：`CS7` 对抗与角色弧、`CS4` 阅文反派课；强度 A；版权 🟡。

### C23 可理解动机，不等于洗白

给反派一个能解释当前行动的具体欲望，再让读者看到恐惧、珍视或脆弱；理解因果不等于赞同恶行。正例：为保组织生存而压迫新人，结局仍承担责任；反例：只写“他疯了”，或悲惨过去一揭晓，文本便免除全部罪责。同情与评价应分开。  
来源：`CS4` 阅文反派课、`CS7` Weiland；强度 A；版权 🟡。

### C24 主题镜像与诱惑

反派不只挡路，还提出一套对主角有吸引力的解决方案，代表主角可能走向的暗面。正例：两人都要结束战争，一人靠联盟，另一人要永久控制所有人；反例：反派观点蠢到无人会信，主角拒绝它毫无人格成本。诱惑越真实，关键选择越能完成弧光。  
来源：`CS7` 角色弧、`CS9` Truby 访谈；强度 A；版权 🟡。

### C25 离场仍在场

长期反派不必频繁露面，可通过命令后果、代理人、被改变的制度、受害者与流言持续施压。正例：主角每次办事都遇到对方新规则的余波；反例：终极反派数百章没有可感后果，高潮前突然现身自称布局多年。影响链比神秘剪影更能证明威胁。  
来源：`CS4` 阅文反派课、`CS7` 对抗原则；强度 A；版权 🟡（课程素材不可搬）。

### C26 对抗力叠层

把阻力拆为人物内在缺陷、亲密关系、组织制度、社会舆论和自然条件；核心反派可利用这些力量，不必亲自制造所有事故。正例：对手借主角的不信任离间团队；反例：所有坏事都归同一幕后人，世界失去自主性，或阻力很多却不指向核心目标。  
来源：`CS8` McKee、`CS5` 人物研究、`D01` 网文化重组；强度 A+B+D；版权 🟢。

### C27 反派也有变化线

长期反派可随胜利自负、随失败极端，或因主角影响而动摇；每次变化必须改变策略。正例：失去合法性后从制度战转入舆论战；反例：一直聪明强大，高潮突然降智，或反派死亡后其制度、盟友和遗留问题自动消失。结局要回应其早期目标、方法与代价。  
来源：`CS1` 番茄人物课、`CS7` 角色弧；强度 A；版权 🟢。

# 五、版权、证据与入库规则

## 5.1 哪些可以重写，哪些不要改编

| 风险 | 可做 | 不应做 |
|---|---|---|
| 🟢 通用原理 | 多源研究后自建分类；用原创语言、原创例子和原创练习；保留来源记录 | 误称“某平台官方标准”或“业内公认” |
| 🟡 署名模型／公开作者课 | 讲抽象命题并归因；只作必要、适量引用；把参数标为作者经验 | 沿用同一独特命名、目录顺序、图表、案例链和作业设计 |
| 🔴 完整／付费课程 | 只作检索线索或事实核对；若确需使用，先获得书面许可 | 逐段改写、同义换词、重画同构图、批量提取案例或把课程拆成插件卡 |

WIPO 的通行原则是版权保护具体表达，不垄断思想、程序和操作方法；但解释方法的文字、图示及有独创性的选择编排仍可能受保护。中国现行《著作权法》列明复制、改编、汇编等权利，并对课堂教学、适当引用等例外设置条件。商业插件通常不能仅凭“用于教学”自动免责；本节是内容治理建议，不替代针对具体材料的法律意见。  
来源：`L01` WIPO、`L02` 国家版权局、`L03` 北京市知识产权局；强度 A。

## 5.2 平台课程的特殊边界

- 17K 页面明确标示“未经许可不得擅自转载本站内容”，因此可研究其所述通用原则并做独立表达，不能搬运课程正文、原例和结构。来源：`L04`。
- 阅文课程页面的版权声明示例将课程文字、图片、视频等列为权利内容；国王陛下的配角／反派课在本报告中只作为命题出处，若直接沿课程目录拆卡应视为 🔴。来源：`L05`、`CS4`。
- 番茄、阅文公开作者课“公开可访问”不等于“可复制进商业数据库”。本报告只保存事实性摘要、链接和自创例子，不收录逐字稿或课程截图。
- 《别说你懂写网文》及 Sanderson、Swain、Weiland 等署名体系只能概念级归因使用；不要把一位作者的完整框架换中文名后包装成自有体系。

## 5.3 建议的内容生产闸门

1. 每个核心命题尽量有两个彼此独立的来源；只有单一课程时，在卡片上显示“某作者／某课程经验”。
2. 研究记录只保留“可抽象命题、出处、检索日期、版权状态”，不存付费课逐字稿、截图或批量原例。
3. 分类名称、顺序、检查表与交互流程由产品重新设计；正例、反例、人物名与练习全部原创。
4. 上线前做三层相似度检查：文字相似、结构相似、案例相似；🔴 来源单独进入法务复核。
5. 数字规则必须带 `scope`、`source_owner`、`evidence_grade` 和 `overridable=true`；D 级数字不得在界面显示为“科学规律”。
6. 来源失效时保留页面标题、主体、发布日期和最后核验日，但不要用网页存档规避付费墙或权利控制。

# 六、面向“写作技巧插件”的字段建议

本项目现有边界要求“方法卡提供规划、事实句与分镜层指导，不直接产出可拼接正文”，且理论组件采用渐进披露。建议每条保存以下字段：

| 字段 | 用途 |
|---|---|
| `component_id` / `name` | 稳定 ID 与教学名；不要把他人独特课程名直接注册为产品名 |
| `trigger_line` | 15—25 字触发说明，例如“反转缺少前置依据时使用” |
| `reader_need` | 本条满足的期待：公正、掌控、好奇、归属、情绪结算等 |
| `preconditions` | 使用前必须存在的关系、规则、证据、目标与代价 |
| `execution_checks` | 构成要件和逐项检查，不给可直接拼正文的示范句 |
| `failure_modes` | 写俗、写尬、降智、赖账、机械降神、节奏通胀等反例模式 |
| `abstract_examples` | 原创的情境级正反例；不引用小说原句或课程案例 |
| `source_refs` | 来源 ID、链接、主体、日期、证据等级、最后核验日 |
| `copyright_risk` | 🟢／🟡／🔴，另记许可状态和禁用素材范围 |
| `parameters` | 默认章数、字数或悬念数；必须带适用题材和可覆盖标记 |
| `story_state_effect` | 本条兑现后必须改变的目标、关系、信息、资源或风险 |
| `no_prose_boundary` | 明示“只给要求、检查项和分镜意图，不生成正文句子” |

建议索引层只显示名称与触发线；展开后再显示构成、铺垫、失败模式与抽象例；研究层才显示完整来源与版权备注。这样既符合渐进披露，也能让用户区分“平台事实、署名方法、网络经验”。

# 八、调查限度与下一轮深挖顺序

1. 本报告建立的是“可教学地图”，不是效果排行榜；各条能否提升追读，需要按题材、渠道和读者群做 A/B 测试。

3. “正例／反例”全部为抽象原创情境，只说明结构，不等于可直接放进小说的成品桥段。
4. 下一轮最值得逐条深挖的是：打脸的仇恨值上限、扮猪隐藏动机、反杀的公平伏笔、章末小答＋大问、长线伏笔升温、负向人物弧、长期反派适应策略。
5. 若要形成第一批插件，建议从四类各选 5—8 个高频且 🟢 的组件做小规模验证；不要一次把全部 108 个条目暴露给作者。
