# 中文网文 AI 创作工作台研究资料包

**版本日期：2026-08-24**  
**研究范围：中文长篇网文作者需求、叙事结构、动态规划、故事记忆、下一章供料、一致性检查与软评价**

## 这套资料解决什么问题

这不是一份“让 AI 自动写完整小说”的方案。它研究的是另一条路线：

> 作者持续日更、边写边改时，系统怎样记住已经发生的内容，怎样让计划可调整，怎样在下一章前找到真正相关的材料，怎样把硬冲突与软创作判断分开。

资料包以用户提供的 33 篇论文清单为起点，又补充了中文网文行业报告、平台公开规则、作家访谈、人机协作研究、长文本记忆、图检索、时间知识图谱和代码仓库级 AI 工程论文。原始清单保留在 `11_原始33篇论文清单_用户提供.md`，没有覆盖或改写。

## 证据标签

报告中的判断尽量标为三类：

- **证据结论**：论文、官方规则、行业报告或作者访谈直接支持。
- **跨领域推论**：从长文本 AI、RAG、Agent Memory 或代码工程迁移过来的解释，尚未在中文网文上直接验证。
- **产品假设（待验证）**：可进入原型或用户测试，但不能当成已经拍板的产品合同。

## 研究边界

1. 英文论文大量使用短故事、剧本、一次性长篇或自动生成数据。它们能证明某种机制“可能有用”，不能直接证明它适合中文日更网文。
2. 起点、番茄、七猫、纵横、飞卢、晋江的商业机制与读者结构不同。报告只把平台公开信息当作约束证据，不把“某平台一定偏好某种结构”写成事实。
3. 作家访谈能反映真实流程，但样本数量有限，且名家与新人、男频与女频、付费阅读与免费阅读之间可能差异很大。
4. 论文中的自动评价器多数没有达到“真值”水平。硬检查和软评价必须拆开，不能用一个总分替作者做决定。
5. 所有架构建议都属于**候选，待 CZ 拍或待实测**。
