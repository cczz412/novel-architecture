## 一句话总纲

九份回包基本都指向同一个形状：**我们的骨架（冻结原文→事实库→压缩视图→按需回捞）与多份相关研究的方向一致（注意：证据不足以称「业界共识」），不用改；但三件事必须补——① 压缩视图只能当导航不能当唯一记忆，② 下游承接要走「先分角色、先过硬门」的验收结构，③ 一切自动裁判都只能筛查不能签票。**

## 各主题的可落地结论

### 1. 伸缩压缩：拿到起跑参数了（BRIEF_01 回包）

- 🔥 关键修正：「远期压成一句话」只能是**常驻导航视图**，不能是那段历史唯一剩下的记忆——ReadAgent 实测：只有摘要 77.52%，摘要+回捞原页 86.16%。回捞通道是刚需，不是增强。
- 起跑参数（当作初值，本地调优）：记忆包总预算 `min(0.25×窗口, 14k tokens)`；当前层 3200（事实 1:1），近期层 1600（默认近 3 章，压缩比试 3/4/5:1），远期常驻 800（10~20 个胶囊、每个 40~80 汉字、起跑 20:1），按需召回 2000（最终 8~15 条事实 + 2~6 段原文），元数据 400。
- 回捞顺序：实体/时间/故事线硬召回 → BM25+向量 → 一跳因果图 → 重排去重 → 按故事时间送入。人物状态用 `valid_from/to + supersedes`，伏笔用 `setup_id→payoff_id`。**先不用上图数据库。**
- 触发机制：章锁定后升格/建视图；每场前重编译；近期层默认 3 整章后降级。

### 2. Agent 记忆项目：抄 Graphiti 的双时间 + Tencent 的分层晋升（BRIEF_07 回包）

- 核实结果：四个项目都真实存在且活跃（Tencent 18,465★ / Mem0 62,852★ / Graphiti 29,695★ / agentmemory 26,768★）；**Zep 开源 Server 已停维护，踢出候选，Graphiti 顶上**。
- 最值得抄的两样：
  - **Graphiti 双时间失效**：`valid_at/invalid_at + created_at/expired_at`，旧边不删——正好是我们「覆盖编号+过期状态」的成熟版，直接对应 CZ 的「永久字段+反向指针」。
  - **Tencent 分层晋升**：L1→L2/L3 按通用性/稳定性/可执行性审查晋升——最接近「事实句→人物永久字段」的现成结构。
- 不抄：整套图数据库、fail-open、删除式更新（我们的真值纪律禁止硬删）。

### 3. 吃书检测：五段架构，自动裁判只筛不裁（BRIEF_05 回包）

- 推荐架构：主张抽取 → 多路候选并集 → 确定性校验＋上下文验证并行 → 证据合并风险分级 → **作者裁决后才冻结更新**。
- ⚠️ 能力边界要认：叙事场景 NLI 掉点严重（FACTTRACK 叙事 P/R 约 60；ConStory 检查器召回仅 0.55；20% 文本被 7 个模型全部漏检）。≥3 跳、隐含常识、动机弧、知情暗示类矛盾现阶段机器查不出来。**红灯系统的定位必须是「高召回筛查+作者裁决」，永远不宣称零漏检。**
- 时间线：拆三层（叙事顺序/故事顺序/状态有效期），存部分时间（区间+before/after），程序管成环/区间无解/死后行动这类硬错，模型只管解析。这直接回应了我们 Q8 的「时间线对象」盲点。

### 4. 拆书配方：三种格式，第一版做 A+C（BRIEF_03 回包）

- 九组拆解维度已收敛（定位承诺/宏观结构/人物关系/金手指/冲突转折/期待钩子爽点/章节执行/文风/治理适配）。
- 三种配方格式：A 原子技巧卡（生成提示、方法库）、B 期待—压力—兑现图（跨章规划）、C 配方执行实例（关章检查、作者豁免）。**第一版 A+C 必做，B 轻量。**
- ⚠️ LLM 自动拆书的可靠边界：证据层可自动；结构推断要人工合并；「主题/钩子/爽点」这类解释判断只能出多候选，不能自动定标签。

### 5. 读者体验判定：联合门控，别信单一分（BRIEF_04 回包）

- 推荐「结构证据 + 分布低尾 + 双向成对确认」三关联合：绝对阈值只查机械事实；分布参照只筛候选不单独亮灯；成对比较做最终确认。
- LLM 裁判可靠性实数：系统级排名可用（LitBench 73%，领域奖励模型 78%），单篇不可靠（HANNA 单篇 τ≈0.25）；连续强度打分不可靠，只能粗分高/低。
- ⚠️ 「章末钩子指标 ↔ 真实追读」**没有**同行评审实证（最接近的 Fong 2026 β=.075，弱）。情绪弧与馆藏相关仅 .12~.14。**黄灯永远是启发式提醒，不进硬门，也别给作者报「分数」。**

### 6. 4B→豆包迁移：赢家排名不能白拿，要买一座「排名桥」（BRIEF_06 回包）

- 可外推：合同不变量（字段/证据边界/切分隔离）、方向性信号（清错标、淘汰明显失败者）。
- 🔥 不可外推：**经验赢家排名和最优数值**（数据配比、LR、LoRA 超参）。「4B 会 ⇒ 大模型会」和「4B 不会 ⇒ 大模型不会」都不成立（JSON 格式能力也是）。Dense 代理 MoE 还有额外风险（路由/最优超参不同）。
- 落地含义：4B 的角色定位要收窄为「淘汰器+合同调试器」，不是「选冠军器」。上豆包前要买最低限度的排名桥：**两档各跑 baseline+候选共 4 个 SFT 臂**，贵臂优先花在 P1-01（A vs C2_UNIT）这种会改变路线的比较上。零训练探针（C0/C2 配对、JSON 三路径、泄漏探针）先行。
- 👉 这条建议 Codex 在当前 4B 主线的结论口径里显式写上「赢家待商用档复验」，避免 4B 结果被当成终局。
- ⚠️ 但别把账算反了（CZ 2026-08-09 晚校正）：本地这条线的**主产出是数据集+格式合同，它们正是可迁移资产，全是给 Mini 的准备**；4B 是数据集的调试台，checkpoint 是副产品（另有免费档部署设想，见 03 文件第 5/5b 节）。「待复验」只针对配方排名和最优配比，不针对数据集本体。

### 7. 因果边：反事实法有先例，但要改叫「使能」，连边必须限制动作（BRIEF_08 回包）

- CZ 的「拆前置」反事实判定有直接先例：RED 数据集用「无 A 则无 B」判定，但发现它筛出来的更接近 **PRECONDITION/ENABLE（前置/使能）而不是狭义 CAUSE**。这不是坏事——对「伸缩时什么不能丢」来说，使能关系正是我们要的；但表示里要如实叫「使能」，别都标成「导致」。
- 链长与传递：**只存相邻直接边，闭包当派生视图算，不写直边**（MAVEN-ERE 先例）；链长分级用 1 跳直边 / 2 跳派生 / 3 跳人工审查 / ≥4 只作路径查询——正好实现 CZ 的「限制环数」。
- 边类型分层：MVP 露四种——导致 CAUSE / 使能 ENABLE / 阻止或结束 / 动机 MOTIVATE（动机和事件因果分开）。
- ⚠️ LLM 开放式连边假边率极高（GPT-4 在 MAVEN-ERE 上的**代理指标**约 89.6%——这是「开放抽图」任务的结果，只能证明必须约束动作，**不能**外推成「我们的逐对判定也会错九成」）。约束动作：先程序生成候选事实对，模型只做逐对判定，再过校验器，分阶段跑。
- 「可回退折叠」没有直接先例（最近的是无损图摘要/子事件聚类）——这是我们的原创设计，只能本地实验验证。

### 8. 下游承接：两份回包拼出完整验收结构（BRIEF_02 + BRIEF_09 回包，主脑精读）

两份报告高度互补，合并后的核心结构：

- **事实先分角色**（两套词表合并）：必须实现（MUST_REALIZE≈MUST_ACCOUNT）／必须不违背（MUST_RESPECT≈HARD_CONSTRAINT）／可选支持（OPTIONAL≈BACKGROUND）／干扰控制（IRRELEVANT_CONTROL）；另加两个关键概念：**开放槽 OPEN_SLOT**（材料没给、允许创作填充——防止把合法创意误杀成幻觉）和**阻塞未知 BLOCKING_UNKNOWN**（缺它就不该直接产方案——红线 3 的测试基础）。
- **输出命题分五类**：有支持／冲突／**无依据补写过去或现状**／与事实相容的未来扩写／非事实文本。🔥 知识问答指标搬到小说最大的坑就是把「材料里没有」一律当幻觉；真正要拦的是补写过去和现状，未来扩写是合法创作。
- **CZ 五条红线全部有测法**：
  1. 顾此失彼 → 必须事实覆盖率随条数 N 的衰减曲线 + 中部惩罚（Lost in the Middle 效应）
  2. 违背事实 → **整份方案 Any Hard Conflict 零容忍硬门**，创意分不能平均掉它
  3. 不承认不足 → **独立路由调用**：第一次低温调用只准输出 PROPOSE/ASK_FACTS/SEARCH_FACTS/DECLINE 四选一，结构互斥，只有 PROPOSE 才进第二次生成。⚠️ 别指望模型自觉：AbstentionBench 发现推理微调平均让弃答召回**下降 24%**，「多想」不等于「更会承认不知道」；识别得出 ≠ 会行动（主动澄清率实测普遍 <5%）
  4. 技巧硬套 → Mechanical Rate（技巧出现但功能/时机/事实保持任一失败）；每种技巧冻结功能签名（伏笔=埋设F→触发T→兑现P 三点+时序+移除测试）；T0~T3 四臂对照（不点名/只点名/点名+给功能/故意给不适配的技巧看它会不会拒绝）
  5. 创意 → 只在前四条通过的候选里比，盲化成对+允许平局+按题材分层
- **决策顺序**：硬门（冲突）→ 任务门（必须实现率）→ 质量门（成对胜率）→ 取最小 K。不做总分。
- **剂量实验设计**：每现场 32 条母池（4 必须实现+8 必须不违背+12 可选+8 干扰），A0~A4 嵌套真子集臂；12 现场试跑 → 40 现场筛 → 120 现场正式 A/B；样本单位是「独立故事现场」，种子和裁判票不算 N。
- **模型候选**：首轮四家 GPT-5.6 Sol / Gemini 3.1 Pro / Claude Opus 5 / Qwen3.8 Max；Kimi/DeepSeek/豆包保留翻盘位。⚠️ 全部排名是「测试优先级先验」不是行业结论，本地红线数据可随时翻盘。
- **自动验收栈**：确定性规则（死活/时序/数字，高精度当硬门）→ 相关事实小包检索+NLI → 异构双 LLM 裁判（引原文+fact_id）→ 不一致样本+高严重度全人工，一致样本抽 10~20% 估漏检。
