# 调研报告 04｜“情绪不够、钩子不强、期待感弱”能不能自动判定？

> 调研日期：2026-08-09  
> 对应任务：`BRIEF_04_reader_experience_metrics.md`  
> 结论性质：研究建议，不覆盖项目已有决策；所有软性判断仍是可豁免黄灯。

## 一句话结论

**可以自动筛出一部分“明显可疑”的章节，但现在没有可信的通用分数或固定阈值。** 最合适的做法是：从大纲中提取可核查的结构信号，用同题材、同章节功能的本地分布找低尾异常，再与作者确认过的“刚好可接受”样例做双向成对比较；只有多路证据一致时才亮黄灯，其余情况弃权。

学界能提供“该测什么”和“哪些近似算法有道理”，不能直接提供“都市爽文每章至少 3 次转折”这样的生产标准。真正的阈值必须用目标作者、目标读者和真实追读数据校准。

## 1. 决策摘要

| 问题 | 调研结论 | 产品决策建议 |
|---|---|---|
| 能否判断“情绪一直平着” | 能做粗粒度异常筛查；文本正负情绪不等于读者情绪，单一情感词典不够 | 测读者侧唤醒度变化、显著反转、长平段；只与同类分布比较 |
| 能否判断“章末钩子偏弱” | 未决问题、风险、信息缺口都可提取，但没有任何一个代理指标单独等于追读 | 用“高风险未决项 + 预期唤醒 + 边界样例比较”的组合 |
| 能否给 1–10 分 | 不可靠。创意评价的人类一致性本就有限，LLM 对单篇故事的连续分数更弱 | 不向作者展示总分，不用单次分数触发提醒 |
| 六种情绪弧线能否当规范 | 不能。原研究是整书、英文、10,000 词窗口，且作者明说情绪弧线不等于情节 | 只作研究背景，不作章节模板或黄灯依据 |
| “高分作品平均 N 次转折”能否当标准 | 分布可说明“少见”，不能证明“差”或“会掉留存” | 用中位数、MAD、分位数；按题材、章节功能、字数、章节位置分层 |
| LLM 适合扮演什么角色 | 适合结构提取、二值检查、相对比较和说明证据；不适合做审美裁判 | 允许平局与弃权，交换 A/B 顺序，要求引用 beat ID |
| 第一版应做什么 | 两种窄任务比一个“章节质量分”更容易验证 | 先验证两种候选黄灯：① 情绪变化可能偏平；② 章末续读动机可能偏弱 |

### 推荐方案

1. **先判定本章是否需要钩子。** 结算章、余韵章、刻意反高潮、作者标记的过渡章可直接跳过或换参照组。
2. **从大纲结构中取证。** 提取场景/beat、读者已知信息、角色目标、风险、未决问题、章末状态变化，不让模型只凭文风打印象分。
3. **查同类分布。** 低于同类低分位只进入候选，不直接亮灯。
4. **做边界样例比较。** 候选与两个“刚好可接受”的同类样例分别比较；A-B、B-A 都判同一方才算有效。
5. **要求联合证据。** 至少一个结构信号和一个读者体验信号指向同一问题，才允许出现黄灯。
6. **不确定就安静。** 顺序翻转、证据段落不一致、上下文不足、模型之间分歧，全部归为 `abstain`。

## 2. 证据等级

下文的“可靠性”按与本产品问题的距离分级：

| 等级 | 含义 | 能支持什么 |
|---|---|---|
| A | 连续阅读中的真实行为，或控制实验中的继续阅读选择 | 候选产品信号，但仍需中文网文复验 |
| B | 人类悬念/情绪评分，或跨媒介、跨领域的阅读/成功关联 | 可作黄灯的辅助证据，不能直接搬阈值 |
| C | 形式理论、计算模型、自动指标与人类评分的相关性 | 支持特征设计与算法原型 |
| D | 技术可行性、词典或模型演示，没有目标人群与追读验证 | 只适合研发探索 |

公开研究中，**还没有 A 级证据证明“中文连载网文章末有 N 个未决问题 / N 次揭示 / N 次情绪转折，就会提高追读率”。** 最接近的直接证据是 2026 年一项英文故事实验：读者对下一章“唤醒度”的期待，与是否继续读可选第三章有关；这仍不是对某一种钩子结构的因果验证。

## 3. 先把几个容易混淆的概念分开

| 概念 | 实际测量对象 | 不等于什么 |
|---|---|---|
| 文本情感极性（valence） | 文字表达得偏正面还是偏负面 | 情绪强度、悬念、读者是否兴奋 |
| 唤醒度（arousal） | 平静—激动/紧张的能量水平 | 正面—负面 |
| 角色情绪 | 某个角色此刻的感受 | 读者情绪、叙述语气 |
| 读者侧预期情绪 | 读者读到此处后，预期下一段会有多紧张、兴奋或激烈 | 文中出现多少情绪词 |
| 悬念（suspense） | 对有利/不利结果的期待、风险与不确定性 | 单纯意外 |
| 好奇（curiosity） | 读者意识到一个自己想填补的信息缺口 | 问号数量 |
| 惊奇（surprise） | 新信息到来后，读者对原先判断的回看式更新 | 对未来的期待 |
| 钩子（hook） | 促使读者采取“继续读”这一动作的整体动机 | 必须停在生死瞬间的悬崖结尾 |
| 悬崖结尾（cliffhanger） | 在高风险动作或答案到来前切断叙述的一种话语安排 | 所有有效钩子 |

这套区分与项目已有的真相层设计很合拍：计算悬念、信息缺口和钩子时，应读取 `READER` 已知什么，而不是只读取角色知道什么；钩子也应继续与故事义务分开。研究显示，小说中的叙述与对话情绪轨迹可能几乎不相关，进一步说明“把所有文字混成一个情感分”会丢掉关键层次。[Vishnubhotla et al., 2024](https://aclanthology.org/2024.findings-acl.150/)

## 4. 情绪曲线研究：什么能用，什么不能用

### 4.1 Reagan 六种基本弧线只适合当研究起点

[Reagan et al.（2016）](https://link.springer.com/article/10.1140/epjds/s13688-016-0093-1)分析了 1,327 本英文 Gutenberg 小说，使用 labMT/Hedonometer 对滑动的 **10,000 词窗口**计算情感值，归纳出上升、下降、下降—上升、上升—下降、上升—下降—上升、下降—上升—下降六类主要形状。

它不能直接下放成章节标准，原因很明确：

- 数据单位是 20,000–100,000 词的整本书，不是 2,000–4,000 字的一章或一个场景。
- 论文明确提醒，词典法在单句上可能比随机还差，要靠大窗口平均；短促的一段情绪高潮可能完全抓不到。
- 情绪弧线描述文字唤起的正负变化，不能反推具体情节。
- “成功”用 Gutenberg 下载量近似，受经典作品、曝光和少数离群书影响，不是章末追读。
- 六种形状是语料中的常见模式，不是好故事的合格模板。

结论：**不能用“偏离六类弧线”亮黄灯，也不能从原论文推导每章应有几次转折。**

### 4.2 后续研究给了两个更有用的方向：变化幅度与显著反转

[Berger、Kim 与 Meyer（2021）](https://academic.oup.com/jcr/article-abstract/48/2/235/6146928)把相邻段落情感变化称为 sentiment volatility。研究覆盖 4,000 多部电影、30,000 多篇在线文章，并用实验操纵变化顺序：情感波动更高与电影评价、文章继续阅读有关，实验也支持“刺激感”这一机制。它是很有价值的 B/A 邻近证据，但在线文章不是连载小说，情感分析仍是文本极性，而且效果会随题材变化。

[Knight、Rocklage 与 Bart（2024）](https://www.science.org/doi/10.1126/sciadv.adl2013)在近 30,000 个电影、电视剧集、小说和募款故事中，用趋势检测寻找正负走向的反转；更多、更大的反转与评分、下载或筹款成功有关。电视剧还做了同一剧集内比较。局限同样明显：这是观察关联，不是章末留存；小说仍用 10,000 词窗口，词语极性也可能把“坏事发生在坏人身上”误读成单纯负面。

这两项研究支持把“长度归一的变化幅度、显著反转数和反转幅度”列为候选信号，但不支持“越多越好”或固定 N。

### 4.3 场景/短篇尺度的最大风险是篇幅混淆

短文本里，转折数很容易只是字数的替身：文字越长，可检测的峰谷自然越多。[Somasundaran et al.（2020）](https://aclanthology.org/2020.nuse-1.12.pdf)的数据集原有 942 篇平均约 320 词的学生叙事，其中 25 篇因不足 50 词被剔除，弧线分析有效样本为 917 篇。峰/谷数与人类质量分的原始相关约为 .54；控制篇幅后变为 −.016/−.011。加入弧线特征也只让自动评分 QWK 从 .656 增到 .676。这说明计数分析必须显式控制篇幅：可把字数、有效事件数或 beat 数作为协变量、offset 或分层变量；简单相除也可能留有偏差，仍须验证。局部抖动还要用最小幅度和持续时间过滤。

更可控的候选组合是：

- 唤醒度或极性的稳健范围：`Q90 - Q10`；
- 平均相邻变化：`sum(|x_t - x_{t-1}|) / (K-1)`；
- 跨过噪声带的显著反转数，而不是所有斜率换向；
- 最长平段占比；
- 章末相对前几个 beat 的抬升或下降。

这些是产品原型公式，不是论文给出的通用阈值。

### 4.4 中文研究和工具现状

[Liu（2024）](https://www.nature.com/articles/s41599-024-03147-6)分析了 66 篇中文科幻短篇，用 Jieba 和大连理工情感词汇本体把每篇分成五个等字数段，计算七类情绪、极性、丰富度与曲折度。它展示了在中文科幻文本上构造粗粒度词典曲线的可操作性，不证明曲线准确反映角色或读者情绪。研究目标是比较作者群体，不是验证算法准确率、章节质量或读者留存。固定分块也会切断场景，难以处理反讽、含蓄表达和情绪归属。

更直接的网文研究也没有给出“情绪强 = 追读高”的证据。[Yu、Pianzola 与 Zhang（2026）](https://doi.org/10.26083/tuda-7994)分析起点中文原作与 WebNovel 英译本的免费开篇：段落文本情感预测评论情感的线性模型 `R²=.001`，加入进度、平台、交互和书级差异后的完整 GAM `R²=.142`；约 77% 的段落还因评论稀疏被排除。它测的是文本情感与评论情感是否同向，不是下一章留存或评论数量。[代码](https://github.com/GOLEM-lab/Qidian-Webnovel-sentiment)

可用组件如下：

| 工具/资源 | 能做什么 | 对本任务的限制 |
|---|---|---|
| [SnowNLP](https://github.com/isnowfy/snownlp) | 轻量中文正负情感概率 | 官方说明训练数据主要是买卖评价，对其他领域效果可能不好；不适合直接判小说 |
| [大连理工情感词汇本体](https://ir.dlut.edu.cn/zyxz/qgbtk.htm) | 七大类、细粒度情感词与强度，可作可解释词典特征 | 词义、否定、反讽、视角和上下文有限；官方页面标明仅供科研及教学使用，商业授权状态未说明，商用前须取得权利方书面许可 |
| [SKEP](https://aclanthology.org/2020.acl-main.374/) / [Senta](https://github.com/baidu/Senta) | 情感知识增强的预训练模型与工具 | 公开评测是通用情感任务，不是中文小说的读者侧动态 |
| [EmotionArcs](https://aclanthology.org/2024.latechclfl-1.7/) / [代码](https://github.com/yuri-bizzoni/EmoArc) | 多情绪、整书轨迹和可复现实验 | 英文小说；人工验证规模小，未验证追读 |
| [trendet](https://github.com/alvarobartt/trendet) | 按参数化窗口标注数值序列的上/下趋势，可据方向切换操作化“反转” | “显著”只指规则筛选，不是统计显著；输入情感值与窗口阈值都须在中文章/场景尺度重建 |

**检索结论：截至 2026-08-09，没有找到可直接用于生产的“中文网文章节/场景情绪弧线模型”，同时具备中文小说人工金标、目标读者一致性和真实追读验证。** 现有工具更适合做特征候选或标注辅助。

## 5. 悬念与好奇：学界怎样把它们变成可计算对象

### 5.1 三条主线

| 理论/模型 | 核心定义 | 可落地的近似 | 证据边界 |
|---|---|---|---|
| 信息缺口理论 | 好奇来自“我知道自己缺什么，并想得到答案” | 提取读者可明确表述、答案被认为可获得、且有价值的未决问题 | 不是问号计数；理论不提供章末阈值 |
| 信念变化模型 | 悬念是对下一时刻信念大幅变化的预期；惊奇是已经发生的信念更新 | 生成几个合理后续，估计结果分布、风险与下一步可能的更新幅度 | 状态空间和概率很难可靠估计 |
| 计划/解法模型 | 可行解越少、失败后果越重、角色越接近无路可走，悬念越高 | 提取目标、阻碍、可行方案数、失败概率与代价 | 早期系统依赖人工知识工程；LLM 估计仍会漂移 |

[Loewenstein（1994）](https://doi.org/10.1037/0033-2909.116.1.75)的信息缺口理论说明：真正能激起好奇的不是“有未知”，而是未知被读者意识到、具有价值，且读者相信继续投入能获得答案。由此可知，章末未决问题应按显著性、利害、具体性和可回答性加权。

[Ely、Frankel 与 Kamenica（2015）](https://www.journals.uchicago.edu/doi/abs/10.1086/677350)把悬念写成对未来信念变化的期待，把惊奇写成当前相对之前的信念变化。形式很漂亮，但它是理论模型，不是现成的小说 API。

[Cheong 与 Young（2006）](https://cdn.aaai.org/AAAI/2006/AAAI06-331.pdf)等计划式叙事模型，把悬念近似为角色可用解法减少；[Xie 与 Riedl（2024）](https://aclanthology.org/2024.eacl-long.147/)进一步讨论希望、恐惧、不确定性和读者—角色知识差。对本项目最实用的启发是：**危机升级不只是“坏事更大”，还包括可行路径变少，而且必须从读者已知信息来算。**

### 5.2 一条有效的神经近似：未来状态的预期变化

[Wilmot 与 Keller（2020）](https://aclanthology.org/2020.acl-main.161/)在约 30 万篇 WritingPrompts 短篇上训练层级模型，并对 200 篇故事做逐句人类悬念标注。五名标注者的 Krippendorff α 约为 .52–.57，说明任务本身主观；最佳模型对一步后续的 Ely 表征状态变化做概率加权，测试集 Spearman 约 .71，接近该数据中的人类上限。概率熵减少的两个版本只有约 `.051/.088`，所以不能把“熵下降”直接当成悬念实现方案。

这个结果不能简单复制到中文网文章末：

- 训练数据是英文 Reddit 短篇，不是长连载大纲；
- 需要为每个位置采样或估计可能后续，成本较高；
- “接近人类上限”只在该标注协议与语料内成立；
- 后来的预印本复现实验发现，现代 LLM 能粗分高/低悬念；部分数据中的相邻段粗方向有一致性，但连续强度、整体升降轨迹、关键拐点和依赖全篇铺垫的段落都不可靠。[Matlin et al., 2025](https://arxiv.org/html/2508.15794v1)

所以，这类未来状态变化模型适合研发实验，不适合第一版单独触发黄灯。

### 5.3 更便宜、也更容易解释的近似：活跃问题账本

[Potentially Inquiry-Terminating Questions（PITQ）研究](https://www.cambridge.org/core/journals/language-and-cognition/article/linguistic-basis-of-narrative-suspense-narrative-suspense-depends-on-potentially-inquiryterminating-questions/5EE1B5222149BEC6D76B2BB4C354F67C)把悬念拆成宏观问题及其临近子问题。例如，“主角能否逃脱？”是宏观问题，“守卫会不会发现钥匙？”是可能提前决定宏观答案的子问题。问题被提出、刷新或部分回答会增加活跃度；长期未触及则衰减。四篇德语文学文本中，该指标显著预测连续人类悬念评分，第一项研究边际 `R²=.459`、条件 `R²=.481`。[开放数据](https://doi.org/10.17605/OSF.IO/YJ2Z7)

它比“有几个坑”更接近读者体验，但仍只验证了主观悬念，不是追读，而且标注者对问题数量会有分歧。适合本项目的改写是：

```text
问题 ID / 问题文本 / 宏观问题 ID
opened_at / last_refreshed / status(open, partial, closed)
读者是否意识到 / 重要性与后果 / 可能答案
看起来何时会回答 / 证据 beat ID / 抽取置信度
```

每个问题的候选活跃度可写成：

`Q_j = importance × reader_salience × answerability × outcome_difference × exp(-λ_g × distance)`

这里的 `λ_g` 应按题材和节奏用本地数据校准。章末只取最高的 1–2 个问题并做递减加权，不把全部问题相加，避免“挖很多小坑”得到虚高分。这是从 PITQ 和信息缺口理论推导的产品公式，不是已有行业标准。

### 5.4 危机升级应测“后果 × 退路收窄 × 仍有不确定性”

计划式悬念模型表明，负面结果临近、可行解法减少、剩余解法成功率降低时，悬念会上升。[Dramatis](https://cdn.aaai.org/ojs/8836/8836-13-12364-1-2-20201228.pdf)

因此“危机升级”的近似应是：

`crisis ≈ consequence_severity × path_narrowing × residual_uncertainty`

不是敌人、伤害或“危险”一词出现多少次。完全无解、角色失去能动性的局面也可能让读者退出，而不是更想追下去。

## 6. 哪些代理指标真的碰到了“继续读”

### 6.1 最接近目标的直接证据：预期唤醒度

[Fong、Gui 与 Yang（2026，v4）](https://arxiv.org/html/2412.15239v4)招募 263 名参与者，每人阅读两篇故事的两个章节，得到 1,052 条参与者—章节层面的兴趣/期望记录，以及 526 次是否愿意额外花 1–2 分钟阅读可选第三章的真实选择。

- 人类报告的下一章预期唤醒度预测继续阅读：`β=.075, p<.05`。
- 由 LLM 想象后续得到的预期唤醒度：`β=.077, p<.10`。
- 预期正负效价不显著。
- 未来结果的不确定性也不显著。
- 在 200 个独特章节的聚合回归中，LLM 对人类预期效价、唤醒度的拟合斜率为 .571、.563，`R²=.369/.297`，显示中等程度的一致。
- LLM 不确定性几乎不能解释人类不确定性：`R²=.005/.0004`。

这是目前与“下一章选择”最接近的公开证据，但仍是单篇预印本、英文短篇实验和一次额外阅读决定，不能等同于中文网文的长期留存。论文也明确把结果称为关联而非单一特征的因果效应。

论文的平台样本为 8,399 章、937 本书，但只保留 vote/read 与 comment/read。作者发现重传章节会重置阅读数，因此主动剔除了 continue-to-read。旧版本里更大的章节样本和平台追读数字不应再当作证据。

### 6.2 Cliffhanger 的结果并不稳定

- 两项随机书面故事实验（`N=202`、`N=273`）中，cliffhanger 比“主角获胜”结局提高了观看未来篇章的愿望，但没有提高享受度或自报悬念。[Media Psychology](https://doi.org/10.1080/15213269.2023.2219456)
- 电视剧连续观看实验（`N=133`）中，cliffhanger 提高生理唤醒，却没有提高继续观看意图。[研究页面](https://folia.unifr.ch/unifr/documents/319990)

因此可说“cliffhanger 有提高即时唤醒和部分自报后续兴趣的证据”，不能说“cliffhanger 稳定提升真实章节留存”。

### 6.3 跨领域旁证支持唤醒与变化，但不能替代网文验证

[What Holds Attention（2023）](https://journals.sagepub.com/doi/10.1177/00222429231152880)结合 60 多万次在线阅读事件与控制实验，发现高唤醒、带不确定性的情绪更能维持阅读，而低唤醒的悲伤会抑制阅读。材料主要是网络文章，不是连载小说。

电竞直播中，悬念也与观众更不容易离开有关，惊奇效应较小。[Simonov、Szymanski 与 Wiertz（2023）](https://journals.sagepub.com/doi/abs/10.1177/00222437221108653)这说明 Ely 式悬念能碰到真实停留行为，但游戏胜负状态远比开放式小说容易建模。

### 6.4 中国网文公开数据的空白

[Qidian-Webnovel Corpus](https://openhumanitiesdata.metajnl.com/articles/10.5334/johd.368)收录 110 部中英网文、2,791,837 条中文评论以及段落定位，适合做读者反应研究。但样本由完结、热门、至少 200 条评论的作品筛出，且没有每个读者到达章末后的追读分母；评论数据还受 DTA 限制，只供大学/非营利研究。它不能直接充当商业训练集，也不能拿评论量替代留存。

行业实践能提供结果指标思路。[七猫/纵横作家中心](https://news.zongheng.com/news/23393.html)把平均留存率、章节留存率和万字留存率归入“内容质量分析”；一项中国专利也用后续若干章的解锁流失、评论和翻页速度定位问题。[专利 CN114971741A](https://patents.google.com/patent/CN114971741A/zh)这些材料没有公开样本、系数或独立验证，只能说明“先看行为结果，再回查内容”比“用钩子计数推导留存”更接近行业做法。

截至本次检索，没有找到公开同行评审研究能证明，以下任一指标在控制作者、作品、付费墙、更新节奏、推荐流量和章节位置后，独立预测中文网文下一章阅读或解锁：

- 章末未决问题数量；
- 新信息揭示数量；
- 危机升级次数。

## 7. 可用指标清单

表中的公式用于定义可测对象，阈值都需要本地校准。

| 指标 | 测什么、怎么算 | 证据 | 黄灯适用性 | 主要误报 |
|---|---|---|---|---|
| 读者侧唤醒范围 | 对 K 个 beat 标注预期读者唤醒 `a_t`；`Q90(a)-Q10(a)` | 产品假设；Fong 不验证章内范围，暂无直接追读证据 | **实验候选**；只能与同类比较，不能单独触发 | 克制、幽默、低声量恐怖、静默揭示 |
| 平均绝对相邻变化（产品定义） | `MAV = Σ|a_t-a_(t-1)|/(K-1)`；VAD 向量须先统一各维量尺再取距离 | Berger 的 volatility 是相邻文本效价差的标准差；Liu、Knight 提供跨媒介邻近依据，但都未验证本公式或 beat 级读者唤醒 | **实验候选**；需另一信号族确认 | 高频但无意义的情绪抖动、场景切碎 |
| 显著情绪反转 | 平滑后只计跨过噪声带、持续足够 beat 的斜率换向；同时记录幅度 | 跨媒介成功关联；Somasundaran 证明原始计数受篇幅混淆 | 可作辅助；**不能定 N** | 长章天然更多、反转不代表因果转折 |
| 最长平段占比 | 最长连续满足 `|a_t-a_(t-1)|<ε` 的转移数 / `(K-1)`；`ε` 从本地标注噪声估计 | 算法推论 | 可辅助“情绪变化偏平” | 有意余韵、信息章、表层平静内里变化 |
| 章末预期唤醒 | 让目标读者判断读完结尾后对下一章的能量期待；模型值只作代理，更适合相对比较 | Fong 2026 是最接近追读的证据，但人类值显著、LLM 值仅边缘显著，且未验证中文网文 | **本地人类验证候选**；LLM 估计不能单独触发 | 读者分群、模型不确定性失真、题材差异 |
| 加权活跃问题 | 对每个 open/partial 问题算 `Q_j`，取 Top 1–2 | 信息缺口理论、PITQ 人类悬念曲线 | **钩子黄灯的结构主信号** | 谜团已陈旧、作者故意收束、读者没意识到问题 |
| 宏观问题临近终止 | 子问题某个答案是否会大幅决定宏观问题，且答案被延迟 | PITQ | 适合解释“为何可能有悬念” | 多线叙事、答案并不重要、假二选一 |
| 危机/退路收窄 | `后果 × 可行路径减少 × 仍不确定`，比较章初与章末 | 计划式悬念模型 | 只作联合信号 | 完全无解、角色无能动性、单纯堆危险词 |
| 预期状态变化 | 生成一步可能后续，按概率加权当前与后续叙事状态的表征距离 | Wilmot 2020 的 Ely 版本与该数据内人类悬念相关较高 | **实验项**；距离定义、成本和漂移都要重验 | LLM 后续分布不代表目标读者 |
| 结果熵/不确定性 | 对可能后续分支概率算熵或方差 | 熵能描述分支分散，但 Wilmot 的熵减少版本表现很差；Fong 的 LLM 不确定性也不匹配人类、不预测其实验中的继续读 | 不单独亮灯 | 高熵可能是混乱，不是好奇；模型分布过窄 |
| 揭示类型 | 每次信息更新标 `resolve/narrow/reframe/open/raise_stakes` | 叙事理论与产品推论 | 适合解释，不计原始数量 | 兑现承诺会关闭问题，却可能提高满意度 |
| 惊奇/信息增益 | 比较揭示前后的预期分布变化 | Ely 理论；回看式指标 | 可查“揭示是否意外”，**不等于钩子** | 无铺垫随机转折也会很意外 |
| 问号或疑问句数 | 文字表层计数 | 没有追读验证 | **拒绝** | 修辞问句、对白、没有问号的强缺口 |
| 六类弧线匹配度 | 与 Reagan 六型的距离 | 整书描述研究 | **拒绝** | 章/场景尺度错误，把创新当偏差 |
| LLM 整体 1–10 分 | 直接询问“情绪/钩子几分” | 单篇与人类相关有限；悬念数值和拐点不稳 | **拒绝作为触发器** | 位置、文风、长度、自我偏好、分数压缩 |

### 第一版研究原型只验证两种候选黄灯

**A. 情绪变化可能偏平**

- 适用前提：章节功能不是余波/结算/刻意克制；当前 beat 数与分段方案下，曲线指标经重分段或重测后足够稳定。`K=3` 时默认只做结构抽取，不触发曲线黄灯；其他最小样本数按指标单独校准；
- 曲线候选：`MAV`、唤醒范围、最长平段属于同一个“曲线异常家族”，合并成一个候选信号，不能把三者当成三份独立证据；
- 联合条件：曲线家族落入同类异常尾部，并且另一信号族也支持“变化偏少”，例如重要状态/目标/关系没有位移，或目标读者的双向边界比较一致偏平；
- 取消条件：主角/读者状态发生显著位移，或分轨结果显示“表层平静、内在变化明显”；
- 文案只说“变化信号偏少”，不说“情绪不够”。

**B. 章末续读动机可能偏弱**

- 适用前提：大纲明确要求本章承担续读钩子；
- 结构候选：章末没有近期活跃且重要的问题，或主要问题全部关闭且没有替代动机；
- 读者体验候选：与两个边界样例做双向成对比较，结果一致偏弱；人类预期唤醒可辅助校准，LLM 低唤醒不能单独触发；
- 联合条件：结构证据与来源不同、且离线验证有增量信息的读者体验/成对证据同时成立；
- 文案指出关闭了哪个问题、缺少哪类继续动力，允许作者选择“这是有意收束”。

## 8. LLM-as-judge 到底可靠到什么程度

### 8.1 总体判断：能筛查，不能裁决

| 研究 | 关键结果 | 对本产品的含义 |
|---|---|---|
| [LitBench（EACL 2026）](https://aclanthology.org/2026.eacl-long.362/) | 43,827 个训练故事对、2,480 个测试对；最强通用零样本评审与人类偏好一致率 73%，领域训练奖励模型 78% | 连“哪篇更好”这种粗比较仍有明显分歧，只够做低风险筛查 |
| [Psychological Depth Scale（EMNLP 2024）](https://aclanthology.org/2024.emnlp-main.953/) | 97 篇故事、5 名训练评审；人类 α 平均 .72。GPT-4o 多角色平均与人类 `ρ=.51`，情绪唤起约 .57，参与感约 .42 | 情绪唤起只有中等一致；参与感更弱 |
| [HANNA](https://aclanthology.org/2022.coling-1.509/) / [后续 LLM 评审研究](https://aclanthology.org/2024.tacl-1.62/) | 1,056 篇故事；人类在六维度 ICC 约 .28–.56。该研究中 Beluga-13B 单篇平均 Kendall τ 约 .25；聚合 1,000 多篇后对生成系统的排序约 .70，但系统级提升的统计证据较弱 | 单篇裁决弱；大量聚合后的系统排序不能证明单章判断可靠 |
| [悬念人类实验复现（2025）](https://arxiv.org/html/2508.15794v1) | 预印本；能粗分高/低悬念，连续数值误差大，整体轨迹与关键拐点不可靠 | 只支持实验性二值检查；未在长篇中文连载或章末钩子上验证 |
| [Rating Roulette（EMNLP 2025）](https://aclanthology.org/2025.findings-emnlp.1361/) | 在 MT-Bench 聊天回复成对评价中，三种评审模型重测 α 仅 .265–.563；最佳模型三次完全相同约 61.3% | 说明单次 LLM 评审会漂移，但这些数字不是故事或情绪评分结果 |

人类本身也没有统一审美金标。[The Reader is the Metric（2025）](https://aclanthology.org/2025.findings-acl.1304/)发现普通读者与专家会形成不同偏好簇：普通读者更看重可读性，专家更看重主题、修辞和复杂情感。这意味着参照库必须匹配目标读者，不能拿“文学专家平均分”代替产品用户。

### 8.2 成对比较优于绝对分，但要防顺序偏差

[PairS（COLM 2024）](https://arxiv.org/html/2403.16950v5)在 HANNA 的连贯、惊奇、复杂度上，把 GPT-4 Turbo 与人类的 Spearman 相关从绝对评分约 `.35/.28/.38` 提升到 PairS-beam 排名约 `.44/.36/.49`。该实验使用大规模集合排序，不是“候选与两个边界锚点各比较一次”；它支持研究成对排名，但不直接验证本文的两锚点黄灯协议。

顺序偏差非常实际。[MT-Bench](https://arxiv.org/html/2306.05685v4)的写作任务中，交换 A/B 后，GPT-4 只有约 42% 保持相同选择，约 46% 偏向先出现的答案。因而每一对都要跑：

- `candidate → anchor`；
- `anchor → candidate`。

两次赢家不同，结果就是“不确定”，不能随机选一个。成对判断还可能不传递：A 胜 B、B 胜 C，不保证 A 胜 C，所以不应建立看似精确的全局排行榜。

### 8.3 少样本锚定主要改善稳定性，不保证更接近人类

MT-Bench 加入三个示例后，交换顺序一致性从 65% 增至 77.5%，但与人类的一致性没有同步改善；在该组三示例长提示实验中，成本约增至四倍，不能当成通用成本倍数。更有希望的是给出质量接近的参照文本：[自动创意评价研究（2025）](https://aclanthology.org/2025.findings-emnlp.1171/)中，Claude 3.5 的成对准确率从 .64 增至 .75，Spearman 从 .14 增至 .49；但基准围绕 12 篇《纽约客》原作及其 LLM 生成版本构建，不能直接外推到中文网文。

产品侧可优先试验质量较高、与候选差距不过大的参照，并另外测试作者或编辑确认的“刚好可接受”章末。边界锚点是否优于强参照仍是产品假设，必须单独验证。

### 8.4 推荐的 LLM 评审协议

1. **结构抽取与审美判断分开。** 抽取器只回答可核查问题：哪个问题仍开放、哪一 beat 提高风险、章末改变了什么。
2. **试验二值清单，不用整体 Likert 分。** [CheckEval（2025）](https://aclanthology.org/2025.emnlp-main.796/)在摘要与对话任务中显示，把主观维度拆成可追溯的二值问题能提高评审一致性；长篇叙事仍是待验证场景。
3. **相对比较边界样例。** 问“哪一个章末让目标读者产生更具体、更强的下一步期待”，允许平局。
4. **交换顺序。** 任何顺序翻转都弃权。
5. **只为候选黄灯追加成本。** 分布未异常时不做多次评审；进入低尾后要求双向顺序一致，并由预先选定的跨模型家族评审复核。重复一致不等于接近人类，最终聚合规则和门槛仍要在人工标注集上校准。
6. **说明必须引用 beat ID。** 程序核对引用是否真的存在；解释流畅不等于证据正确。
7. **显式输出 `abstain_reason`。** 如 `insufficient_context`、`order_inconsistent`、`judge_disagreement`、`intentional_quiet_chapter`。

## 9. 绝对阈值、分布参照、成对比较怎么选

| 方案 | 优点 | 风险 | 建议用途 |
|---|---|---|---|
| 绝对阈值 | 快、稳定、容易解释 | 审美量没有通用零点；跨题材、篇幅、章节功能误报高 | 只检查机械事实，如“要求的章末义务是否缺失”，不用来判强弱 |
| 同类分布 | 能适应题材和写作功能，适合发现异常 | 只能说明少见；会复制平台偏见、幸存者偏差和流量混杂 | 作为候选筛选层，不单独亮灯 |
| 成对比较 | 比 1–10 分更贴近偏好，锚点易理解 | 顺序、参照质量、非传递性、成本 | 用于低尾候选的确认层 |
| 联合方案 | 能把误报压低，理由可追溯 | 研发和校准成本更高，覆盖率会下降 | **推荐**：结构证据 + 分布低尾 + 双向成对一致 |

### 推荐触发逻辑

```text
if 本章不要求该类读者效果:
    no_light
elif 抽取覆盖不足 or 指标在重分段/重测下不稳定:
    abstain
elif 不足两个来源不同、且离线验证有增量信息的信号族落入同类异常尾部:
    no_light
elif 与边界样例的 A-B / B-A 结果不一致:
    abstain
elif 结构证据与相对判断指向同一问题:
    yellow
else:
    abstain
```

启动实验可以把同类 `P10/P90` 当“进入复核”的待调超参，不能直接当亮灯线。正式阈值应由目标精确率反推；联合门控是否真的降低误报，要报告实际假阳性率、精确率和覆盖率，不能由“两个信号”自动推出。

## 10. 怎样建立“同类型作品分布参照”

### 10.1 参照组至少要匹配这些维度

| 维度 | 为什么要匹配 |
|---|---|
| 子题材与目标读者 | 悬疑、都市爽文、日常、恋爱、恐怖的期待机制不同 |
| 章节功能 | 开篇、铺垫、升级、高潮、结算、余波不能用同一条线 |
| 章节位置 | 第 1–3 章与第 80 章承担的引导任务不同 |
| 字数与有效 beat 数 | 原始转折/揭示计数强烈受长度影响 |
| 免费/付费与平台机制 | 付费墙、广告、章节重传会改变留存分母 |
| 作者/作品阶段 | 名气、存量粉丝、更新稳定性会混入成功指标 |
| 更新间隔与库存章节 | 没有下一章可读不应算钩子失败 |

参照最好分三层保存，不混成一个平均数：

1. **作者个人已接受样例**：最能表达其风格与有意克制；
2. **目标读者确认过的边界样例**：用于判断“刚好可接受”；
3. **权利清晰的同类作品样本**：用于经验分布和外部对照。

统计上使用中位数、IQR/MAD 与经验分位数，不用均值硬切。小样本分层向更宽题材分布收缩，避免某个细分组只有十几章却产生虚假的精确阈值。

### 10.2 “高分作品”不能单独定义正常

高分、评论多、下载多会混入作者知名度、年代、曝光、推荐和幸存者偏差。EmotionArcs 表 2 中，七类情绪总强度与图书馆馆藏数的 Spearman 相关只有约 `.12–.14`（总熵为 `−.12`）；论文随后按馆藏/评分数 `<100` 与 `>500` 分组，组内相关变大，但作者也说明这些切点是任意选择。选择分组后存在相关膨胀和不可外推的风险，不能据此设生产阈值。

更稳的参照设计同时保留：

- 广泛同类作品的分布；
- 同类高表现作品的分布；
- 作者自己的接受分布。

若三者冲突，向作者说明冲突，不把“高表现作品常见”写成“正确写法”。PairS 只显示：HANNA 连贯性五档分布在约 100–200 个随机排名锚点时趋于稳定；这些不是 few-shot 示例、边界样例或本产品标注预算，不能推导每个题材需要多少样本。

### 10.3 真正的结果标签

平台数据可得时，优先使用：

- 到达本章结尾的读者中，下一章开始率；
- 下一章完成率；
- 同一阅读会话继续率；
- 次日 / 7 日回访；
- 付费解锁率。

“本章打开数”不是合格分母；评论率、投票率只作次级标签。模型还要控制推荐曝光、作者/作品固定效应、章序、篇幅、更新间隔、免费/付费、库存章节和新老读者。

## 11. 误报清单与保护措施

| 误报场景 | 为什么会误判 | 保护措施 |
|---|---|---|
| 结算、余波、哀悼、休息章 | 合理功能就是降低能量或关闭问题 | 章节功能前置门；与同功能章比较 |
| 克制、反讽、潜台词 | 情绪不写在词面上 | 分开文本、主角、读者三条轨；引用状态变化 |
| 平静但高压的恐怖/悬疑 | 低动作、低词汇唤醒仍可高期待 | 加权活跃问题和后果分支可以抵消“平”信号 |
| 日常、治愈、切片生活 | 续读可能来自陪伴与角色依恋，不是危机 | 增加题材专属钩子类型；不要强制危机升级 |
| 完整兑现重要承诺 | 问题关闭会让开放项减少，但满意度可能上升 | 把揭示分类；允许“兑现一个、推进另一个” |
| 多 POV、非线性叙述 | reader/character knowledge 不一致 | 按 `READER` 与 POV 分轨，不混总分 |
| 很短或场景极少的章节 | 曲线指标在重分段或重测后不稳定 | 曲线部分弃权；`K=3` 默认仅做结构抽取，其他最小样本数按指标校准 |
| 信息很多但都不重要 | 揭示数虚高 | 只记改变重要问题或状态的揭示 |
| 危险很大但完全无解 | 风险词很多，读者却可能放弃 | 同时要求剩余不确定性和角色能动性 |
| 有意反高潮或文学偏离 | 同类低尾可能正是风格选择 | 作者意图与个人样例优先，黄灯可永久豁免该模式 |

黄灯也不应在每次局部编辑后重复出现。沿用项目风险队列与卡点检查，只在作者关闭章节大纲前聚合成一张卡。

## 13. 本地验证计划

### 阶段 A：先验证“人能否稳定判断”

- 选两个窄任务：`情绪变化明显偏平 / 否`、`哪个章末更想让人继续 / 平局`；
- 使用目标题材的中文原创网文大纲或章末，至少三名目标读者标注；作者另标“这条提醒是否有行动价值”；
- 对二分类和含平局的名义标签报告 Krippendorff nominal α、Fleiss κ 与原始一致率；只有另采连续/近似区间评分时才用 ICC；
- 重复读者、重复作品用多层模型，或至少按读者与作品聚类计算不确定性；
- 按作品和作者留出测试，防止模型只学到词癖。

一个可执行的发现性试点是 200–300 个成对样例、每对 3 名目标读者，先覆盖最优先的两三种章节功能。这个规模不足以稳定估计所有作者、读者和章节功能分层；若人类一致性仍低，就要继续缩窄问题，而不是训练更大的裁判。上线样本量应按“实际触发黄灯的案例数”和每个关键分层分别设计。

### 阶段 B：离线校准选择性黄灯

主要验收项：

- 黄灯精确率：由盲评目标读者或独立编辑裁决提醒是否合理；作者接受率另记为“行动价值”，不当质量金标；
- 覆盖率：系统愿意判断多少案例；
- 弃权率及原因；
- A/B 交换顺序一致率；
- 不同题材、章节功能、作者风格的精确率差异；
- 每章平均提醒数和重复提醒率。

为符合“误报少比全覆盖重要”的产品原则，可以先把**黄灯精确率点估计 ≥90%、单侧 95% 置信下界 ≥80%**设为上线目标示例，允许较低覆盖率。若样本近似独立并使用 Clopper–Pearson 区间，`45/50` 个金标黄灯判对时，下界才刚过约 `.80`；重复作者/作品则要用聚类重采样或多层模型修正。若黄灯只覆盖 10%，取得 50 个触发样本约需 500 个测试案例，关键题材还要分别满足最低样本数。标签主体、置信水平、区间算法和分层方案都应预注册。这个目标是产品风险选择，不是研究常数。[Trust or Escalate](https://openreview.net/forum?id=UHPnqSTBPO)提供了选择性评审的校准先例，但它的保证依赖校准集与部署集近似可交换；分布漂移后必须重校准。

### 阶段 C：影子运行与线上行为

- 先在后台运行，不向作者展示，观察哪些信号会误报；
- “提醒是否影响作者”单独做实验：按作者或项目聚类随机展示/隐藏黄灯，测接受、修改、豁免与关闭行为，避免同一作者跨章学习污染；
- “文本版本是否影响读者”另做实验：随机呈现最终文本版本，保持下一章可用性、付费墙、发布时间和曝光一致，估计版本对追读的影响；
- 预注册一个主要结果，例如“到达章末且下一章可用者的同会话下一章开始率”，完成率、回访和付费解锁作次要结果；
- 不把“提醒 → 作者修改”和“版本 → 读者追读”混成同一个因果问题。

### 阶段 D：持续校准

- 作者豁免只更新偏好和参照，不改写事实层；
- 记录模型版本、参照集版本与阈值版本；
- 监测提示精确率、覆盖率和题材差异漂移；
- 不因某个高表现作品有更多反转，就自动提高全平台标准。

## 14. 最终产品建议

### 可以现在做

- 在大纲阶段维护读者问题账本与 ending hook 结构字段；
- 画描述性 reader-arousal / character-state 曲线，不把它当质量分；
- 实验性计算 `MAV`、稳健范围、最长平段、加权活跃问题和危机退路收窄，并检验不同信号族是否提供增量信息；
- 先用同类低尾找候选，再用双向成对边界样例确认；
- 只发可豁免黄灯，模型拿不准时不提示。

### 暂时不要做

- “都市爽文每章至少 N 次转折”；
- “未决问题不少于 N 个”；
- “新信息揭示率低于 X%”；
- 六种情绪弧线合规检查；
- LLM 一次性 1–10 分；
- 用评论量、投票量代替下一章进入率；
- 把任何软指标升级为红灯或自动改写理由。

### 还需要产品侧回答的四个问题

1. 第一批目标题材和目标读者是谁？
2. 章节功能是否已在大纲卡上显式标注？
3. 能否获得“到达章末 → 下一章开始/完成”的正确分母？
4. 作者是否愿意保存少量“刚好可接受 / 明显偏弱”的个人边界样例？

若这四项暂时不齐，第一版应叫“结构观察提示”，不要叫“留存预测”。

## 15. 与现有项目材料的对齐

本建议按所附项目材料中的边界设计：

- 软性节奏、技巧、情绪与模板偏差只出黄灯，不进入硬事实冲突；
- 作者可以停止、降级或豁免，系统不把豁免偷偷写回真相；
- 在关闭章节大纲这一卡点聚合提醒，不逐段打扰；
- `READER` 知识与角色、作者知识分开；
- hook 继续与 story obligations 分开存储；
- 结构提取只产生可回溯的工作信号，不覆盖作者承认的事实层。

这也解释了为何推荐“选择性黄灯”而不是“自动质量分”：它能接入现有风险队列，又不会让研究尚未验证的审美代理冒充真相。
