# 产品目标与抽取范围｜Notion 原页本地镜像

这套材料主要解决一个问题：事实抽取到底为谁服务、抽到什么程度才算够。

## 结论先放这里

✅ 产品目标不是“把每个小动作都抽出来”，而是让大纲中枢拿到后续写作不能安全遗忘的变化，并维持长程一致性。

- 作者工作的主界面是大纲中枢；系统判断历史真假的依据是冻结正文和事实底账。
- 事实底账不宣称穷尽正文所有细节。
- 热事实八类必须保证：人物状态、知情与误信、目标计划承诺威胁、关系身份资源位置、规则能力限制代价、关键因果、未决伏笔风险待办、本章出口状态。
- 冷事实不删，但不强抽：无后续影响的小动作、气氛、一次性玩笑、重复寒暄、服饰环境和长尾细节留在冻结正文，按需回取。
- 条数不是合格标准；一章事实多或少都可以，真正要看的是应该进入账本的内容有没有覆盖、有没有抽错。
- 训练考卷不能只衡量“金标每条是否全命中”，还要衡量这些结果能否供大纲、状态账、长线账和下一章执行包使用。

## 后续怎样使用

以后出现下面三类任务时，应把本目录作为固定参考材料带入：

1. 审 A 语义真源：判断哪些事实应保留、哪些只是冷细节；
2. 设计或重做考卷：把“对大纲和长线有没有用”纳入计分，不能只按旧金标逐条召回；
3. 外发 ChatGPT：要求它同时参考产品目标、热事实范围和大纲结构，重新设计抽取合同与验收标准。

⚠️ 这套材料是上位参考，不是当前 R03 修复轮的改卷令。R03 现有考卷、金标和合同继续冻结；要改范围或评分，另开下一轮并留新版本。
