# 01·产品总图 v1｜草案
状态：**现行草案**
当前用途：说明产品最终解决什么问题，以及各模块如何配合。
不负责：规定具体模型、前端框架或抽取阈值。
主要来源：S1 产品北极星；S2 R2 目标令；S4 事实句与大纲裁决。
最近复核：2026-07-27
## 一句话
> 这是一个以“大纲中枢”为作者工作面、以“冻结正文＋可追溯事实”为历史依据、能把同一故事投影成正文、分镜和互动叙事的长篇创作系统。
## 产品核心不是“抽很多事实”
核心是四件事：
1. 作者能看清当前故事骨架，并安排未来五章、十章的转向；
2. 写到几百章后，人物状态、知情、承诺、规则和因果不崩；
3. 需要前文细节时，系统按问题回冻结正文取证，不靠模型背整本书；
4. 大纲、正文、分镜、互动分支共享同一底座，但投影不能反向污染历史真值。
## 两条主流程
### 导入已有作品
```plain text
冻结正文
→ 建来源坐标与检索入口
→ 按需回答／登记关键变化
→ 建当前状态与长线账
→ 投影出可编辑大纲
```
### 从大纲继续创作
```plain text
选择故事线
→ 编辑本章计划事件
→ 编译章节执行包
→ 逐段生成正文
→ 计划—成文对账
→ 作者确认
→ 登记真正写成的事实与状态变化
```
## 产品的五个工作面
1. **大纲中枢**：作者安排本章与未来，不直接当历史真值。
2. **证据与查询面**：提出问题，系统回原文给可追溯回答。
3. **长线控制面**：故事线、状态、知情、触发器、义务、规则、锁定和影响传播。
4. **投影与预览面**：正文、剧情卡、分镜、互动分支、资产导出。
5. **风险与裁决面**：红黄灯、材料不足、矛盾、作者豁免和待确认改动。
## 三种创作动作必须分账
- 只改变呈现顺序，不改变故事事实；
- 真正新增或修改剧情，需要走计划、写成、确认和回账；
- 生成多条候选路线，由作者选择，未选分支不得污染主线。
## 存量作品接入
当前高价值方案：黄金三章深读，中段摘要，最近 7–10 章细读；前文缺什么现搜现补。这里的“黄金三章／最近 7–10 章”是存量接入的候选起步参数，不是长期固定门槛，后续按作品与作者问题校准。全书深抽可以是可选后台任务，不应成为开始创作的前置条件。
## 产品成功的最小读数
- 作者提出的关键问题能被回答，答案可回原文；
- 下一章执行包足够写作，不必重读整本书；
- 修改一处只复核直接受影响部分；
- 计划、正文、事实和投影不会互相冒充；
- 作者能看见风险，也能看见已通过部分，不被系统反复唠叨。
