# 原子需求与验收背景板

这里保存第三类共同背景：把产品愿景拆成一句句可单独理解、备料、测试和评分的用户预期。

它和另外两类背景分工如下：

- 产品共同背景板回答“我们准备做什么产品，哪些原则和边界已经拍下”。
- 外部报告背景板回答“外面有哪些证据、经验、反例和未知”。
- 本背景板回答“每个局部能力应该让用户得到什么结果，怎样判断离预期还有多远”。
