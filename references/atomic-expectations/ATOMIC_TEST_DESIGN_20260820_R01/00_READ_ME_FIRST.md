# 127 条原子需求·六例验收设计 R01

这份设计把现行 127 条原子需求各拆成 6 个小测试，一共 762 个。每组小测试权重合计 100，核心分、附加分和红线分开。

## 怎么用

- 查某条需求的 6 个测试：打开 [01_ATOMIC_TEST_DESIGN.json](01_ATOMIC_TEST_DESIGN.json)，按 `expectation_id` 查找。
- 准备测试时，先看 `execution_kind`：Python 规则和本地函数可以先做，人工判断、混合或模型调用需要另外的执行器和权限。
- 先看 `blocked_by`；有阻断的测试不得靠假字段、默认值或人工私料冒充可运行。
- 每个小测试只允许 0/25/50/75/100 五档分数；命中 `redlines` 时直接按红线处理，不能被其他得分抵消。

## 当前什么身份

- 本地机械校验已通过：127 个大测试、762 个小测试，需求 ID 与 R02 一一对应。
- 这是验收设计，不是已经能运行的 pytest/API 套件，也不是 Gold。
- 364 个小测试尚有明确依赖阻断。
- 引用的 BOOK-xxx 节选不随 Git 分发；它们只能从获准的本地材料包解析，不得猜书名、作者或未提供章节。
- 本轮 API、模型调用、Gold 生成和真实作者调查都是 0。

机器校验结果见 [VALIDATION_RECEIPT.json](VALIDATION_RECEIPT.json)。
