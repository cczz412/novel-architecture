# 作者原话和产品理解要并存

身份：外部先验

## 遇到什么

作者说“反派再坏一点，但只对主角”或“这一卷先别让主角翻身”。后续 Agent 准备只存一条自己改写后的全局偏好，或者根据沉默、重试和连续编辑自动推断长期方向。

## 对的做法

保留作者原话，也保留一份作者能纠正的产品理解。作用于规划、检查还是取料，与作用于哪本书、哪一卷、哪一章、哪个角色或剧情阶段，是两条不同的范围轴；未开始、暂停、仅本次越过、结束和撤销也不能混成“当前有效”一个概念。

最新的明确决定不能被旧摘要、旧缓存或行为推断偷偷推翻。读取到方向、决定采用、产物确实遵守、方向已经停用是四类不同证据；模型临场补一句解释不能冒充执行证据。具体字段、优先级、状态枚举和自动结束规则仍未拍。

## 错的做法

只存 Agent 的转述，不留作者原话。把一次抱怨或重做当永久偏好。根据沉默、折叠、重试直接升级长期方向。一个全局字符串同时管模块范围和故事范围。用模型自述证明自己照做。把本卡升级成执行票，或把研究候选写成已拍偏好合同。
