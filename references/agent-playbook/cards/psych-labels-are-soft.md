# 人格标签只能提醒，不能替角色做决定

身份：已拍加固

## 遇到什么

人物页有 MBTI、九型、依恋型或临床标签。后续 Agent 准备把标签直接塞进规则引擎：角色做出不符合标签的选择就报硬冲突，或让标签自动决定下一步行为。

## 对的做法

**已拍：**心理标签只作展示、软先验和编辑索引，不能独立充当行为约束。长程行为判断要看已确认事实、当前目标、关系、具体情境和历史选择；单一标签永不独立触发硬告警。七层字段、检查器四档、优先级和触发写法仍是人物账设计候选，不是现有字段或能力。

**加固：**SI-007 P13 的外部证据显示，模型认识心理学概念、会写出“像某标签”的短文本，不等于能跨场景稳定维持角色行为；标签配合情境、动机、历史选择和例外更可靠。它支持降级为软先验，但报告提出的大五分值、依恋维度、七层结构和四臂实验没有升格成产品合同。

## 错的做法

`INFP`、`NPD`、九型编号或依恋类型单独决定角色行动。标签不符就拦截剧情或判“崩人设”。把角色成长、伪装、压力下反常都当错误。冻结七层字段、检查器四档或优先级。把本卡升级成执行票，或把 P13 的实验方案写成已拍。
