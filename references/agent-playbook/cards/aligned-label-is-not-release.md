# “已对齐”只是状态说明，不是施工放行票

身份：设计审查风险

## 遇到什么

设计目录或索引写着“第二版已对齐”“已完成”。后续 Agent 准备跳过现行合同和正文，直接按这个标签施工。

## 对的做法

这张卡记录的是 SI-016 对**当时候选合同包**的审查风险，**不是现行产品已经炸了**。当时审查发现，索引里的“已对齐”和正文深处的旧句互相冲突；消化稿还注明，回包后 CZ 曾另行授权施工，所以不能拿这次历史扫描判断当前仓库仍有同一问题。

按 R14，背景板和设计稿负责解释产品语义，不证明代码已经具备；执行现状要回当前指针、正式合同、代码、测试或结果票。索引标签只用于导航。标签与正文或现行合同冲突时，登记为过时材料并停在当前权威入口，不能自己挑一句顺手的继续做。

## 错的做法

把“已对齐”当发布票、施工票或验收票。只看目录状态，不读当前合同。把 SI-016 的历史问题写成现行产品故障。直接复制回包 B1 候选合同。把本卡升级成执行票，或自行决定哪份旧句生效。
