# 收工不是关章，无书稿不算写完一章

身份：已拍加固

## 遇到什么

作者只完成了章计划，没有书稿，点了“收工”。后续 Agent 准备增加已写章数、连续更新、正文进度，或者直接把入口推进到下一章并当成本章已经关章。

## 对的做法

**已拍：**无书稿也可以收工，但只增加规划进度，不移交真值接力棒，不增加已写章数或连续更新。关章是另一道独立工序，要过字数、任务、剧情进展、质检、不冲突和符合规划等硬门槛，系统才可建议“到此为止”，再由作者确认。不要为了修风险取消“无书稿收工”；要分清它完成的是规划，不是书稿。

**加固：**SI-007 P01 指出，候选稿若把计划完成、写出草稿、形成可读章节和发布压成一个“完成”，会让系统维护一部作者没写出来的影子小说。这个审查支持分轨，但 P01 提出的 `plan_ready`、`draft_written` 等名字仍只是字段草案。

## 错的做法

无书稿收工后增加已写章数、日更打卡或发布进度。把整章暗稿当成正文。把“收工”按钮直接映射为 `chapter_closed`。因为 P01 有风险意见就删除无书稿收工。把报告里的状态名冻结成数据库枚举。把本卡升级成执行票，或把加固建议写成已拍字段。
