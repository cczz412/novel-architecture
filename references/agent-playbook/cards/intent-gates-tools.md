# 按意图分探讨／查询／真改

身份：已拍＋加固

## 遇到什么

AI 要办事，站点很多。要不要把每一站都做成工具，让它自己找？

## 对的做法（已拍）

必须先分清意图：探讨 vs 查询 vs 真改。作者只是想聊聊剧情，不能直接生产出来。外部 MCP：只读＋本地提案，写入正史永不开放给外部。聊天产出落画布，不留在气泡里。

## 加固形状（SI-008，还不是合同）

调查建议：聊天、点选、外部 Agent 走同一张动作清单；按意图露出工具；不要 1:1 搬后台站。这些可当设计形状，不能当成已经冻结的工具表。

## 错的做法

一张万能工具把查询、建提案、签字塞在一起。把后台每一站都暴露成工具。作者版 CLI 当主界面。聊天能改的比画布点得到的还多。
