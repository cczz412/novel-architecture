# 拆书配方是参考，不是真值标签

身份：已拍加固

## 遇到什么

拆书报告或模型给一章贴了“爽点、钩子、主题、情绪曲线”等标签。后续 Agent 准备把这些标签写进事实账，或让它们自动成为生成硬约束。

## 对的做法

**已拍：**技巧、爽点、氛围和视觉线索属于创作供料或写法指导旁挂物，有来源锚，但不进事实质量门。写法指导使用开放词表，不固化标签树；它可以帮助出题和检查，不能冒充故事已经发生的事实。

**加固：**SI-003 的配方调查同向提醒：证据层可以自动化，结构解释要人工合并；主题、钩子和爽点只能给多候选，不能自动定标签。报告里的九组维度、A／B／C 格式和“A＋C 首发”都是外部方案，不是合同。

## 错的做法

模型一贴标签就写进 Canon。用“爽点不足”挡住事实入账或关章。固定一棵题材通吃的标签树。照抄九维、A＋C 或具体配方字段开工。把本卡升级成执行票，或把外部配方建议写成已拍。
