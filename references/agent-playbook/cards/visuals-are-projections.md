# SVG 和分镜是投影，不是故事真源

身份：当前产品纪律

## 遇到什么

SVG、角色图或分镜里出现了新服装、新伤势和新关系，后续施工准备把这些画面细节直接写回故事；或者把 CCZ-49／74 说成已经覆盖完整分镜系统。

## 对的做法

视觉产物只能使用获准的故事材料，并保存来源、版本和资产身份。生成画面新增的细节只是视觉候选，不会自动改人物、事实、地点或因果账；真要采用，必须走对应的正式剧情和入账流程。

当前 CCZ-49 是低成本 SVG 分镜入口，CCZ-74 负责 SVG 图库、素材选择、坐标、大小、层级和角色标记。它们不能冒充完整分镜卡生成、视频生产或外部交接系统。

## 错的做法

画面一出现就改故事真值。让批准镜头代替正文证据。把当前 SVG 小样扩写成全自动动画能力。用未核权素材或让模型猜看不清的事实。
