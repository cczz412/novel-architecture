# 作者看人话，合同字段留在内部

身份：已拍加固

## 遇到什么

后续 Agent 已经有内部字段、模块号和枚举，准备直接把 `truth_bearing`、`slot_status`、C7、P3、`draft` 等词放进按钮、提示和作者可见状态。

## 对的做法

**已拍：**当前产品口径把用户、工程、治理三圈命名分开。作者界面用人话：界面叫“大纲”，内部正名叫“规划账”；界面只说“事实”和“计划”。稳定英文字段只出现在合同和代码，P 号、模块号、治理字段也不进入产品正文。一个概念只有一个内部正名，旧词只留搜索映射。

**加固：**SI-016 在当时候选合同和设置示意里看到字段名、P 号与产品文案混用，提醒这会让不同实现各自翻译。这个审查加固了三圈分工，但没有冻结全量中文文案、字段到文案映射表或 UI 信息架构。

## 错的做法

直接把枚举值当按钮文案。让作者学习内部模块号和治理术语。为了界面好看反过来改数据库字段含义。一个地方叫大纲、另一个地方又把大纲当旧统称。把 SI-016 的示例词表当完整 UI 合同。把本卡升级成执行票，或自行新增字段名。
