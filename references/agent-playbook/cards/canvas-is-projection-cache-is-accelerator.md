# 画布是交互投影，缓存只是加速层

身份：当前产品纪律

## 遇到什么

画布、浏览器缓存或前端组件保存了一份人物、事实和章节数据，后续施工准备把这份副本当成新的故事真源。

## 对的做法

画布是作者操作当前章和查看工作证据的主要位置，但画布上的对象仍是正式数据与章票工作区的可重建投影。未提交增量要明确留在本章工作区；已经提交的结果回正式账本和版本链。

缓存只负责提速，丢失后应能从受权来源重建。具体前端库、本地缓存和服务端存储由现行 UI／存储合同决定，本卡不冻结技术选型。

## 错的做法

让画布节点、浏览器缓存和正式账本各自可写。缓存丢了就无法恢复。把某个前端库或旧压测数字写成永久产品合同。
