# 作者抱怨不是配置命令

身份：外部先验

## 遇到什么

作者说“金手指一开就还债太烦”“这卷想更爽一点”或“配角坏得不够”。后续 Agent 准备直接修改一个并不存在的全局设置，或立刻生成剧情来证明已经解决。

## 对的做法

先判断这句话是一次不满、临时例外、长期创作方向，还是在问产品能力；再只查询真实存在、确实相关的控制。真有控制时，说明为什么相关、哪些仍未知、影响哪里、何时生效、能否只试一次以及怎样恢复。没有对应控制时，直接说没有；可以给明确标成“仅本次”的替代建议，但不能假装改了配置。

作者关闭设置建议，只能说明现在不想被打断，不是新的创作偏好。具体设置名、滑杆、自动映射和效果承诺都没有因本卡成立。

## 错的做法

发明“爽度”“压力债”“反派恶意”等字段并写入全书。把一句抱怨直接变成正文或长期规则。不说明作用范围和恢复方式。用户关掉提示后马上换个说法继续弹。把本卡升级成执行票，或把外部候选写成已拍设置体系。
