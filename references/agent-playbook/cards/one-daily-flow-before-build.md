# 日常流程只认当前一条主线

身份：当前产品纪律

## 遇到什么

几份旧设计稿对入口、暂停、提交和异常恢复的说法不同，施工者准备各做一套，或按文件更新时间自行挑一份。

## 对的做法

作者日常流程以 CCZ-50 的实时票面和后续正式合同为准。未提交章节回到同一张章票、同一幅画布和原停点；工作卡结果先留在本章工作区。作者完成章末检查并提交后，选中的增量才合并进正式账本。

其他页面和模块都接这条主线，不能各自维护一套“完成”语义。发现旧稿冲突时登记冲突，回当前模块入口处理。

## 错的做法

首页、画布、写作区和章末页各自定义一套状态。未提交工作自动丢到新章。按“最后修改时间”决定哪份旧设计有权。
