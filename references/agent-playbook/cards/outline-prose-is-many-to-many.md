# 一条计划不只对应一段书稿

身份：外部先验

## 遇到什么

后续 Agent 要做计划—书稿对账，准备规定“一条计划只绑定一个段落，一个段落只完成一条计划”，再用这组一对一关系判定偏离。

## 对的做法

允许一条计划分散到多段书稿，也允许一段书稿同时承担多个剧情拍。映射应能回到可解释的书稿位置，并说明当前判断的作用范围；作者纠正错误映射时，也要区分只改当前链接、当前剧情点还是更大范围。倒叙、换序、人物误解和临场发挥不能仅因位置变化就自动判违反计划。

当前计划—书稿结果语义不因本卡改写。外部材料提出的是多对多关系层这一候选形状，不是新的数据库状态、互斥枚举或自动判偏离算法。

## 错的做法

强制一条计划对应一个段落。段落移动就判计划失败。模型第一次对齐后不允许作者纠正。用一条链接代表整章兑现。把研究里的结果分类直接冻结成互斥字段。把本卡升级成执行票，或把外部候选写成已拍映射合同。
