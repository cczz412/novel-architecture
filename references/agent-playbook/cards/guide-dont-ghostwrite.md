# 别把编辑助手做成 AI 写手

身份：已拍加固

## 遇到什么

需求报告里反复出现“续写、生成、提高产量”。后续 Agent 准备顺手加一个“一键写正文”入口，认为这只是补齐用户需求。

## 对的做法

**已拍：**产品是导写＋核对的编辑助手，不生成书稿成文，现在不做，以后也不做。可以把“怎么写”拆成很细的写法要求、信息点和章事实稿，但不能给示范句或可直接发表的正文，更不能留隐藏后门。

**加固：**SI-005 的需求材料同向显示，长篇作者的核心痛点更集中在记忆、回查、维护和证据，而不是让 AI 多写正文。这个调查只能防止产品走偏，不能证明所有作者都接受同一种边界，也不能推出付费意愿、按钮形态或生成合同。

## 错的做法

把“用户想提高产量”翻译成正文生成。用“示例”“预览”“临时草稿”绕开不代写边界。把调查里的用户原话写成产品已经决定。把本卡升级成执行票，或把外部建议写成已拍功能。
