# 验真先判，修复不能顺手改账

身份：已拍

## 遇到什么

验真器判一条事实不受证据支持，同时给了一个“修正版”。后续 Agent 能不能直接用修正版覆盖候选或真值？

## 对的做法

验真先做诊断，只判“支持／不支持／不确定”，允许弃权。修复另起一步，修法只能成为候选建议，不能跟诊断绑成一次自动改账。高影响变化仍走作者或正式闸确认；跨家族模型可以互相拦错，但不能被当成不会同错的万能保险。

## 错的做法

验真器一发现问题就自动重写事实并落账。让主抽模型自检自改。两个模型一致就直接转正。把“跨家族”写成质量保证。把本卡升级成固定模型分工、API 名单或自动修复执行票；把“跨家族一定可靠”的待验假设写成已拍保证。
