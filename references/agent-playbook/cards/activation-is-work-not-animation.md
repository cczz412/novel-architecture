# 激活不是播完一段动画

身份：当前产品纪律

## 遇到什么

页面播完动画、分镜或演示以后，准备把“播放成功”直接算成作者已经感受到产品价值。

## 对的做法

激活要让作者看见系统正在处理他的真实材料，并能看懂依据、结果和下一步。分镜或动画可以帮助展示工作，但不能只凭播放时长、观看完成率或视觉效果认定激活。

作者日常入口和首次价值以 CCZ-50 的实时口径为准。CCZ-49／74 只承接当前 SVG 图库和分镜视觉工作，不能反过来定义整套产品激活。任何分钟数和媒体规格都要另有试验与验收，不能从旧报告继承。

## 错的做法

播放成功就记成激活。拿旧的 90 秒、10 分钟或双入口数字当永久合同。为了制造“哇”的效果，把当前任务、来源和可复核结果藏起来。
