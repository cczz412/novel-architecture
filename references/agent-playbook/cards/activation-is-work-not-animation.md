# 激活不是播完一段动画

身份：已拍加固

## 遇到什么

onboarding 做出一段动画或有声分镜。后续 Agent 准备把 `preview_played`、90 秒首播或 10 分钟交付直接定义成产品激活。

## 对的做法

**已拍：**激活是作者看见系统在做真实、专业、可理解的产品工作，不是炫酷特效。最短可信链仍是：真实问题→回原文取证→作者确认→安全更新→再次使用。分镜只是“看得见在干活”的一种形态；有声动态分镜是附带产物，不是首屏主承诺。90 秒只是模型延迟预算，不是产品合同。

**加固：**SI-006 P4 把情绪上的“哇”与能预测采用的行为分开，这个提醒与 R14 同向。但该报告没有接触目标用户，也没有跑可用原型；双入口、90 秒／10 分钟、动画规格、指标和样本量都仍是待验证假设。

## 错的做法

播放成功就记成激活。用动画观看率替代证据确认和再次使用。把 90 秒、10 分钟、双入口或媒体质量写成验收合同。让高成本视觉生成占掉作者主线。把本卡升级成执行票，或把 P4 建议写成已拍。
