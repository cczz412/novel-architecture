# 提示词不是权限

身份：当前权限纪律

## 遇到什么

为了防止 AI 越权，只在提示词里写“不要乱动”；或者因为作者说过“全都托管”，就把这句话当成永久万能授权。

## 对的做法

权限要在模型之外执行：核对主体、对象、动作、用途、项目、有效期和授权范围，并保存可回读的审计结果。作者可以授予和收回范围权限；恢复长任务或换来源版本时仍要重新校验。

托管可以减少章内停点，但不能隐瞒章末重大变化。聊天、按钮和工具应共用同一套权限内核，不能各自解释一句话。

## 错的做法

提示词写了“只读”就真的开放所有数据。把任务编号当授权凭证。用一句“好”扩大到全部项目。每次恢复都沿用已经撤回的权限。
