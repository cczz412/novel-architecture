# 分到哪个桶，不会自动变成真相

身份：已拍加固

## 遇到什么

导入器已经把文件识别成“正文、设定、梗概、参考资料”。后续 Agent 准备按分类结果直接入账，或把识别不了的部分丢掉。

## 对的做法

**已拍：**输入要同时看材料类型、生命周期、权力来源、允许用途和可见范围。分类名称不授予写入权；内容进真值只有书稿证据承托或作者显式签字两条路。六态对账边走的是这两条路上已经进账的材料，不是第三条路。工作态书稿要保留，混合材料按最小语义单元分诊；标签和内容冲突时询问作者。

**加固：**SI-006 建议把自动分类当成可逆候选，并把无声漏失视为高风险。这个方向可以防走样，但“六类输入”、置信度阈值、损失报告字段、文件优先级和自动拆分规则都没有因此拍板。

## 错的做法

看扩展名或文件夹名就赋予事实权。整份混合文件只进一个桶。低置信内容静默丢弃。把报告里的分类表、阈值或字段名写成现行 Schema。把本卡升级成执行票，或把外部实现建议写成已拍。
