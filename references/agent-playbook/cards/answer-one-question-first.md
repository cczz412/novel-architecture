# 先回答一个真问题，不先造整本百科

身份：当前产品纪律

## 遇到什么

作者导入旧稿。系统准备先深抽全书、补齐人物百科和世界观，全部完成后才肯开始工作。

## 对的做法

先完成必要的材料接纳和诚实检查，再围绕作者眼下的真实任务取最小够用的材料。能回答就给出带来源和覆盖范围的答案；材料不足、格式失败或仍有未读范围，就明确说清，不能补故事。

全书整理可以随后按模块继续，但不是第一次价值的固定前置。导入、恢复和材料终态回 CCZ-85；作者接下来在哪继续工作回 CCZ-50。

## 错的做法

逼作者先填完整 Wiki。把全书深抽完成设成所有任务的前置门。为了尽快给答案而跳过输入失败、未读范围或来源版本。
