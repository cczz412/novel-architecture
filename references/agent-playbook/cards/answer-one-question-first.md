# 先回答一个真问题，不先造整本百科

身份：已拍加固

## 遇到什么

用户导入旧稿。后续 Agent 认为正式开工前必须先深抽全书、补齐人物百科和世界观 Wiki，全部完成后才能回答问题。

## 对的做法

**已拍：**已有长篇先让作者提出一个真实问题，系统按问题回原文取证，只请作者确认当前答案和需要长期保留的变化。第一次使用可以只做“上传材料＋回答一个真实问题”；全书深抽完才开始工作不是默认路线。材料不足就明说不足，不补故事。

**加固：**SI-006 的输入调查同向提醒，整书自动分拣和先造百科会放大错序、漏失和 AI 推测冒充事实的风险。它支持“索引＋真问题起手”，但文件优先级、输入比例、章节数量和导入步骤仍是候选。

## 错的做法

把“完成全书解析”设成首次价值前置门。逼作者先填 Wiki。材料不足时自动补全人物和设定。把报告里的六类输入、格式顺序或章节阈值冻结成合同。把本卡升级成执行票，或把外部导入方案写成已拍流程。
