# 改句子不能顺手改故事

身份：外部先验

## 遇到什么

作者只选中一小段，要求删套话、收紧节奏或调整文风。后续 Agent 准备用整段重写或批量补丁处理，却没有检查故事含义是否被改掉。

## 对的做法

修改范围只限作者选区，修改维度只限作者明确要求的表达问题。应用前要回看候选是否碰了事件结果、人物知情、故事时间、因果、视角、伏笔、专名或对话意图；无法判断时就保留为待作者比较的候选，不静默落稿。多条小改也要能回到原文和这次授权，并允许整体撤回。

字符相似、向量相似或模型一句“意思没变”都不能单独证明故事没变。外部材料只给了安全检查方向，没有冻结检查器、分数、事务字段或批量应用合同。

## 错的做法

作者选一段却顺手改选区外内容。把否定翻转、主客体交换、时间变化或线索删除当文风优化。相似度高就自动应用。把风格插件获得表达权限解释成故事事实写权。把本卡升级成执行票，或把外部检查清单写成已拍字段合同。
