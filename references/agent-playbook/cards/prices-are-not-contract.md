# 调查里的价格表不是施工合同

身份：已拍

## 遇到什么

SI-005／006 写了月费、按项目价格、积分、免费额度和 BYOK 建议。后续 Agent 准备据此建套餐、扣费字段或付费墙。

## 对的做法

R14 已冻结付费墙、正式价格、免费额度和大部分计费结构；调查价格只能作为历史候选或以后受控试验的自变量。当前唯一打开的收费缝是“小抄卖整理方便”：不付费也不损失内容。任何新价格、积分规则、BYOK 计费或套餐都要等新的明确裁决与真实试验记录，不能从报告直接施工。

## 错的做法

把 ¥39、¥299／599／999、积分换算、免费字数、失败退款或 BYOK 双重收费规则写进代码。拿竞品标价、痛点强或口头愿付推导正式定价。看到本卡就开计费执行票，或把报告建议写成已拍商业合同。
