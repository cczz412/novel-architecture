# 一次实验别同时改五件事

身份：外部先验

## 遇到什么

新一轮评测同时换了模型、Prompt、示例、上下文、Schema 和评分器，分数上升。后续 Agent 能不能说“某一项改动有效”？

## 对的做法

一次实验能证明的，只是实际改动包造成的整体差异。没有单变量对照，就不能把功劳归给其中一项。P4 预检合同要求比较某个变量时先冻结样本、模型、解码、目标责任区、输出合同和评分器等非目标条件；这仍是预检，不是产品已拍。外部方法回包同样要求一次只改一个变量，并在运行前写清主指标、失败门和平局处理。A／B／C 若分别加入整包示例或整包尺子，只能解释为“整包效果”，不能声称纯语义因果。

具体要用多少示例、哪条门线、哪种检验，仍要 CZ 拍并写进正式实验合同。

## 错的做法

一次改五件事，再挑最顺眼的一项讲原因。边看结果边改主指标或门线。把复合实验写成单因素结论。把 P4 预检或外部方法写成 R14 已拍。把本卡升级成执行票；把示例、规则数、学习率、轮数或模型名单写成已拍方法合同。
