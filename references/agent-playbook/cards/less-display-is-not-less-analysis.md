# 少看一点，不等于少分析一点

身份：已拍加固

## 遇到什么

作者说“这次只看核心”“别拆那么碎”。后续 Agent 准备用一个全局颗粒度数字，同时减少切段、抽取、规划、检查、证据保存和界面展示。

## 对的做法

**已拍：**R14 允许作者前台先看目标、必须／不能、场景和待决定，再渐进展开；后台可以保留完整合同。覆盖回执可以折叠，但必须能展开。少展示不能删除底账、来源、证据、未知和过期信息。

**加固：**外部调查建议统一的是作者能说人话的入口，不是让所有模块共用一个数。系统要说明这次改变的是展示密度、解释长度、规划结构，还是确实需要重新分析；会改变结构、证据或下游计算时，要回到对应模块解释并确认。固定三档和跨模块参数映射仍未拍。

## 错的做法

“只看核心”就少抽事实、少留依据或跳过检查。把一个滑杆直接传给所有模块。界面折叠后让证据不可回看。根据作者快速略过就自动形成长期偏好。把本卡升级成执行票，或把加固建议写成已拍三档和统一参数合同。
