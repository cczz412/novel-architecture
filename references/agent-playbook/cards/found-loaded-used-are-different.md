# 找到、装进、真正用到是三道证据

身份：外部先验

## 遇到什么

检索器命中了材料，打包日志也列出了文件，模型最后还给了一个看似正确的答案。后续 Agent 准备据此写“证据已经被使用”。

## 对的做法

把三件事分开核对：需要的原文有没有被找到；找到的材料有没有按正确版本、顺序、权限和范围真正装进本次上下文；输出中的具体结论有没有实际依赖这些材料。检索日志只能证明检索侧，材料清单只能证明组装侧，模型自述也不能单独证明利用侧。

证据不足时按“不知道卡在哪一段”处理，再补对应检查。外部研究给出了这组三段式诊断先验，但没有替本项目冻结日志字段、指标、原因码或回捞次数。

## 错的做法

把 RAG 命中当成模型已经使用。把“文件在库里”当成“文件已进包”。把工具调用成功、注意力图或模型一句“我参考了”当利用证明。因为最终答案碰巧正确，就反推检索和组装都正确。把本卡升级成执行票，或把外部建议写成已拍评测合同。
