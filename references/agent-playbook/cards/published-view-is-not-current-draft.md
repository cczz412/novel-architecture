# 本地最新稿不等于读者看过的版本

身份：外部先验

## 遇到什么

作者把连载作品迁进来。本地文件、平台草稿和线上读者实际看到的内容不一致，后续 Agent 准备拿“当前文件”统一代表已发表历史。

## 对的做法

先确认当前任务要延续或修复的是哪一个可回验版本。作者正在编辑的稿、平台尚未公开的草稿、读者实际可见的版本和暂时无法判断的状态不能静默压成一个“已发表”布尔值；同一章在不同平台也可能不是同一版。续写、回改、后文补救和发布对账应各自引用对应基线。

这张卡只保留外部调查提出的区分方向。平台、时间、状态枚举、批量导入流程和线上对账合同仍要 CZ 另拍，不能从本卡发明字段。

## 错的做法

把本地最新稿当成所有读者已经看过。只存“已发表／未发表”，丢掉来源平台和对应版本。平台草稿未公开也按正史约束后文。状态不明时猜一个默认值。把本卡升级成执行票，或把调查候选写成已拍发布状态合同。
