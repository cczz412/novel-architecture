# 垂直场景共用真源，不复制七套产品

身份：已拍加固

## 遇到什么

作者、短剧、漫画、互动故事和配音都要不同字段。后续 Agent 准备给每个垂直场景各建一套项目格式、事实库和确认流程。

## 对的做法

**已拍：**多个垂直场景共用一套故事真源内核，可以增加各自的扩展字段和投影。停止线不是“出现了新字段”，而是某个场景要求绕过确认直写真源。改编工作台可以独立成窗口，但仍共享底座；投影上的纠错只有作者确认后才对真值生效。

**加固：**SI-005 的需求地图把一致性、证据和可演化状态识别为跨场景的共同部分，也把“被多个垂直市场拉成重型全家桶”列为高风险。报告里的垂直清单和扩展字段只是候选，不是新 Schema。

## 错的做法

为视频、读者和互动分支复制事实账。让某个投影或外部生产工具直接改 Canon。见到新场景就新增一套核心对象。把报告中的垂直字段表当施工合同。把本卡升级成执行票，或把加固建议写成已拍细节。
