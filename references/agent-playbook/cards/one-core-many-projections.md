# 一套故事真值，可以有多种受控投影

身份：当前产品纪律

## 遇到什么

作者、分镜、短剧、漫画或插件需要不同视图和字段，后续施工准备给每个场景复制一套事实库和确认流程。

## 对的做法

不同场景共用正式故事内核，只读取自己获准的最小范围，并用投影或经过准入的扩展表达差异。完整读取走统一受控接口；新字段和新账本责任走 CCZ-102。

投影上的修正不能直接反写真值。正式写入必须经过对应合同和当前权限；这可以是作者明确动作或已授予的范围权限，不要求所有小项逐条手签，也不允许任何场景绕过审计。

## 错的做法

为每个垂直场景复制人物、事实和因果账。让视频或插件把生成细节直接写回故事。见到新视图就新增一套核心对象。
