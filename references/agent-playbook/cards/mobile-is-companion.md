# 手机不是缩小版写作台

身份：已拍加固

## 遇到什么

桌面工作台已经有很多能力。后续 Agent 准备在手机上逐项照搬，或者反过来因为做不齐全功能就先不做移动端。

## 对的做法

**已拍：**手机端 V0 是响应式网页伴侣，负责记灵感、查设定、确认／驳回和看进度；不把手机当完整写作台，也不在手机上承担选线出题等深工作。当前口径不做原生 App。

**加固：**SI-006 P1 的外部案例同向说明，跨设备应按任务分工；同步、版本、备份和恢复出错，比“有没有全功能客户端”更容易直接毁掉信任。但报告里的 Web／PWA／原生端时序、导入导出格式、MCP 和 CLI 优先级都不是新合同。

## 错的做法

追求桌面与手机逐按钮对齐。把深度规划和复杂编辑硬塞到小屏。因为报告推荐某个平台壳、格式或工具顺序就直接开工。把本卡升级成执行票，或把外部平台建议写成已拍。
