# 手机端形态尚未冻结，不能从旧报告直接施工

身份：候选边界

## 遇到什么

看到旧材料写过“手机只做陪伴端”或“手机照搬桌面”，后续施工准备直接冻结移动端范围。

## 对的做法

先确认作者眼下的日常任务，再决定哪些适合手机、哪些必须留在大画布。移动端可以是查看、轻确认、提醒或续接入口，也可能承接别的真实需求；具体 V0 形态要回 CCZ-128／50 的当前决定和后续验证。

在没有新拍板和验收前，本卡只保留“不凭旧报告定范围”这一条纪律，不宣称手机端已经有固定产品形态。

## 错的做法

默认手机必须拥有桌面全部能力。反过来永久限制手机只能提醒。把旧竞品调查或界面草图写成已拍合同。
