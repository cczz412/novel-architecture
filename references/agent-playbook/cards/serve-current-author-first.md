# 首发主线不是所有故事用户

身份：已拍加固

## 遇到什么

报告里同时出现小白、读者、互动故事用户、网文作者、短剧团队和改编负责人。后续 Agent 想把这些人都放进首屏和同一版待办，避免“漏掉市场”。

## 对的做法

**已拍：**首发主线只服务已经写了 3～20 章、近期准备继续写、正被结构回查和一致性问题拖累的作者。V0 不做读者入口；1～2 家短剧或漫剧团队只走设计伙伴轨道，不获得与作者主线相同的施工优先级。“一句话生成整本”也不是早期承诺。

**加固：**SI-005 说明相邻人群的需求确实存在，但任务、证据、交付和付费方式差异很大。它能加固“不要全塞进一个首页”，不能把报告里的人群排序、规模估计或产品窗口直接写成现行范围。

## 错的做法

为了覆盖市场，同时开读者模式、互动续写、作者工作台和视频工作室后台。把设计伙伴写成第二条同优先级产品线。把外部人群分层当成已拍 ICP 或市场份额。把本卡升级成执行票，或把调查建议写成已拍范围。
