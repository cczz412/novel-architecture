# 局部复核要说明旧结果为什么还能用

身份：已拍加固

## 遇到什么

作者只改了两段。后续 Agent 想把整本旧分析原样复用，或者反过来每次都重跑全书，却说不清哪些旧结果已经过期。

## 对的做法

**已拍：**R14 要求改动形成新章版本，维护旧锚点到新锚点的映射；影响传播默认列直接依赖并说明理由。机器派生物可以重算，计划态只亮灯，冻结书稿绝不自动修改。查询和检查还要说明使用的版本以及结果是否过期。

**加固：**外部调查建议让每条被复用的结果能解释自己依赖了什么、为什么在这次修改后仍有效。锚点移动、拆分、合并，分析规则或模型变化，都会削弱复用证明；无法证明局部复核安全时，应扩大范围，必要时退回全量复核。全量复核是后备，不是日常默认。具体新鲜度字段、阈值和算法仍未拍。

## 错的做法

只看文件名、生成时间或“改动很小”就复用全部结果。锚点断了仍沿用旧结论。为了省事每次全书重跑。因为局部复核没有报错就宣称全局仍正确。把本卡升级成执行票，或把加固建议写成已拍缓存和失效合同。
