# 运行回执不是作者署名

身份：当前纪律＋未实现边界

## 遇到什么

模型输出 `used_components`，或页面记下“加载过某插件”。后续 Agent 准备用这条记录证明插件确实影响了结果、认定谁是作者、决定版权归属，甚至据此允许公开发布。

## 对的做法

**已拍：**一次插件运行要把“用户声明、系统加载回执、模型自报、作者采纳”分开记录。模型自报只是四段中的一段，不能当内容确实生效的证据。运行来源回执只回答本次运行里谁参与了什么，不判断著作权、作者身份或内容归属；社群插件的作者署名另走“原作者＋历次微改者”署名链。能否公开还要过独立的权利和治理流程。

**加固：**SI-007 P03 指出，候选稿里的 `used_components` 只是模型自报，程序校验键合法也不会把它变成数字签名；上传者名字和格式通过同样不足以证明权利。这个提醒只加固证据边界，不新增法律结论。

## 错的做法

把模型说“我用了”当成系统加载证明或效果证明。用运行回执自动生成版权结论、作者名单或平台申诉结论。微改后抹掉原作者。上传者填了名字就视为有权公开。把四段回执合成一个布尔值。把本卡升级成执行票，或把 P03 的治理建议写成已拍法律合同。
