# 识别到产品反馈，不等于同意外发

身份：已拍加固

## 遇到什么

作者在创作对话里说“你们怎么没有这个功能”。后续 Agent 准备自动提交产品反馈，并顺手附上聊天、书稿、角色卡或上传原件作上下文。

## 对的做法

**已拍：**当前合同要求授权按主体、对象、字段、动作、用途、项目和有效期分别判断，只开放当前任务所需最小范围。涉及第三方处理时，还要先说明处理主体、数据、用途、地域、保存、再使用与删除边界，每次发送和返回都能回到材料版本与授权记录。

**加固：**外部调查建议把眼前创作问题与产品反馈分成两条支线。先形成作者可见的反馈草稿，再单独取得提交许可；同意提交不等于同意附带私人材料，默认排除聊天、书稿、角色卡和原件，并允许预览、编辑、取消。只从明确指向产品的对话或交互识别，不能扫描小说正文里的负面词触发上报。反馈去向、保留期和后台合同仍未拍。

## 错的做法

识别到抱怨就自动上报。把“同意提交”解释成“同意附全量上下文”。为了复现问题默认上传作品内容。把产品意见写进小说灵感、事实或长期创作方向。把本卡升级成执行票，或把加固建议写成已拍反馈平台和数据合同。
