# 草稿是提案，产出落画布

身份：已拍

## 遇到什么

模型吐了一大段字。这算结论吗？还没签字能不能当正史？

## 对的做法

聊天是说话的地方，不是装结果的地方。产出必须落成画布上的对象（选项卡、风险、带原文锚的答案）。草稿／提案不是正史。进真值必须作者确认；聊天说「好的」「都确认」不算签字。投影上可以当面纠错；批准前不改写真源。

## 错的做法

把气泡里的长文直接当账本更新。草稿一入库就当正史。关闭聊天／关掉窗口变成改主数据。
