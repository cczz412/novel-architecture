# Agent 情景卡

这个目录只做一件事：施工者遇到常见误区时，快速打开一张短卡，先别把事情做歪。

它不是产品真源，也不是施工授权。当前口径按下面的顺序确认：

1. 已核对的产品决定与规格按 [Notion 主存登记](https://app.notion.com/p/9ee897f5b8e54320a8aeb1f98569f133)读取，未迁项回原 Linear 主存；活动任务、依赖和未决问题实时读取所属 Linear 票；
2. 已经实现的工程能力，读取 GitHub 当前 main、正式合同、代码和测试；
3. 外部报告只提供候选证据，统一从 CCZ-64 和调查收件入口追溯。

## 怎么用

1. 从 [INDEX.md](INDEX.md) 找最接近当前问题的一张卡；
2. 只读那张卡和它列出的当前依据；
3. 开工前回读采用的决定版本、对应 Linear 任务与 GitHub 正式合同；
4. 卡片与当前真源冲突、来源过期或边界仍含糊时，停在当前阶段，登记冲突并请 CZ 拍板。

## 身份怎么看

“当前产品纪律”“当前权限纪律”等，只说明这张卡在提醒什么，不证明运行时已经上线。“候选边界”“候选设计要求”表示仍要后续拍板或施工。“外部先验”只能提供证据，不能直接变成产品决定。

日常目录现在有 65 张卡。P02 No-Go 已退出日常目录，只在[历史审查索引](history/README.md)保留证据身份。

不要为了核一张卡而通读旧调查包，也不要从历史附件反推当前产品口径。
