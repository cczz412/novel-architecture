# Agent 情景问答

什么时候用：施工时拿不准账本／篮子／工具／执行包／权限，或抽取／评测／记忆、需求／产品形态、日常循环／插件／画布／平台／人格标签、规划账／保存对照交棒／状态轴、局部复核／反馈外发／切片验收会不会做歪，先打开[卡片目录](INDEX.md)，对上那一张。

什么时候不用：不要当执行票、训练许可或产品已拍清单；不要用它代替共同背景板 R14；不要拿它当理由去通读调查包全文。

说白了：这是给人和云 Agent 的薄入口。主张仍在[外部报告知识库](../external-knowledge-base/README.md)，原报告仍在[调查总览](../survey-inbox/INDEX.md)。这里只回答「遇到这件事，对的做法／错的做法」。

## 怎么找

1. 打开 [INDEX.md](INDEX.md)，用「遇到什么」对号。
2. 只读对得上的那一张卡。
3. 要核出处，再打开卡上的消化稿或 R14 段落。禁止通读 `packages/`，禁止把 `work/` 当知识库。

## 卡片上的身份

| 身份 | 意思 |
|---|---|
| 已拍 | 共同背景板 R14 里已经写下的产品纪律 |
| 已拍加固 | 外部调查和已拍同向，用来防走样；形状细节还不是新合同 |
| 外部先验 | 外面的证据／经验，不能冒充已经决定 |
| 设计审查风险 | 审过候选设计稿的翻车点；不是「现行产品已经炸了」 |
| 本票纪律 | #115 怎么找材料；不是产品功能已拍 |

外部句子不能升级成产品决定。仍开口的拍板（知情账、暗稿、读者承诺、稀章）不在本夹已收各批。

身份行请尽量只写上表五个词。旧卡目录里还有 `已拍＋加固` 这类写法，等格式 V1.1 一起改，现在不重写前 9 张。
