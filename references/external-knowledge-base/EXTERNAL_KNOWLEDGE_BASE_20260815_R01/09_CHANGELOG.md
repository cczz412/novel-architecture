# R01 变化说明

这是外部报告知识库的第一个本地登记版本，没有上一版可比较。

## 从 ChatGPT Pro 候选包吸收了什么

- 152 份材料的报告准入账。
- 167 条原子结论与待核缺口。
- 2398 条去重来源登记。
- 新旧冲突、收窄、替代和历史隔离关系。
- 研究缺口队列、未来报告准入标准与 8 张主题背景页。

原始候选 ZIP 的 SHA-256 是 `6c70cbf7fb9bdf624358d321c6c49f52d2bfd824f63c1227028f206027ec8a59`，原字节保存在 `intake/raw/CANDIDATE_EXTERNAL_KNOWLEDGE_BASE_20260815_R01.zip`。

## 本地登记时补了什么

- 把 30 份新报告原字节转入 SI-015，准入账不再指向 `TEMP`。
- 逐份补上 Prompt 追溯状态；因逐字 Prompt 缺失，全部如实标为重建题意。
- 尝试打开背景正在使用的 157 个来源，并把结果回写来源登记。
- 候选包原有 86 条正向 A／B 结论；`CLM-DR-UX-03-K10` 因两个来源连续超时降为 U。本地 R01 保留的 85 条正向 A／B 结论全部至少有一个来源直接打开。
- 增加本仓库的正式落点、当前入口和下一版发布协议。

## 没有改变什么

- 没有修改产品共同背景板 R13。
- 没有把外部建议升级成产品决定。
- 没有删除旧报告、旧来源、负结果或未知项。
