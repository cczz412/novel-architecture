# 作者工作流、输入材料与长期连载

## 可以作为外部先验

连载反馈进入作者决策时，量化数据更适合定位“哪里异常”，不够单独解释“为什么异常”；评论更适合产生原因假设、指出具体错误和提供读者措辞，不适合多数表决剧情方向。[CLM-DR-WF-03-K01] [CLM-DR-WF-03-K02]

平台指标名称与算法会变化，所以任何“追读下降”“读完率异常”都要保留平台、版本、观察窗口和分母。[CLM-DR-WF-03-K07]

拆书和素材管理可以确认的底线是：学习抽象方法与复制具体表达不同；平台原创违规与法律侵权也不是同一个判断。来源指针、作者自己的分析和原文件副本应分开，引用最好能跳回原处，而不是把来源全文悄悄搬进创作项目。[CLM-DR-WF-04-K03] [CLM-DR-WF-04-K05] [CLM-DR-WF-04-K10] [CLM-DR-WF-04-K11]

## 只能当经验或候选假设

评论者、沉默读者和付费读者不能安全视为同一群人；这是实践样本支持的风险边界，不是代表性人口统计结论。[CLM-DR-WF-03-K03]

作者会在反馈、既定主题、人设弧线和个人审美之间做选择。有作者主动减少看反馈，也有作者在发现明确 bug、重复负反馈或平台规则风险时修订已发表内容；“纠错”和“为了故事故意偏离读者期待”必须分开。这些是案例型经验，不能升级为所有作者的统一流程。[CLM-DR-WF-03-K05] [CLM-DR-WF-03-K06]

编辑或运营可能充当“解释中介”，把数据波动、市场经验和剧情问题放在一起判断；榜单也可能作为竞争样本和灵感源。这些都是多案例经验，不是统一行业流程。[CLM-DR-WF-03-K04] [CLM-DR-WF-03-K08]

职业连载很可能需要滚动规划，而不是一次写完的固定大纲；存稿、已发布正文和未来规划承担不同风险。但相关新报告没有导出来源，当前只能作为待补链假设。[CLM-DR-CN-04-U01]

## 分歧与反例

“一味听读者会写崩”有实践者自述，但还不是行业规律；反方向也有作者从评论中发现漏洞并调整。[CLM-DR-WF-03-K09] 拆书教程样本明显偏新人和教学型作者，不能代替职业作者、工作室或不同题材的真实流程。[CLM-DR-WF-04-K17]

模板是高风险过桥口：只复制“槽位”与复制原作连续情节不同；仅删除专名、换名字不足以保证不再可识别。[CLM-DR-WF-04-K07] [CLM-DR-WF-04-K12]

## 不能证明什么

当前不知道目标作者实际以什么比例使用 Word、平台草稿、表格、便签、聊天记录和脑内大纲；也不知道断更回归时哪种恢复流程最有效。[CLM-DR-WF-01-DERIVED-U01] [CLM-DR-WF-02-U01]

“反馈触发换主角、提前揭密、直接弃书”等具体数据—动作路径证据不足，不能做自动规则。[CLM-DR-WF-03-K10] “拆书笔记多久回看一次”也没有一般规律。[CLM-DR-WF-04-K02]

## 对产品设计的候选启示

更稳的形状是：把数据和评论当信号层，把作者决定当决策层；保留改线原因、影响范围和是否修改已发表事实。输入侧应允许混合材料和低整理度材料，不要求作者先完成 Wiki。研究资料应在隔离域中保存来源，过桥到创作项目的应是作者自己的抽象分析，而非原作条目。[CLM-DR-WF-03-K01] [CLM-DR-WF-03-K02] [CLM-DR-WF-03-K05] [CLM-DR-WF-04-K10] [CLM-DR-WF-04-K11]
