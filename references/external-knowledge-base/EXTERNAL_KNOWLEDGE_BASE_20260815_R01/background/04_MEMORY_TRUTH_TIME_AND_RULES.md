# 长篇记忆、事实、计划、认知、时间与规则

## 可以作为外部先验

“当前状态”可以是权威历史的确定性投影，不必成为第二真源。可靠做法是保留事件／变更历史，投影说明自己算到哪个基线；快照能删除重建的前提，是重放所需的历史与规则仍完整。[CLM-DR-MEM-03-K01] [CLM-DR-MEM-03-K06] [CLM-DR-MEM-03-K07]

事实有效时间与系统知道时间应分开。某事在故事世界何时成立，与系统何时录入、修订或得知，不是同一个时间；小说叙述顺序也不能兼任故事时间。[CLM-DR-MEM-03-K02] [CLM-DR-MEM-03-K03]

版本最好保留谱系而不是只留“最后修改时间”。知识图谱或关系图本身不会自动提供历史语义；图中的边若没有有效期、来源、版本或变更事件，同样会形成第二真源。[CLM-DR-MEM-03-K04] [CLM-DR-MEM-03-K05]

文本中的时间关系允许模糊、无界、分支和未知。`unknown` 不能被补成 `false`。[CLM-DR-MEM-03-K11] 时间先后不能自动升级成因果，这一条在本包只作为保守设计边界，不冒充已获独立 A／B 级承托的外部结论。

物品持有、多伤势、冷却和倒计时更适合从独立变化汇总当前值，而不是在多个 current 字段之间双写维持一致。[CLM-DR-MEM-03-K09] [CLM-DR-MEM-03-K10]

## 只能当经验或候选假设

发生、说过、相信、误信、梦到和计划很可能需要分开，结构化记忆、长上下文和 RAG 也很可能要按任务组合；但两份新报告没有导出真实来源，不能在本轮单独升级为已知结论。[CLM-DR-MEM-01-U01] [CLM-DR-MEM-02-U01]

规则、能力和例外是否提前拆条，取决于是否需要计算、触发、验证和跨场景复用。当前没有证据支持把所有自然语言规则预先原子化。[CLM-DR-MEM-04-U01]

## 分歧与反例

互动叙事工具和时态数据库支持“单一可写真源＋派生视图”的方向，但小说中的心理、关系、隐含动机比物品持有更难确定。工程同构不能替代作者语义确认。[CLM-DR-MEM-03-K13]

异步投影可能 stale；重新计算也可能因历史缺失、规则变化或分支选择得到不同结果。因此“删快照即可恢复”不是无条件承诺。[CLM-DR-MEM-03-K06] [CLM-DR-MEM-03-K07]

## 不能证明什么

外部材料不能替产品冻结表结构、字段、关系类型或原子化粒度。也没有公开小说基准能证明“把全部历史放进长上下文”“全部进图”或“全部拆条”在本产品任务上最优。[CLM-DR-MEM-02-U01] [CLM-DR-MEM-04-U01] [CLM-DR-MEM-03-K02] [CLM-DR-MEM-03-K05]

## 对产品设计的候选启示

可以把事件、来源、版本和作者确认当更硬底座，把 current 状态视为带锚的投影；状态应能表达 stale、unknown、conflict 和 branch。事实、计划、人物认知和查询结果继续分层。这个方向与 R13 相容，但外部报告不产生数据库合同或开工权。[CLM-DR-MEM-03-K01] [CLM-DR-MEM-03-K06] [CLM-DR-MEM-03-K11] [CLM-DR-MEM-01-U01]
