# 中国网文作者生态与民间话语

## 可以作为外部先验

中国网文圈常用词不是一套统一技术标准。较稳定的做法，是把“有人这样说”和“这个说法被证明有效”分开。比如，“黄金三章”长期存在于平台课程、作者访谈和行业回顾中，但它比较稳定的核心只是**开头尽快给出继续读的理由**，不是一套跨平台唯一公式；平台之间对开篇、签约、更新、福利和留存的口径也并不统一。[CLM-DR-CN-01-K01] [CLM-DR-CN-02-K01] [CLM-DR-CN-02-K03] [CLM-DR-CN-02-K04]

“爽点、期待感、吃书、追更、追读、压抑、降智”等词都具有真实使用基础，但经常把不同层面混在一起。爽点既可能指文本中的状态变化，也可能指读者体验；期待感包含悬念，却不限于悬念；吃书的稳定核心是后文与既有文本或设定发生、或被读者认为发生冲突。[CLM-DR-CN-01-K04] [CLM-DR-CN-01-K06] [CLM-DR-CN-01-K09]

平台数字必须带平台、日期和动作含义。日更数字可能是发文要求，也可能只是福利或活动门槛；“追读”既可能是普通说法，也可能是某个平台的内部指标；同一个词不能跨平台自动共用公式。[CLM-DR-CN-01-K12] [CLM-DR-CN-01-K14] [CLM-DR-CN-02-K02]

## 只能当经验或候选假设

“大纲党／无纲党”不能可靠代表真实工作法，章纲和细纲也没有统一粒度。它们适合做作者自述、材料分诊和界面语言，不适合直接变成后台硬类型。[CLM-DR-CN-01-K10] [CLM-DR-CN-01-K11]

“卡文”更适合作为作者生产症状，而不是单一病因或固定诊断；具体原因仍要回到材料、任务、情绪和流程查证。[CLM-DR-CN-01-K08]

“压抑”“降智”可以帮助作者和读者表达不满，但它们不是可直接写入事实账的标签。更安全的做法是回到可回验症状：角色当时知道什么、有什么目标和能力、哪条既有证据被违反，以及负面情绪是否为作者有意安排。[CLM-DR-CN-01-K17] [CLM-DR-CN-01-K18]

## 分歧与反例

黄金三章的“三”已经在部分传播中缩短成“一章”甚至更短，这说明教程传播会压缩和绝对化原本带条件的经验；它不等于旧说法已被正式废除。[CLM-DR-CN-01-K03] 平台规则也会快速变化，旧课程、旧训练营数字和当前政策不能混用。[CLM-DR-CN-02-K05]

## 不能证明什么

当前没有公开因果数据能把“某种黄金三章写法”换算成固定追读增益，也不能把高留存直接等同作品好、把低追读直接诊断成结构差。[CLM-DR-CN-01-K19] 固定“日更一万”等说法也不能从个别活动、福利或社区话语升级成全体作者强制规则。[CLM-DR-CN-02-K10]

3—20 章作者是否在固定章数必卡、真实输入材料分布、教程传播链的原发出处，目前仍有未补链或无代表样本的缺口。[CLM-DR-CN-03-U01] [CLM-DR-WF-01-DERIVED-U01] [CLM-DR-CN-06-DERIVED-U01]

## 对产品设计的候选启示

前台可以继续使用作者熟悉的民间词，但后台应把它翻译成“可观察事实＋来源＋范围＋不确定性”。平台规则、编辑课程、作者经验、读者评论和短视频口诀必须是不同来源类型；任何固定数字都要带原始口径。这个方向只是外部先验，不替 R13 拍字段、流程或硬门槛。[CLM-DR-CN-01-K04] [CLM-DR-CN-01-K08] [CLM-DR-CN-02-K05]
