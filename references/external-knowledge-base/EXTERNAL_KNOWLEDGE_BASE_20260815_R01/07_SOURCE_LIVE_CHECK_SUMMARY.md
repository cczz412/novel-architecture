# 背景引用来源打开核验｜2026-08-15

## 结论

本轮只核验 8 张背景页实际引用的 157 个来源，不把 2398 个库存网址全部当作现行证据。

| 结果 | 数量 | 怎么理解 |
|---|---:|---|
| 直接打开 | 144 | 自动请求取得 2xx／3xx 响应；只证明地址本轮可访问，不自动证明内容支持结论 |
| 登录或地区限制 | 4 | 地址存在，但知乎、豆瓣或 ResearchGate 拒绝本轮匿名访问 |
| 检查失败、需要补查 | 9 | 两种轻量请求均超时，不能算实时通过 |

ChatGPT Pro 候选包原有 86 条正向 A／B 结论，其中 85 条至少有一个来源直接打开。`CLM-DR-UX-03-K10` 只依赖两个本轮超时的 Claude 官方文档地址，已经从 A 降为 U，并留在候选边界等待重查；因此本地 R01 现有的 85 条正向 A／B 结论全部通过来源打开门。

逐来源结果见 [07_SOURCE_LIVE_CHECK_RECEIPT.jsonl](07_SOURCE_LIVE_CHECK_RECEIPT.jsonl)，当前状态已回写 [03_SOURCE_REGISTRY.csv](03_SOURCE_REGISTRY.csv)。其余没有进入背景页的库存网址仍标为 `URL_PRESENT_NOT_LIVE_CHECKED`。

## 这次核验没有证明什么

- HTTP 打开成功不等于来源质量高，也不等于网页正文支持报告中的具体解释。
- 登录受限不等于来源失效；正式引用前仍要在合适账户和地区下人工复核。
- 技术文档、平台规则、法律、价格和供应商条款仍按各自刷新条件重新打开。
- 本轮没有制作网页快照，也没有替产品方向拍板。
