# 外部报告知识库

这里是给产品讨论读取的“报告背景板”。它把原始调查报告编译成短背景页、原子结论、来源登记、冲突关系和研究缺口；它不是产品共同背景板，也不是当前执行状态。

## 当前入口

- 机器指针：[CURRENT.json](CURRENT.json)
- 人读入口：[外部报告知识库 R01](EXTERNAL_KNOWLEDGE_BASE_20260815_R01/00_READ_ME_FIRST.md)
- 原始 30 份新报告：[SI-015](../survey-inbox/items/SI-015_external_knowledge_research_returns.md)

## 平时怎么读

日常讨论只打开 R01 的 `background/` 对应主题页。要核数字、规则、技术结论或争议，再按 `claim ID → source ID／report ID → 原文` 往回追。

产品共同背景板回答“我们准备做什么、哪些边界已经拍下”；这里回答“外面有什么证据、经验、反例和未知”。外部报告不能把候选建议变成产品决定。

新报告如何收件、拆结论、合并冲突和发布下一版，见当前版本的 [未来报告准入标准](EXTERNAL_KNOWLEDGE_BASE_20260815_R01/06_FUTURE_REPORT_INGESTION_STANDARD.md) 与[本地更新协议](EXTERNAL_KNOWLEDGE_BASE_20260815_R01/08_LOCAL_RELEASE_AND_UPDATE_PROTOCOL.md)。
