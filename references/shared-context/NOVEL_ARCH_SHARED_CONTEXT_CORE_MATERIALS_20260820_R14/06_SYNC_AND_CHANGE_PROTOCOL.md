## 什么时候需要出新版本

出现以下任一情况，就建立新版本，不在已发布版本里静默改字：

- CZ 新拍或改拍会改变产品语义；
- 正式合同或结果票让现有描述失真；
- 现行版出现会误导执行的冲突；
- 新增或撤销背景板成员；
- 易变登记页的更新影响核心结论。

纯文字修复、不改语义时可以出补丁版，但仍要重算 SHA、登记差异；不得原位改写已发布父版。
