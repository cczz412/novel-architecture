## 这套材料解决什么

R08 承接 R07 的共同产品说明，用来让不同窗口在“产品要解决什么、故事真值怎样管理、作者怎样确认、修改怎样传播”上说同一种话。它不是当前执行票，也不能覆盖正式治理合同、冻结合同、结果票或 CZ 的新指令。

这一版的主要工作是把 R07 冻结后 CZ 一整晚的密集拍板（挂账本 ADD-001～017）吸收进正文：产品红线的最终口径、人怎么跟产品交互、导入与教程怎么走、规划账长什么样、停点系统、插件系统、商业口径冻结，以及 MVP 抽取管线的第一批实测结论。

## R07 → R08 主要变化（十分钟看懂这版变了什么）

按主题分组；每组给落点页。拍板日期均为 2026-08-13，逐条原文见挂账本。

### ① 产品定位与红线（01 页）

- **产品＝提示词工厂**（J1）：把“怎么写”的全部思考展示给用户（全是现成规划账的组装），用户拿指导粘到任何外部写作 AI；红线只有一条＝不给写作模型、不生成成文。教程、台词扩写、场景卡对白要点全按“给要求不给成文”执行，多稿悬着的“红线精确划界”一次关闭。
- **“不代写”升级为主动卖点**（ADD-001）：可核验的全书理解是付费意愿最前排，书稿生成反而是付费态度最分裂的动作。
- 试用版／高级功能分界；隐私姿态＝私人空间感（J3）；产品名字不急（J8）。

### ② 交互模型（02 页，新章）

- 补上两代设计都没回答的“人怎么跟产品交互”：**画布是真身、点哪里哪里就是入口、聊天框是万能入口但产出必须落画布**（ADD-006），配防乱三机制。
- AI 建议要**署名到出处**（F4）；画布概念澄清为单一连续概念（ADD-008）。
- **上下文负担纪律**（ADD-007）：账本可以细、执行包必须瘦，两道门＋存而不喂；D11 伸缩压缩确认回捡并列为“必须好好设计的大难题”（ADD-008），专项设计单已派。

### ③ 账本体系（02、03 页）

- **真值方向性**（ADD-010）：有书稿则书稿为真（抽错＝产品的错）；产品内创作则规划为真（写偏＝作者的事）；新章入库真值接力棒交回书稿。
- **规划账成形**（ADD-004 七题）：界面叫大纲、内部叫规划账；五层篮子；选项消化清单即时对账；字数预估驱动槽位映射；来源身份同篮。
- 全书大纲引导分层深化＋理论拆解＋长线节奏监控台＋节拍 BEAT（H2）；选线成为开章第一动作（H1，细化 N19-B）；章级沙箱多开（H3）；整章重写＝分层回退（H7）。
- 新账本对象：人物账（H4，聚合视图防第二真源）、灵感账（“删了欠不欠账”判据）、义务账定名；版本管理（章＝门牌＋版本链）与反向剧情图管线两张地基设计单交付（GAP-01／03）。
- 触发系统绑事件不绑章节号＋预热＋素材栏（G2）；矛盾＝剧情机会（G4）；**体检只属导入侧**（G7，覆盖旧读法）。
- M8 续写规划重画：要点汇聚一屏＋主架卡片编排（G3）、选项折叠区＝变更清单（G1）、前文最小修＋欠账分期（F1）、驳回＝思路级否定必记必读（F8）、口味配置（G8）、选项＋手写混合输入＋落位核查（J5）。

### ④ 导入与教程（03 页）

- **材料架**：多格式接收＋六架分拣＋三铁规（ADD-003）；分拣确认小白档后置＋疑似正文丢失四类强停（ADD-009）。
- 普通导入 ≤10 章；**整本工程**黑盒批处理带积分／时长预估；拆解是基础动作、体检可选、批量动画跳过体检（Q3）。
- **教程双路**（ADD-001）：路 A 零额度预制放映厅／路 B 真数据速通到剧情层；激活事件＝90 秒确认一条能点回原文的事实；**演示书改用真书前三章**（J7，自拟微书作废）。
- 审查默认视图＝**故事概览**（半屏 SVG＋梗概，通用展示原则，Q1）；概览身份＝感官愉悦＋自我认知，可产出“发抖音的解说画面卡”（F2）。
- 拆书菜单立规矩：**文风模仿永不上菜单**，拆别人的书＝隔离研究项目（ADD-009 附）。

### ⑤ 停点系统（01、03 页）

- **停点即设置**（ADD-005）：全流程停点位预先埋位，三档可配；**小白默认放行、高级作者才频繁停**（方向反直觉但拍死）；真值签字不进档位。
- 注册表 P1–P21（含两次撞号裁定）；强制必停分 S 类护账本／F 类护钱包。

### ⑥ 插件系统与节奏包（02、03 页）

- 写法挂件升级为**插件（Skill）系统**（ADD-014）：一切理论技巧走卡牌制无自动冒出；同一插件按消费场景**分层取用**（剧情生成 ≤50 字／段落写法 100–300 字／分镜画面……）；**渐进式披露**（索引行常驻＋内容层按需单层）；分层标准公开给用户自制。
- **体裁节奏包**（H6）：网文节奏内置可解耦；主节奏与出口节奏分离；网文→漫剧切集＋QC 豁免协议（只免“查无此事”）；跨书结构复用 v2 预留（H8）。
- 角色视角模式（ADD-008 新设计，替代旧三身份）：防降智／创意／沉浸冒险三用途，**V1 只进防降智重放**（J6）。

### ⑦ 商业口径冻结（01、08 页）

- 当晚先拍了免费／付费双轨与积分预估制，随后 CZ 两次收口：**收费全部暂行**（ADD-008）→ **付费墙话题全面冻结**（J2）。此前各稿付费墙／免费额度讨论全部视为占位。
- 保留下来的是话术与原则：对外话术黑名单三句、积分预估制化解“无法预测消耗”骂点、BYOK 不重复扣费、失败不收费、看引用不计积分、护城河＝开放导出＋持续校准（ADD-001／002）。

### ⑧ 抽取管线实测结论（04 页，MVP 实测先验）

- **边设计边实装边实测**授权（ADD-015）；🔥 **双 API 纪律**：抽取与质检必须不同家族模型。
- 六段管线实装（主抽豆包→程序回填引文→补漏 GLM→跨家族验真→去噪→去重）；实测硬数据：密度波动大头是漏抽不是题材、设定密集块漏抽两次复现、表观补漏率被粒度灌水（28%→净口径 5–11%，三修后 7%）、质检修正建议一半误改（固化为只挂建议待人审）、交叉审计价值实锤。
- **API 暂行分配表**（J4）：抽取＝豆包 turbo、质检＝GLM 5.2，暂行不等人；**全部标注“MVP 实测先验，研究线 DISCRIM17／T-03 出结果后校准”**，不改研究侧任何数据资格与训练门。
