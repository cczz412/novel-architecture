# 抽取、模型与数据策略

状态：**项目级共同背景的易变现场页；证据截止 2026-08-08 18:50 +08:00**

这页只讲当前证据允许推出什么。它不会替 CZ 发训练令，也不会把一次本地实验写成生产定版。

## 长期不轻易变的抽取原则

- 目标是登记后续不能安全遗忘的关键变化，不是一次穷尽全文；
- 其他细节留在冻结正文，作者问到时按需回取；
- 模型负责语义选择，程序负责编号合法性、逐字回填、位置、SHA、排序和 Schema；
- 程序能证明证据来自原文，不能单独证明证据在语义上托住主张；
- 查询回答默认不写永久底账；
- 生产模型不能给自己的输出签质量绿票；
- 答不出要回“材料不足＋回取轨迹”，不能补故事。

## SEMANTIC_CORE / FACT_ONLY 当前结论

这条线只练“抽哪些事实、怎样写事实句”，答案放在独立 `fact_sentences` 容器。它不是 C2 正式输出合同，也不是生产配方。

Z00／Z01 已在同一批 48 个案例上完成配对零训练诊断：A_CORE 使用无编号正文，C2_CORE 在同一正文插入 B/T 编号；两边都没有加载 LoRA、训练或调用 API。当前窄结论是：C2 编号没有明显伤害召回，但多报更多题外事实，使单人语义复核下的精确率和 F1 下降。

这轮只有一次独立语义审查，也没有测 `evidence_ids` 负担、跨单元负担或训练后胜负。当前状态是硬停等待路由。5%／10% 混训没有运行，不能把这条线写成“训练有效”，也不能整条归档成历史。

## P4｜R01 截止后的本地预检

P4 已把后续研究收成一份窄合同：模型可以读取更宽的只读上下文，但只能在尾部责任区产生新事实和合法 evidence。背景区不能替正文 evidence，章序、区序、位置提示、任务目的、前态、背景卡和示例都先冻结，避免把多个变量混在一起。

这仍只是预检。真实完整章合格数是 0／12，因此没有读取真实小说正文、生成合成章、运行真实六臂、训练或调用模型 API。外部研究只提供“以后值得测什么”的先验；本地直接证据仍以 P3 和 P4 票据为准。

## 证据位置合同

当前本地候选要求每条事实能回到：

- 稳定事实编号；
- 原始来源 SHA；
- 0 起算、左闭右开的起止位置；
- 逐字切片回验；
- 目标责任区内的合法证据编号。

已核结果是 396 条事实可唯一定位，1 个重复出现的证据行被隔离，39/40 个原型行通过最终位置门。这个机制已经建立为本地候选，但还没有覆盖全部生产数据。

## 未来新素材的窄选段纪律

CZ 2026-08-07 00:20 的拍板和账序 00:24 条，在本地共同选材账中落成一条只管“以后新增”的窄规则：同一本书通常取 1～2 段，跨窗口合计最多 4 段；同一作者名下全部作品合计最多 4 段；多段要来自不同章节；优先较新、较贴近当前连载节奏的网文；不倒逼旧存量重切或重删。作者未核实、片段重复或权利未清的材料只能留在候选区。

这是一条取材和去重纪律，不是训练许可，也不是 Production Canonical 的完整合同。旧账里“只维护正向＋特殊两个消息卷、单文件超过约 10MB 才拆”的文件组织口径，没有进入当前生产路线。当前本地目标是一份 Canonical 语义真源，A／C2 从它机械派生；普通、特殊等是样本类别，不是两份互相竞争的真源。

## Production Canonical 的门

“Production Canonical”是可供正式训练和同源评测的唯一生产教材候选。生成它前，至少要同时满足：

1. 每个纳入来源的训练权能回到证据或明确裁定；
2. 作品、作者、来源身份清楚；
3. 每条证据的位置和 SHA 可回验，歧义不能由程序猜；
4. 普通分布与特殊分布都达到预先规定的覆盖；
5. 作者级、书级、来源级 TRAIN／DEV／blind 不交叉；
6. 五本真实候选的 DEV／blind 角色和污染边界已拍；
7. 正式 evaluator、人工复核规则和阈值与同一数据版本冻结；
8. 两次独立构建逐字节一致。

现在有计划、有部分资格修复，但没有 Production Canonical 数据集本体。

## 评分不能压成一个总分

当前评分至少分六层：

1. 输出是否生成、是否触顶、是否复读；
2. JSON 和 Schema 是否合法；
3. 逐字 exact；
4. 事实语义是否命中、是否多抽或漏抽；
5. evidence 编号、原文、位置和 SHA 是否合法；
6. 语义是否真的被证据承托，以及是否需要人工复核。

Evaluator R02 已机械重算 164 个案例、1,420 条事实，但 164 个案例的人工语义队列仍待处理。67 个 invalid JSON 继续算失败，107 个案例进入复读诊断。任何单一“准确率”都会把格式失败、事实错误和证据绑定错误互相遮住。
