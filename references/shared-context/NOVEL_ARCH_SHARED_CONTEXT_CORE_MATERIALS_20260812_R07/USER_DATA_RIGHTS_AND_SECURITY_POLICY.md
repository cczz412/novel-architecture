# 用户数据权利与安全政策

状态：**R07 现行辅助成员；不是已生效的隐私政策、用户协议或法律意见。** 本页汇编 N05-A、N10-C、N12、N18 的批准方向；依据账序 2026-08-12 21:18 条，且法律复核和安全施工合同完成前，不能拿它向用户作承诺。

## 政策总句

仅在当前著作权人或授权方明确许可的权利、地域、期限和用途内处理材料；每次访问只给当前任务所需的最小范围。系统和外部参与方都不能绕过确认直接改写真源。用户数据默认不用于训练，删除、导出、第三方处理、人工审查和日志都必须有明确边界与可追溯记录。

## 适用对象

- 用户上传或连接的书稿、剧本、章纲、梗概、参考资料和第三方 IP；
- 作者签字、作者私有 Canon、剧情原子、状态账、索引、缓存和派生材料；
- 参考图、LoRA、素材、候选镜头与冻结生产资产；
- 模型输入输出、人工审查材料、运行日志、权限日志和导出记录；
- 从上述内容形成的训练候选、评测候选或调试样本。

## 权限：读和写都要管

来源条目：N05-A；R03 候选源状态：`READY_TO_DECIDE`；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

### 写入边界

- 外部工具、合作方、MCP、CLI 和人工成员只能提交修改提案，不能直接改写真源。
- 提案必须包含修改对象、理由、来源、影响预览和请求的生效范围。
- 作者或有权主体批准后才能落账；批准前只在提案或投影层生效。
- 撤回、拒绝、超时和部分批准都要留下处置记录，不能把未批准提案伪装成当前 Canon。

### 读取边界

- 作者私有 Canon 默认拒绝外部读取，不因“接上工具”自动开放。
- 每次授权至少判断：主体、对象、字段、动作、用途、项目、有效期。
- 只开放当前任务所需字段和最短可行期限；跨项目、跨用途、扩大字段或延长期限都要重新授权。
- 撤销后阻断后续读取，并保留不含正文内容的撤销与审计记录。
- 用户能查看和导出自己的授权记录、访问记录和变更提案记录。

## 分动作权利账

来源条目：N10-C；R03 候选源状态：`READY_TO_DECIDE`；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

“自有、授权、公版”不能代替按动作判断。每份材料至少逐项登记：

| 处理动作 | 必须核对的权利信息 | 权利不明时 |
|---|---|---|
| 私下存储与分析 | 授权主体、允许的内部处理、地域、期限 | 不接收或隔离，不能默认“只在后台所以没问题” |
| 生成改编内容 | 改编或相关许可、用途、作品范围、地域、期限 | 不生成可交付改编内容 |
| 公开传播 | 传播范围、平台、地域、期限、署名与完整性要求 | 不发布、不外发 |
| 收费 | 商业使用许可、收益或结算约束、地域、期限 | 不收费、不包装成商用许可 |
| 交第三方模型处理 | 是否允许第三方处理、处理主体、用途、保存与再使用边界 | 不发送第三方 |
| 用于训练 | 是否明确允许训练、训练对象、模型归属、用途、期限、退出与删除条件 | 默认不训练 |

能否转授权要单独登记，不能从“允许使用”推成“允许再交给别人”。“公版”要写清司法辖区和作品类型；在中国语境中，署名权、修改权和保护作品完整权不因保护期届满自动消失。正式上线前由律师复核权利账模板、政策文本和高风险用例。

## 数据保存、版本与删除

来源条目：N12；R03 候选源状态：`READY_TO_DECIDE`；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

- “底层原子和证据永不删”只适用于活跃项目内部：历史版本不能被静默删除或改写。
- 这条审计纪律不是平台永久保存用户内容的理由，也不能对抗用户的合法删除请求。
- 删除项目或账户时，按适用政策清理原文、剧情原子、状态账、索引、缓存、派生材料和训练候选；第三方处理方和备份链的删除范围、时限与例外要在施工合同中明确。
- 必须留存时，只留最少量、不含用户内容的删除回执；回执说明请求、范围、处理结果和依法不能立即删除的例外，不保存可还原书稿的文本、向量或摘要。
- 删除不能靠只删前台文件完成；索引、缓存、派生材料和未使用训练候选也在范围内。
- 活跃项目的版本历史与用户删除权发生冲突时，按适用法律、合同与账序裁决处理，不能让工程方便自动获胜。

## 默认不训练

来源条目：N12；R03 候选源状态：`READY_TO_DECIDE`；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

- 默认不把用户材料、剧情原子、派生材料、日志或人工审查样本用于自家训练、第三方训练或训练数据改进。
- 第三方模型服务商必须受同一边界约束；不能用“不是我们训练”规避默认不训练。
- 调试、评测、人工审查和质量回放不自动等于训练许可，但也不是无限使用许可；各自要有目的、范围、期限和访问人记录。
- 任何训练例外都需要独立、明确、可撤销且能回到具体材料与用途的许可；本草稿不提供这种许可。

## 第三方处理

来源条目：N05-A、N10-C、N12、N18；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

- 发送前确认处理主体、数据对象、必要字段、用途、地域、保存期限、再使用边界和删除方式。
- 优先发送当前任务所需的最小片段；AUTHOR 范围内容默认不发。
- 第三方返回只能成为候选结果或修改提案，不能直接获得真源裁决权。
- 第三方更换模型、地区、分包商、保存政策或再使用条款时，旧授权不能自动沿用。
- 每次发送和返回都要能回到项目、任务、材料版本和授权记录。

## 日志与人工审查

来源条目：N12、N18；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

- 日志按用途分层：安全与审计日志、运行诊断日志、产品分析日志不能混成一个无限保留池。
- 默认不在普通日志记录完整书稿、作者私有 Canon、密钥或可还原内容；必要诊断采用最小片段、脱敏标识和短期权限。
- 人工审查只允许经授权的人员在明确任务、项目和时限内查看必要内容，并记录查看人、时间、对象、原因和处置。
- 人工审查材料不得私自复制到个人设备、聊天、外部工单或训练集。
- 日志和审查记录的保留期限、删除例外与安全事件处置留给正式政策和施工合同冻结。

## 导出与可携带性

来源条目：N05-A、N18；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

- 用户能导出其书稿、确认后的故事状态、版本与来源记录、权限记录、修改提案和 AI 参与回执。
- 导出要保留对象身份、版本、时间、来源和可见范围，避免离开系统后把计划、作者私有内容或候选结果冒充成已发表事实。
- 导出前做权限过滤；团队成员不能借项目导出获得其无权查看的 AUTHOR 内容或第三方素材。
- 机器可读格式、签名、哈希和兼容格式留给施工合同，不在本方向稿提前拍字段。

## 租户隔离

来源条目：N18；R03 候选源状态：`READY_TO_DECIDE`；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

- 不同用户、团队和项目的数据默认隔离；检索、缓存、向量索引、日志、导出和人工审查都不能跨租户串读。
- 团队协作只能在已授权的项目范围内共享，角色权限不自动扩展到其他项目。
- 测试、演示和故障排查不能拿真实租户内容当默认夹具。
- 隔离方式、密钥管理、备份和恢复演练属于后续安全施工合同，本页只冻结方向候选。

## 留痕、撤销和安全事件

来源条目：N05-A、N18；本页状态：`APPROVED_DIRECTION`，依据账序 2026-08-12 21:18 条。

- 授权、读取、提案、批准、拒绝、撤销、导出、第三方发送、人工查看、删除和例外都要有审计记录。
- 审计记录服务于问责与用户查询，不成为永久保存用户正文的后门。
- 撤销不抹去过去合法发生的审计事实，但要阻断后续访问，并启动适用范围内的删除或失效处理。
- 若发生越权访问、跨租户泄漏、第三方超范围保存或删除失败，立即停止相关处理，保存必要证据，并按正式响应流程通知有权主体；具体时限和责任人留正式合同。

## 上线前硬门

- 分动作权利账的字段和用户提示经过律师复核；
- AUTHOR 默认拒读和最小授权经过安全测试；
- 项目／账户删除能覆盖原文、索引、缓存、派生材料、训练候选和受控第三方；
- 默认不训练能覆盖服务商条款、日志、人工审查与数据改进设置；
- 导出与权限过滤通过跨角色测试；
- 租户隔离、审计、备份与安全事件演练有正式结果票。

这些硬门只是首个作者可用验收前的方向性前置条件，不代表已经完成，也不授权接收真实用户材料。
