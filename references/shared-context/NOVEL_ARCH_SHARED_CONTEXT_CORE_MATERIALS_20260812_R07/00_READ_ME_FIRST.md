## 这套材料解决什么

R07 承接 R06 的共同产品说明，用来让不同窗口在“产品要解决什么、故事真值怎样管理、作者怎样确认、修改怎样传播”上说同一种话。它不是当前执行票，也不能覆盖正式治理合同、冻结合同、结果票或 CZ 的新指令。

这次新增内容把五件事说得更清楚：谁有权说某件事是真的、凭什么是真的、什么时候是真的、谁能看到，以及怎样修订、撤销或删除。同时补入最短产品证明路径、规划槽位映射、告警覆盖回执、市场验证登记和用户数据权利边界。

## 三层权力关系

| 层 | 回答什么 | 当前真源 |
|---|---|---|
| 裁定证据 | CZ 到底拍了什么 | CZ 最新明确指令与可回读的 Notion 账序原文 |
| 共同背景板 | 大家怎样理解系统 | 现行是 R07；R06 作为不可变父版保留 |
| 执行现场 | 代码、数据、实验实际做到哪里 | 本地现役指针、冻结合同、正式结果票与 Reality Packet |

同一问题有冲突时，按“CZ 最新明确指令或账序拍板 → 领域正式合同与结果票 → 当前指针 → 有边界的实验结果 → 背景板编译文字 → 研究建议”处理。R03 和四份需求回包都是编译输入，不可单独代替账序裁决。
