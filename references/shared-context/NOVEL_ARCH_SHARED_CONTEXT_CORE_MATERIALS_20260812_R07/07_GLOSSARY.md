- 旧 C 版 ≠ C2_UNIT ≠ C2_FULL ≠ P3 C2 任务目的；
- TRAIN 标签 ≠ 训练权利；
- DEV ≠ blind；
- 背景卡 ≠ evidence；
- 场景 ≠ 真值容器；
- 大纲／剧情图 ≠ 已发生历史；
- 查询回答 ≠ 永久事实；
- 本地候选 ≠ 生产默认；
- 共同背景板 ≠ 账序真源；
- Repo Bridge ≠ 权力渠道；
- 零训练诊断 ≠ 混训完成；

- 书稿 ≠ 实验侧“正文”数据容器；

- 作者锁定真相 ≠ 读者已释放；
- 沙箱产物 ≠ 主线真值；
