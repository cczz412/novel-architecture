# 术语表

状态：**随项目级共同背景 R05 使用；遇到上游正式合同改名时发新版本**

| 术语 | 大白话解释 | 当前地位 | 容易误解成什么 |
|---|---|---|---|
| 裁定证据 | 记录 CZ 当时拍了什么的原始账 | 正式权力层 | 不是任意 Notion 页面或聊天摘要 |
| 共同背景板 | 把有效裁定和当前现场编译成可读的共同认识 | R05 是当前项目级指导 | 不取代账序，不自动发施工权 |
| 当前文件夹入口 | 告诉拿到本目录的人从哪里开始读 | `00_READ_ME_FIRST.md` | 不是目录外稳定指针，也不覆盖 `CURRENT_STATE.json` |
| 项目接入参考 | 保存稳定入口、机器指针和 Agent 自动读取的扩展方案 | 当前只启用 `AGENTS.md` 的只读入口 | 不会接管运行状态或授权 |
| 执行现场 | 本地代码、数据、模型、指针和结果票的实际状态 | 以本地真源为准 | 不等于 Git 提交里已经全部存在 |
| 冻结正文 | 带版本、来源位置和 SHA 的原文 | 最终证据 | 不是可以静默覆盖的工作稿 |
| 事实 | 已发生、可判断真假、能回到证据的主张 | 真值层候选对象 | 不包括未来计划和 AI 猜测 |
| 关键变化底账 | 后续写作不能安全遗忘、经确认后长期登记的事实 | 已拍长期方向 | 不宣称穷尽全文 |
| 查询结果 | 为当前作者问题生成的带证回答 | 临时结果 | 默认不是永久事实 |
| 计划事件 | 作者打算以后写成的事 | 计划层 | 没写成前不能发事实编号 |
| 故事状态 | 人物、地点、资源、身份、关系等当前值 | 当前可消费状态 | 不等于整段历史摘要 |
| 知情 | 谁知道、怀疑、误信或不知道什么 | 长期记忆的一部分 | 不只是一个真假标签 |
| 长线账 | 故事线、因果、义务、规则和触发条件 | 长程一致性约束 | 不复制第二份事实正文 |
| 多粒度派生摘要 | 事实压缩视图的不同形态，例如胶囊或章节摘要 | 非真值；和事实句压缩是同一体系 | 不是另建摘要库，也不能替代冻结原文 |
| 按需回捞 | 远期压缩只作导航，需要时重新读取冻结原文核证 | D11／D27 的刚需通道 | 不等于把正文分片向量库当真值；检索可用 BM25／向量扩召回 |
| 大纲中枢 | 作者安排本章和未来的主要工作面 | 已拍产品中心 | 不是历史真值库，也不是正式正文编辑器 |
| 反向剧情地图 | 从已有正文整理出的成文结构 | 导入作品的投影 | 不能叫作者原始大纲 |
| SceneUnit／场景单元 | 生成、交付和局部重做的工作单位 | 已拍概念，字段待落 | 不是真值容器 |
| 卡片 | 处理本章问题的工作单元 | 已拍产品概念 | 不按固定 5～8 张机械切章 |
| 场景执行包 | 程序为当前场景编译的最小上下文 | 可重建缓存 | 不是真值，不默认塞全文 |
| 投影 | 正文、分镜、互动和导出资产 | 可重建输出 | 不能静默反写真值 |
| 来源编号／source ID | 指向冻结原文的一把稳定钥匙 | 证据合同核心 | 不是模型随手编的引用名 |
| evidence | 支撑事实或回答的原文依据 | 必须可回验 | 原文里出现过不等于语义一定支持 |
| canonical evidence position | 证据在原始来源中的明确起止位置和 SHA | 本地已建立候选 | 不是文本搜索到第一个相似句就算 |
| C2_UNIT | 局部 B/T 事实单元、责任区和 evidence ID 的合同／表示家族 | 本地已建立候选 | 不是单个 checkpoint，也不是 P3 的 C2 输入臂 |
| C2_FULL | M1 中使用完整 C2 答案格式的实验臂，并沿用为该臂本地 LoRA checkpoint 名 | 合成风洞候选 | 不是另一份生产合同，也不是 P3 的短任务目的 |
| 旧 C 版／编号短锚版 | 旧 A／C 对照里输出证据编号和不超过 5 字短锚的格式 | 旧专项记录保留；当前本地路线不直接沿用 | 不是 C2_UNIT、C2_FULL 或 P3 的 C2 任务目的 |
| responsibility zone／责任区 | 本次调用允许产出新事实和引用证据的窄范围 | 机械机制已建立 | 不代表最优粒度已经测出 |
| one-stage | 一次调用直接抽事实和证据 | 当前候选基线 | 不是生产已拍路线 |
| evidence-first | 先选证据，再生成或校验事实 | 实验路线 | 尚无真实生产对照 |
| SEMANTIC_CORE / FACT_ONLY | 只练抽哪些事实、怎样写事实句的辅助任务和输出模式 | Z00／Z01 零训练诊断已完成并硬停 | 不是整个混训实验的同义词，也不是生产输出合同 |
| Input Context Contract | 研究规则、目的、前态、背景和结构元数据怎样进输入 | 实验中 | P3 只完成局部淘汰，不等于 Prompt 定版 |
| Background Context／背景卡 | 作者确认的别名、身份、类型和规则等只读辅助材料 | 仅讨论／未测充分 | 不能替正文 evidence 补证据 |
| Wide Read / Narrow Write | 更宽阅读、只在窄责任区产出和引用的候选输入边界 | P4 预检合同已建立，真实实验未跑 | 不是产品已拍术语或生产默认 |
| R01 后研究增量 | 把证据截止后新增的研究先验、本地实测和预检状态分开登记 | R03 活页内容 | 不是把研究报告直接升级成规则 |
| Repo Bridge | 外发时绑定仓库快照、业务包和回包的运输候选 | 协议冻结观察中，尚未通过 | 不是权力层、业务真源或施工授权 |
| Production Canonical | 同时满足权利、身份、位置、分布、切分和评测门的正式生产教材 | 计划存在，数据集未生成 | 不是文件名里带 TRAIN 就算 |
| TRAIN／DEV／blind | 训练、开发选择和最终未知测试三种隔离角色 | 需作者／书／来源隔离 | 历史 exam 或参与选型的 DEV 不能再叫 blind |
| local proxy | 本地低成本诊断代理 | 当前是 Qwen3-4B | 不代表生产模型效果 |
| production candidate | 未来可能承担正式任务的模型候选 | Mini 是当前唯一首选；4B 另有免费档部署设想 | 不是已经部署的生产默认，也不自带训练权 |
| escalation candidate | 首选不合格或复杂任务需要时才升级使用的候选 | Lite 是当前后备升级选项 | 旧 Notion“Lite 首发”已经是被新顺位取代的历史 |
| 4B 实验角色 | 低成本淘汰明显失败方案、调试数据和格式合同 | 当前持续可用 | 配方赢家不能直接外推为 Mini 赢家 |
| 4B 免费档候选 | 事实、格式和成本都过门后，可继续调优并部署到低成本 GPU 的设想 | 仅讨论 | 不是已部署、生产默认或已晋级 |
| evaluator | 分开检查格式、语义、复读和 evidence 的评分体系 | R02 机械层已建立 | 不是一个能替人工判断所有语义的模型 |
| 机械正确 | JSON、编号、原文、位置、SHA 等可确定性复算 | 程序可证明 | 不等于事实含义正确 |
| 语义正确 | 主张完整、限定正确、证据真正支持 | 需独立评分或人工判断 | 不能由生产模型自签 |
| 红灯 | 两端证据可回验的已确认事实、义务或硬规则冲突 | 硬风险 | 不能用于尚查不实的隐含或多跳矛盾，也不能宣称查尽 |
| 黄灯 | 节奏、情绪、手法等可忽略建议 | 软提醒 | 不应反复追旧账 |
| 待复核线索 | 隐含、多跳、动机类或证据尚未闭合的矛盾候选 | 进入裁决队列 | 不是已确认红灯；无结果时只说“当前覆盖范围内未检出” |
| 因果边派生视图 | 从事实中派生的直接因果候选关系 | 程序出候选对，模型逐对判有边／无边／待复核 | 不进事实真值层，不做开放式补边，长链强度更低 |
| 硬停 | 当前证据或授权不足，必须停在边界前 | 执行状态 | 不是项目永久失败 |

## 禁止混用的几个词

- 旧 C 版／编号短锚版 ≠ `C2_UNIT` 合同／表示家族 ≠ `C2_FULL` 实验臂／checkpoint 名 ≠ P3 的 `C2 任务目的`输入臂；
- `TRAIN` 切分标签 ≠ 训练权利；
- `DEV` ≠ final blind；
- 背景卡 ≠ evidence；
- 场景 ≠ 真值容器；
- 大纲 ≠ 已发生历史；
- 查询回答 ≠ 永久事实；
- 本地候选 ≠ 生产默认；
- 共同背景板 ≠ 账序真源；
- Repo Bridge ≠ 事实真值／CZ 裁定／施工权；
- SEMANTIC_CORE / FACT_ONLY 零训练诊断 ≠ 混训已完成。
