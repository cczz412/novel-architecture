# 六本金标 UCR 核准回包｜本地归档

这 12 份文件是 CZ 已上传 Notion 的六窗核准回包本地原件，每本两份：一份审阅说明，一份候选 JSON。

本目录只解决“原始回包以后从哪里找”的问题。2026-07-24 20:20 的 Notion 审收口径是：

- 收件审收通过；
- 资料层级仍是候选银标；
- 不替换现役六本金标；
- 不修改正式登记册或任何 `current` 指针；
- 未走金标拆分与 MRP-72 发布门前，不得当成现役真值。

原件位于本机 `原始回包/`，该子目录按仓规不进 Git。逐文件归档名、大小和
SHA-256 见 `SOURCE_MANIFEST.json`；机器上的下载绝对路径不写进仓库。

换机后缺少 `原始回包/` 不等于仓库损坏：导航与边界说明仍可读，只是依赖这些
候选原件的回放测试会明确标成“缺本地证据而跳过”。
