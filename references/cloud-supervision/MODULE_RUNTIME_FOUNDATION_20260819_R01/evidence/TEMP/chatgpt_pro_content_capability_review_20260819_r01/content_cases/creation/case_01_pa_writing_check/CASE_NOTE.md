# 案例 01｜工作稿检测包与结果接收

这是完全合成的作者工作稿。程序实际生成了章槽快照、检测输入包和正式结果对象，并把检测包排成人读文本。

## 请 Pro 审的内容问题

- “没有立刻答应”与“明确拒绝”的差异是否应标成 mismatch。
- “不得揭露寄件人身份”这种否定性要求，只靠一条引文能不能判为 covered。
- unplanned 细节是无害的氛围，还是应让作者处置的新设定？当前结果只记录，不判重要性。
- 人读页目前展示了检测输入包，但尚没有对正式检测结果的作者人读排版。

## 不能证明什么

冻结 judgment 是人工写的合成 fixture，只用来让现行接收器产生真实输出。它不证明 T14 会在真实稿件上做对语义判断，也不证明已经可以收工。API／模型／重试均为 0。
