# 案例 02｜M8 计划选择卡

这是一个“关系已破裂，却因危险暂时并肩”的合成规划问题。现行 `plan_tool.execute` 实际消费了一条 current＋confirmed 事实，并把冻结 fixture 排成作者可读选择卡。

## 请 Pro 审的内容问题

- A／B／C 是不是真的有三种可用写法，还是只换了句子。
- 推荐 B 有没有保住“合作不等于和解”这个核心。
- 已确认的“今夜不去码头”是否被正确暴露为冲突，问作者的方式是否足够省事。
- 计划卡有没有偷偷加入作者没有说过的重大真相。

## 不能证明什么

卡片内容是手工写的冻结合成 fixture，不证明真实 provider 能生成同等质量，也不证明正式 C7 selection action 已经落账。API／模型／重试均为 0。
