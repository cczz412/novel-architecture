# 案例 04｜M10 场景卡与人物阶段锚点

这个合成场景故意制造了一个时间错位：场景明确发生在沈遥右臂受伤之前，但输入只给了“右臂缠新绷带”的 current 外观锚点。现行确定性导出器照单生成了带绷带的场景卡。

## 请 Pro 审的内容问题

- 作者能不能一眼发现场景时间与人物外观阶段打架。
- 应该由上游提供“按故事位置选锚”，还是 M10 应该在导出时再做一次阶段校验。
- “双手抱木匣”与“右臂新绷带”的冲突应该是硬拒绝、黄灯提醒，还是作者可忽略项。
- 场景卡有没有守住“不展示木匣内部”的防泄底要求。

## 不能证明什么

这不证明 M10 的文字排版错了；它主要暴露了输入端缺少“该场景应选哪个人物阶段”的稳定 owner。也不证明视频、图像或正式 C8 已可用。API／模型／重试均为 0。
