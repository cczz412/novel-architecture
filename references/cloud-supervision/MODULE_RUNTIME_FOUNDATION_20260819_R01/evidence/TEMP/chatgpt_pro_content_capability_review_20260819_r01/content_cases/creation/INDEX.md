# P-A 与 M8～M11 合成内容补审案例

这里有 6 组完全合成的中文故事案例，都围绕《潮汐驿站》这个不存在的测试故事。每组都包含输入、现行函数实际输出、人读输出和审查说明。

1. `case_01_pa_writing_check`：工作稿检测包、冻结判断接收和人读检查清单。
2. `case_02_m8_planning_card`：关系破裂后的临时合作计划卡。
3. `case_03_m9_overview`：confirmed／extracted／rejected 混合时的单章概览。
4. `case_04_m10_scene_card`：场景时间与人物外观阶段冲突。
5. `case_05_m11_budget_selection`：预算下的 HARD／SHOULD／MAY 取舍与回取。
6. `case_06_m11_unresolved_stop`：当前任务遇到作者未决事项时停下。

## 权利与用途

- 所有人名、场景、句子、设定和 provider fixture 都是本次专用的合成内容。
- 没有复制真实小说、正文库、Gold、盲审答案、模型 raw response 或 reasoning。
- 只供外部 Pro 设计内容验收标准；不是真实模型能力 PASS，不是产品上线证据。
- 所有函数调用均在本地锁定环境运行，API／模型／重试为 0，AuthorWorkspace 写入为 0。
