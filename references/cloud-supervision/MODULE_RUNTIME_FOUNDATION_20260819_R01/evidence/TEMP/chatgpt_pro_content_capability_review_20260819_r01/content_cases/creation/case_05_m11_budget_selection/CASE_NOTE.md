# 案例 05｜M11 预算下的装入与遗漏

这个合成任务给了 80 token 的机械预算。现行工具实际装入了两个 HARD 材料和一个 SHOULD 材料；远处氛围细节因预算遗漏，未来揭底材料因不在 current 范围而遗漏。

## 请 Pro 审的内容问题

- “不去码头”和“临时合作不等于和解”是否确实应当是 HARD。
- 上一场的对立语气是否值得占用剩余预算，还是氛围铜铃更有用。
- 未来寄件人被明确排除，能不能避免下游提前泄底。
- 人读结果只显示材料 ID 和选择原因，是否缺少足够的内容预览来让作者判断取舍。

## 不能证明什么

估算 token 是机械 fixture，材料本文也没有被打包进结果。这只能审责任分类、预算取舍和遗漏可见性，不能证明实际上下文能支撑下游写作。API／模型／重试均为 0。
