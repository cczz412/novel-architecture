# M1～M7 内容能力补审案例

这里有 7 组纯合成中文案例。它们不是新的产品设计，也不是模型能力证明；用途是让
外部审查者直接看见现行函数面对具体内容时给作者什么结果，再指出内容质量缺口。

- M1、M2、M5、M6、M7 同时提供机器结果与现行作者可读结果。
- M3、M4 没有对应作者渲染器，只提供现行结构化运输结果。
- 所有 `current_output` 都由 `build_cases.py` 调用当前工作树函数生成。
- API／模型调用／重试：0／0／0。
- 正文身份：100% 合成；真实小说、Gold、raw response、reasoning：0。

审查时请把“机械边界成立”和“内容判断正确”分开。案例通过解析，不代表模块内容能力
已经合格。
