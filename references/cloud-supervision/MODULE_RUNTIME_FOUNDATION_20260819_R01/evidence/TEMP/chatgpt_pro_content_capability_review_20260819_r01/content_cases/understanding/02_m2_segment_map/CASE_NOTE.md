# M2｜把雨夜来信切成可回拼的责任段

## 这份结果怎么来的

- 数据身份：纯合成中文材料。
- API／模型调用／重试：0／0／0。
- 现行函数：segment_tool.execute；segment_tool.render_segment_map。
- `current_output` 是运行上述现行函数得到的，不是人工仿写。

## 作者现在看到什么

- 每段的责任正文、前后只读上下文、字符坐标和来源章节版本。
- 所有责任段按顺序用换行连接，可以回拼成规范化后的整章。
- 段落过渡、台词和动作是否被切开，可直接从人读地图判断。

## 请重点审什么

- 现有机械切段是否把一句完整的动作或台词拆坏？
- 责任段大小和前后上下文够不够支撑后续事实抽取？
- 作者能否理解“责任正文能产事实、halo 只能辅助理解”的区别？

## 这份案例不能证明什么

- 不能证明这是最符合叙事语义的切段，只证明覆盖、坐标和回拼成立。
- 不能证明长章、极短章、高对白章和格式混乱章的内容质量。
- 不能证明 M3 会从这些段中抽对事实。
