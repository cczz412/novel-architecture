# M4｜把候选变成带证据锚的 EXTRACTED 事实

## 这份结果怎么来的

- 数据身份：纯合成中文材料。
- API／模型调用／重试：0／0／0。
- 现行函数：fact_tool.execute。
- `current_output` 是运行上述现行函数得到的，不是人工仿写。

## 作者现在看到什么

- 每条事实有稳定事实号、候选状态、quote、字符锚点和章节版本。
- 所有条目仍是 extracted，尚未冒充作者确认的真值。
- 本案例没有 M4 作者渲染器，因此当前内容只能通过 JSON 审查。

## 请重点审什么

- 事实句和原文 quote 是否一一对应，锚点能否支持作者快速回看？
- 同一情节被拆成多条后是否太碎、重复或缺少关联？
- 当前事实对象给 M5 审查时，还缺哪些作者能看懂的上下文？

## 这份案例不能证明什么

- 不能证明事实已经确认、去重、跨章合并或迁移到改稿后的新版本。
- 不能证明高信息密度章节出现数百条候选时的筛选体验。
- 不能证明第二批写入和已有事实生命周期已经完整接通。
