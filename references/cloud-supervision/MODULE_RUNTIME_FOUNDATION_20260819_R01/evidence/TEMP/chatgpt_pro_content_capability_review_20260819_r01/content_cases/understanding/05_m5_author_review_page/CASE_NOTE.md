# M5｜作者逐条看事实句和原文证据

## 这份结果怎么来的

- 数据身份：纯合成中文材料。
- API／模型调用／重试：0／0／0。
- 现行函数：review_page_tool.validate_page；review_page_tool.render_page。
- `current_output` 是运行上述现行函数得到的，不是人工仿写。

## 作者现在看到什么

- 一页待审事实，按事实号展示候选句、原文 quote、来源、锚点和版本水位。
- 页面明确写着“尚未确认／驳回”，不会把候选伪装成真值。
- 当前页是只读审查单，不包含确认、改写或驳回控件。

## 请重点审什么

- 作者是否能凭事实句＋quote 做决定，还是需要更宽上下文？
- “林乔决定去北桥”这类意图事实与普通动作事实是否应给不同提示？
- 候选较多时，当前一条条页面是否容易审疲劳，应该怎样分组但不代替作者判断？

## 这份案例不能证明什么

- 不能证明作者动作按钮、分页期间固定水位或高影响单签已经完成。
- 不能证明作者确认会正确传播到 M6～M11。
- 不能证明候选事实本身准确；页面只展示现有候选和证据。
