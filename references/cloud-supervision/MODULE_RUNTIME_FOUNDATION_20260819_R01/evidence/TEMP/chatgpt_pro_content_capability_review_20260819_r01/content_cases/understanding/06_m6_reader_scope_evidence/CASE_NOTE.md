# M6｜截至第一章查询“蓝布包”，不泄漏第二章真相

## 这份结果怎么来的

- 数据身份：纯合成中文材料。
- API／模型调用／重试：0／0／0。
- 现行函数：ask_reader_scope_tool.execute；ask_tool.render_result。
- `current_output` 是运行上述现行函数得到的，不是人工仿写。

## 作者现在看到什么

- JSON 明确记录截至 c01、可见章节 1、未来章节 1、被挡事实 1。
- 证据文本只展示第一章“大家以为是账本”的当前已确认事实。
- 第二章的铜钥匙真相、事实号和章节号都没有进入查询结果。

## 请重点审什么

- “截至某章”的读者口径是否足够清楚，是否会被误当成全书真相？
- 纯关键词“蓝布包”能不能覆盖作者常用的同义问法和指代问法？
- 人读文本没有重复展示 reader scope 水位，这会不会让脱离 JSON 的结果被误用？

## 这份案例不能证明什么

- 不能证明自然语言理解、同义词召回或剧情问答能力。
- 不能证明权限系统；这里只证明调用方给定章节顺序下的机械防剧透。
- 不能证明未来章永远不可访问，只证明 as_of=c01 的这次结果没有泄漏。
