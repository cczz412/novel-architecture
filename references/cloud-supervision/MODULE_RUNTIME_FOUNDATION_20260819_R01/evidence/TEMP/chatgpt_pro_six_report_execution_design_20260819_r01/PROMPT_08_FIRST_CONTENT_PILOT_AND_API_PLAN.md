# ChatGPT Pro 窗口 8：首批内容评测与小 API 实验方案

请使用你当前可用的最高推理强度，完整阅读共用 ZIP。你的任务是把 52 张内容考卷压成第一批本地可执行的小实验，不设计组件、不修改代码，也不实际调用 API。

## 固定目标

设计 `PILOT-R01`，只使用合成材料。真实小说、真实作者项目和 Gold 都是 0。

先审下面 15 张候选卡；若当前代码已覆盖或材料不足，可以替换，但必须解释：

### 零 API 机械／身份控制组

- `CCE-A-M1-03`：多格式、脏包、章数与静默丢失；
- `CCE-A-M1-04`：current／已发布／旧稿身份 owner 探针；
- `CCE-A-M2-03`：否定、条件、时间限定是否被切坏；
- `CCE-A-M4-01`：confirmed／extracted／rejected／planned 是否串账；
- `CCE-A-M4-04`：r1→r2 后旧证据是否冒充 current；
- `CCE-A-M5-04`：分页水位、隐藏项误签、未审冒充完成；
- `CCE-A-M6-02`：截至章防剧透与人读范围；
- `CCE-B-M10-01`：受伤前场景是否装入受伤后人物锚；
- `CCE-B-M11-01`：HARD 零丢失、未来隔离、超预算停止。

### 冻结 provider／语义结构控制组

- `CCE-A-M3-02`：传闻、梦境、谎言是否升成世界事实；
- `CCE-A-M3-04`：零候选、高密度、截断、坏响应是否诚实；
- `CCE-A-M7-03`：“声称烧毁＋后来见到”是否被误报红灯；
- `CCE-B-T14-02`：must_not 是否把“没找到”错判为通过；
- `CCE-B-M8-02`：三个计划方案是否真不同并保住硬约束；
- `CCE-B-M9-01`：rejected／extracted 是否污染梗概主文。

冻结 provider 只测运输、校验、展示和门，不能写成模型能力。

## 小 API 语义探针

只从下面 5 张设计小 API 输入：

- `CCE-A-M3-02`
- `CCE-A-M7-03`
- `CCE-B-T14-02`
- `CCE-B-M8-02`
- `CCE-B-M9-01`

建议每卡 4 个单变量合成实例，共 20 次调用；默认 retry=0。20 次红线为 0 后，才允许挑 5 个实例各重复一次检查稳定性，总上限 25 次。

这只是设计建议，不是预算授权。请使用 `MODEL_SLOT_A`，必要时提供可选 `MODEL_SLOT_B`，不要替 CZ 选具体付费模型、供应商或价格。

## 你必须产出四个请求包

### 1. 第一波材料包设计

为 15 张卡分别给出：

- 3～4 个单变量合成实例；
- 输入对象；
- 要埋入的关键点；
- 允许答案族；
- 必须拒绝什么；
- 机械检查；
- 红线；
- 当前 13 组 seed 哪些可以复用；
- 本地还要生成什么安全合成材料。

### 2. API 模型请求包设计

只为 5 张 API 卡给出 provider 无关的：

- system／task Prompt 候选；
- 完整输入字段；
- 严格返回 JSON 候选形状；
- 正常输出示例；
- 危险输出示例；
- parser 失败与语义失败怎样分开；
- 单次最大输入／输出 token 字段；
- `MODEL_SLOT_A/B` 所需能力，不写具体供应商；
- 温度／随机性建议；
- retry=0 的失败收口；
- raw response 如何只留本地并登记身份。

不要让模型返回作者真值，不要让 evaluator 和被测模型看到标准答案或版本名。

### 3. 评分与停点包

每卡拆 3～5 个核心检查点，使用 0／50／100；附加分单列；红线不参与平均。至少覆盖：

- 状态漂白；
- 未来泄露；
- 伪证据；
- 高影响自动拍板；
- 旧版本冒 current；
- HARD 丢失；
- 未检查／未找到冒充不存在或通过；
- 不完整批次冒充完成。

明确：机械身份不闭合就不进入语义评分；任一红线立即停止对应路线；达到调用上限就停，不自动扩样或换模型。

### 4. 跑后回传包

设计本地跑完后重新交给 Pro 的最小结果包，只收：

- 卡 ID 与 fixture identity；
- 模型／provider／prompt／参数身份；
- 原始回包本地 handle 与 SHA，不强制外发正文；
- 规范化结果；
- parser／schema 结果；
- 核心分、附加分、红线；
- 失败证据和 pairwise diff；
- 调用次数、token、重试和停止原因。

不要要求整仓、运行长账或真实小说正文。

## API 与真实材料边界

- 本 Prompt 只设计，不实际调用 API。
- 具体模型、路由、付费预算和调用授权必须由 CZ 另行明确。
- 真实小说阶段需要独立权利票；不能从本包自动继承。
- 小 API 结果只能叫“合成语义探针”，不能叫模块通过、跨题材泛化或生产可用。
- 一次实验只改变一个变量；不能同时换模型、Prompt 和组件。
