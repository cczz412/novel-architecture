# 第96道 r02｜独立召回与三档冻结候选

这套候选只解决首轮硬停暴露的三件事：

1. 候选召回先完成并冻结，人工判词与答案衍生物之后才进入离线评分。
2. 原子主张、评分答案、渲染期望分开建档、分开算 SHA；各阶段只拿自己的输入。
3. 输入预算不用裸字符数冒充 token，改用 39 份封存成功请求的真实 `usage.prompt_tokens` 标定保守上界。

每个阶段在独立子进程里运行，模型 API 与网络调用均为 0。候选没有接入现役运行器，不会修改样张、正式金标、现役记录或历史成绩。

运行入口：

```bash
.venv/bin/python -m experiments.Z96_anchor_layer_evidence_closure_r02_20260724.pipeline \
  --run-dir runs/Z96_刀B_Aplus锚层与证据闭包_r02_20260724
```

正式状态只有 `PASS` 或 `REJECT`。本候选禁用 `FILL`、`MARK` 和自动补锚；任何硬闸失败都停在新运行目录，不回写首轮封存件。
