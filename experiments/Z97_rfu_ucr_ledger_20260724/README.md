# 第97道｜RFU 建账与 UCR 五层候选

这个候选包只解决一件事：把“人工判语义”和“程序算分”彻底分开。

- `J-REF` 只放参考事实单元（RFU）；
- `J-MATCH` 只放候选主张、冻结判词和裁判资格；
- `SCORE` 只读前两区，程序不得回看小说正文、金标原件或历史成绩来补判词。

五个读数并排报告，互相不能抵消：

- 事实头覆盖率（FCR）
- 必要限定完整率（QCR_full）
- 锚承托完整率（ASR_full）
- 可用事实召回（UCR）
- 输出主张承托率（SOP，候选发布线为 0.98）

第3章 v1.2 的 23 个计分原子只做候选 RFU 试建账。资格、限定和最小证据集仍未完成人工扩标，所以本包不会把演示读数冒充正式质量成绩。retry03 没有完成语义判词，只能建候选主张账；Z89 只复用已封存的 23 条历史判词做离线演示，历史成绩不回写。

本包不接现役运行器，不改金标、122 条正式记录、默认链、分类规则或 outbox。正式换尺仍要走后续 MRP-72 发布门。
