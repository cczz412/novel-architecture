# Z97｜人判语义，程序只算分

说白了就一件事：把「这句话对不对」和「数字是多少」拆开。

- 人只写参考事实、候选主张、判词（对／不对、有没有资格判）；
- 程序只读这些已经写下的东西，算出几项覆盖率／召回率；
- 程序不许回头翻小说正文、金标原件或历史成绩，自己改判词。

这也是 2026-07-24 的候选包，0 API，没接现役运行器。演示读数不能冒充正式质量成绩。

测试在 [tests/test_z97_rfu_ucr_ledger.py](../../tests/test_z97_rfu_ucr_ledger.py)；[tests/test_z98_knife_a_step1.py](../../tests/test_z98_knife_a_step1.py) 和 V02 C12 也会引用这里的程序。
