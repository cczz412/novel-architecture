# R2 开发路线安全硬化候选 r01

这个目录只解决一件事：把“检索与回答运行”和“隐藏答案评分”拆开，避免路线程序给自己发证。

- 运行侧只准出现 `RH-*` 请求头、题面和本次证据窗口。
- 隐藏评分头、金标、锁箱与来源组合只允许评分侧读取。
- 逐字证据是“每组至少命中一项，所有组都满足”，不再把多组证据摊平成一个大集合。
- 工作区会扫所有文件字节，不再只扫 JSON。
- 真正的外部签名信任根尚未接入，所以模型发网与正式终验继续红灯；本候选只允许 0 API 开发横评。
- A5 是 B01 语义错位的单变量候选：在 A4h 上只增加“抽象问法→正文可观察动作词”的通用桥接，不加别名、不扩邻段、不改排序器。
- A6 的检索词与 A5 完全相同：只在装包时让每个问题分头先保一份真实命中，再用余量按 A5 全局顺序补齐。
- A7 是 ChatGPT 外审回包后的单变量候选：只把 A5 的题面词袋规划器换成“通用事实本体＋冻结正文精确跨度”规划器；稀疏索引、排序、装包、七档预算和隔离评分器不变。
- A7 正式读数为负：2,500 字档 B01 必答头 17→25，但完整题仍 0；总体完整题 16→13，B02 9→8、B03 7→5，触发预注册回退砍线。该路线只保留诊断候选，不进 A10、不升默认。
