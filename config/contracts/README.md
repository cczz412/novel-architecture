# 任务输出合同

这个目录主要解决“模型回答到底必须长什么样”的问题。JSON Schema 只负责机器能检查的字段、枚举和结构；语义边界还要看对应的完整合同与系统提示词。

`novel_fact_extraction_v2.schema.json` 是小说事实抽取 v2.1 的四字段结构：事实、八态状态、逐字证据，以及按需填写的信息来源人。两句证据上限、来源格式和言语行为边界属于语义／程序闸规则，不只靠 Schema 表达。`novel_fact_extraction_v2.bundle.json` 把这套口径用到的提示词、背景卡、用户消息模板和离线工具按 SHA-256 绑在一起，防止以后只换了其中一块却仍沿用旧版本名。

这套 v2.1 合同已经批准，但还没有接进现役默认链，也不代表已经获准调用模型或开始训练。14 题旧卷仍按两字段 v1 保存历史成绩，不回头重算；旧 v2 候选和通过票要按 v1.1 程序闸重验，不能自动继承。
