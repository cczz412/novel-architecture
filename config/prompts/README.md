# 提示词清单

这个目录主要解决“提示词改过了，却看不出运行时到底用了哪一版”的问题。

每个提示词目录放两样东西：

- `prompt.md` 是要作为系统消息使用的原文。它按普通 UTF-8 文本读取，不做变量替换。
- `manifest.json` 是提示词清单。它用路径和 SHA256 锁住提示词原文，也锁住这份提示词要求的任务输出 Schema。

提示词清单只绑定提示词文件和任务输出 Schema，不反向引用 API 合同包，也不引用上下文配方。这样几层材料各管一件事，不会互相套成循环。

`wave2_synthetic_json_probe_v1` 是一份离线装配探针：

- 系统提示词没有槽位；
- 输入由上下文配方放进一条用户消息；
- 输出只能有一个 JSON 对象；
- 输出是否合格，要再用任务输出 Schema 做本地校验。

这里的材料仍是候选件，没有接进现役默认链，也不代表已经获准读取密钥、联网或发送模型请求。
