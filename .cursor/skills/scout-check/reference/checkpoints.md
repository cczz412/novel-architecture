# 定点检查表

碰到下表任一点：**先停 → 勾选 → 必要时派 1 个子 agent → 写【定点】行 → 再动。**

项目可在本表末尾追加行，不要另起冲突清单。

## 通用定点

| 点名 | 什么时候算碰到 | 停下来要问什么 |
| --- | --- | --- |
| 换工作区 / 换根目录 | `move_agent_to_root` 或明显跨项目 | 入口 AGENTS/README 读了吗？会不会改错仓？ |
| 复用 vs 发明 | 想新建工具台、预览页、SVG/脚本平行方案 | 平级目录有没有现成工作台/资产？路径列出来了吗？ |
| 改契约 / 词表 / schema | 动枚举、字段、交件规范 | 和已拍板契约冲突吗？是补洞还是另起一套？ |
| 改工作台源码 | 动 prototype / 正式 UI | 能否只 TEMP 或 localStorage 试？会不会弄乱默认演示？ |
| 覆盖资产 | 覆盖 png/svg/正式素材 | 有备份吗？是暂代还是正式入库？ |
| 外部 API 生图/生文大批量 | 调 API 池、批量生成 | Key 走现有脚本吗？输出是否只进 TEMP？ |
| 扩大 scope | 用户没要的功能、多角色、深 2.5D 等 | 还在「本轮最小交付」里吗？该不该先问 CZ？ |
| 跨项目写盘 | 往小说/视频/NVM 等其它根写 | 有没有该项目 AGENTS 授权？该不该只写讨论/TEMP？ |

## 勾选模板（主 agent 用）

```text
【定点】<点名>
- 现象：…
- 检查：…
- 结论：通过 / 挡住
- 下一步：…
```
