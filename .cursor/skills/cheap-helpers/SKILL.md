# 便宜助手

给 **高等级主会话** 用。说白了：你出判断，Grok 跑腿。

主会话是 Fable／Opus／Grok 都行；主 agent 自己从系统提示认模型，CZ 不用申报。子 agent 固定派 Grok 4.6 extra high（`cursor-grok-4.6-xhigh`，禁止加 `-fast`）。取舍、结论、方针必须主会话自己下，不许外包。

旧名「审计员团／aux-crew」作废，只当口令别名。

## 会话闩（CZ 点一次，后面一直开）

CZ 会自己提「便宜助手」。提过之后，**同一条对话后面每一轮都按本 skill 走**，不要等第二遍口令。

| 什么情况 | 行为 |
| --- | --- |
| 点名：「便宜助手／上助手／派人／取证」，或旧口令「上审计员」 | 闩上。这一轮就开始派；后面每轮继续启用 |
| 已经闩上的后续回合 | 不必再喊。有取证／穷举／核对／红队就派，派前带一句「派 N 个便宜助手查 X」 |
| 解开：「别派人／轻量点／直接答／关掉便宜助手」 | 解开。解开前不要自己停 |
| 这条对话还没点过名 | 不派人。不要因为任务看起来重就先派 |

闲聊、纯解释、一眼能看完的单文件，即使已经闩上也不硬派凑数。

## 分工铁律

子 agent（Grok）**只做**这四类——共同点是产出可以被抽查验证：

1. **取证**：读指定文件/目录，回报事实 + `文件:行` 引用
2. **穷举**：列出所有 X（消费者、引用点、配置项、断链）
3. **核对**：逐条验证一份清单（路径存在吗、数字对得上吗、两处说法一致吗）
4. **红队**：对主 agent 的草稿结论找反例、找漏项（产出当线索，不当裁决）

子 agent **禁止做**的——这些留给主会话：

- ❌ 「你觉得 A 方案还是 B 方案好」——判断题不外包
- ❌ 写最终结论、定方针、改正式文件
- ❌ 开放式漫游（「看看这个仓库有什么问题」）——必须给窄范围和输出格式

## 派发规矩

- `model` 每次显式写 **`cursor-grok-4.6-xhigh`**（口语「4.6 extra high」「4.6 xhigh」；不写 = 用了别的模型，违规）
- ❌ 禁止写成 `cursor-grok-4.6-xhigh-fast`（带 fast，CZ 2026-08-13 钉不用）、`cursor-grok-4.5-high`（旧钉，已作废）、漏写 `model`
- 只读探查用 `explore` 类型，多步核对用 `generalPurpose`；能并行就一条消息里一起派
- 子 agent 看不到对话历史：prompt 里写清「你只负责 X」+ 文件路径 + 输出格式 + 行数上限；让它自己去读文件，不要整段粘贴长文档进 prompt
- 每条回报必须带引用（`文件:行` 或原文短摘），无引用的结论视为传闻
- 🔥 **主 agent 必须抽查承重事实**：子 agent 说「X 文件里写了 Y」，凡是这个结论会影响你的判断，就自己开文件看一眼再用
- 预算：每波 ≤4 个，一般 ≤2 波；额度充足但综合质量优先，别派一堆读不过来

角色派发模板见 [references/dispatch-templates.md](references/dispatch-templates.md)。

## 输出骨架（给 CZ 的回报）

```text
【结论】主会话自己的判断，一段说清
【证据】便宜助手回报要点（已抽查的标注 ✓）
【分歧/风险】助手之间或与我判断不一致的地方，怎么裁的
【下一步】要不要出工单给 Codex；要的话工单草稿放哪
```

## 与其它 skill 的边界

- 本 skill 管的是「高等级主会话怎么派 Grok 跑腿」，不是同模型满编团队
- 用户明说「cursor 团队」「自检」「探路」→ 仍走那两个 skill
- 施工（改代码、跑训练、动正式资产）不是本 skill 的活，默认产出「给 Codex 的工单」收尾

## 硬禁令

1. 把判断题（哪个更好、要不要改）整包丢给子 agent = 违规
2. 未抽查就把子 agent 的承重结论写进【结论】= 违规
3. 漏写 `model` 或写错 slug = 违规，重派
4. 拿本 skill 当施工队直接改正式文件 = 违规，改出工单
5. 闲聊/小问题硬派人凑仪式感 = 违规，直接答
6. CZ 已经点名便宜助手，后面几轮假装没听见、不再派该派的跑腿 = 违规
