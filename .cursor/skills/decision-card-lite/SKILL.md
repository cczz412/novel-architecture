# 轻量拍题板

给 CZ **勾选项** 用。说白了：他要一眼看懂在问什么、更推荐哪个、差多少，然后点一下就收干净。

不是 NVM 三十问，也不是桌上那份 v3 六段式。那份太重，会占满屏幕，还容易把具体问题问丢。

## 什么时候用

| 情况 | 做不做 |
| --- | --- |
| 要 CZ 在 A/B（最多 C）里拍板 | 用（自动，不必喊口令） |
| 简单是/否、纯事实、已经拍过只需执行 | 不用 |
| 用户说「直接问」「别走问题清单」 | 不用 |
| 用户明说「按 v3」「三十问」 | 不用本 skill，走重模板 |

## 铁律

1. **默认最多 3 题。** 不够就停，等这三道拍完再开下一轮。不要一次甩 8 题，也不要在 3 题后再偷塞第 4 道追问。
2. **每题必须能一眼看懂这四件事：** 在问什么、选项是什么、更推荐哪个、差在哪（有多大）。
3. **优先 canvas，聊天只留入口。** 对话框里不要贴速览表、不要贴六段、不要占满一屏。
4. **选完把选项清掉。** 已拍只留：一句话问题 + 选了哪条。要改再点「改」。
5. **推荐写在明面上。** 不许让 CZ 自己猜「你更想要哪个」。差距用「强烈 / 略偏 / 差不多」，不要五角星墙。

## 聊天里怎么写

整段回复不超过几行。只做三件事：

- 一句：现在拍什么（范围）
- 一句：打开拍题板（链到 canvas 文件，绝对路径，见下）
- 一句：更推荐哪边、差大不大

❌ 禁止在聊天里再把选项表、场景剧本、详解复制一遍。

Canvas 链接必须用**完整绝对路径**（Cursor canvas 约定），例如：

`[拍题板](/Users/a1234/.cursor/projects/<workspace>/canvases/decision-board.canvas.tsx)`

`<workspace>` 换成当前 workspace 的 canvases 目录名。先看已有 `.canvas.tsx`，没有就新建。同一轮拍题复用同一块板，不要每题一块。

## 每题长什么样

完整填空见 [TEMPLATE.md](TEMPLATE.md)。每题只保留这五块，顺序固定：

1. **一句话问题** — 主语 + 动作 + 安置点，问号结尾。不加「这个问题是关于…」。
2. **差在哪** — 一句说清选 A 和选 B 之后，实际会不一样的那件事。禁止「更好 / 更安全 / 更灵活」。
3. **更推荐** — `强烈推荐 A` / `略偏 A` / `差不多`。后面半句原因。
4. **选项** — 默认 2 个，最多 3 个。每个：短名 + 「选完会怎样」半句。不要为了凑 ABCD 硬编 D。
5. **补一句** — 可空。把「知否换哪本」这类附带口径塞这里，不要另开第 4 题。

## Canvas 做法

先读 Cursor 自带 canvas skill，再按 [board.stub.tsx](board.stub.tsx) 抄到：

`/Users/a1234/.cursor/projects/<workspace>/canvases/decision-board.canvas.tsx`

只改题目数据，不改交互骨架。

| 必须 | 禁止 |
| --- | --- |
| `useCanvasState` 存每题选择 | emoji、渐变、阴影 |
| 一次只摊开**还没拍**的第一题 | 把 3 题选项同时铺开 |
| 已拍区只有问题 + `拍了 A · 短名` + 「改」 | 已拍后还留着整排按钮 |
| 状态钩子写死 3 题，不要循环里 hook | 给 Row / 自定义组件写 `key`（本 SDK 会报错） |
| 只 import `cursor/canvas` | 网络请求、相对 import、npm 包 |

3 题里某题还没到（比如第 1 题选 B 就不需要附带口径）：仍保持 3 题上限，把用不上的选项从该题里删掉，而不是再加一题。

## 和 v3 的关系

| v3 有的 | 轻量版 |
| --- | --- |
| 6 段（落地例子、剧本、速览表、详解、裁决区） | 不要 |
| 先「问题理解」再征求确认才出题 | 不要。直接出可勾的题 |
| 五角星、分类标签、30 问施工产物 | 不要 |
| 功能落地例子 5～10 行 | 需要画面时，塞进「选完会怎样」半句 |

CZ 要重模板时，他自己会说「按 v3」。没说就当轻量。

## 拍完之后

聊天里用三行回报裁决，不再展开选项：

```text
1. …？ → A …
2. …？ → B …
3. …？ → A …（补一句：…）
```

没拍完不要开工。用户改某一题，只重开那一题。
