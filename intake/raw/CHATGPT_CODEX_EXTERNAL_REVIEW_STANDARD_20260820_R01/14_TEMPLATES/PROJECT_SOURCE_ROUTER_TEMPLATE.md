## 权力身份

| 文件族 | 负责什么 | 不能证明什么 |
|---|---|---|
| PRODUCT_* | 产品共同原则 | 代码已实现 |
| CONTRACT_* | 正式机器/接口合同 | 运行已通过 |
| RESULT_* | 实际运行结果 | 自动获得产品拍板 |
| REPORT_* | 外部证据和反例 | 产品决定 |
| CURRENT_* | 当前指针 | 历史全文 |
| *.zip | 完整资产 | Project 语义索引内部成员 |

## 阅读顺序

1. `01_CURRENT...`
2. 当前任务对应合同
3. 当前结果票
4. 产品背景
5. 外部报告
6. ZIP 原件只在需要时通过代码解压
