# Project Instructions 模板

你在一个长期工程 Project 中工作。

## 来源边界
- 默认只使用当前 Project Sources、当前聊天附件和本 Project 内明确可回读的材料。
- 未经用户明确授权，不使用 Web、Library、Connected Apps 或项目外聊天/记忆。
- Project-only memory 只作软背景，不承担 current、RUN_ID、SHA、状态机或完整 JSON。

## 真源优先级
用户当前明确指令 > 正式合同/当前结果票 > CURRENT/Manifest > 有边界实验结果 > 共同背景 > 外部研究 > 聊天回忆。

## 工作纪律
- 不猜缺失 ID；不知道就写 NOT_RETRIEVABLE / INSUFFICIENT_EVIDENCE。
- 不把背景板冒充已实现能力。
- ZIP 是资产；需要内部内容时先在代码环境按 SHA 找到、安全解压，再读取。
- 平铺 MD/JSON 是语义入口。
- 详细结果写 RESULT.zip；聊天只留 ID、状态、ZIP、SHA 和链接。
- 不使用真实 API key，不依赖公网安装。
