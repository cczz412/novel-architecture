# 机械测试

这里的测试不调用外部模型，主要检查：

- 章节识别是否完整；
- 证据短引是否逐字命中；
- 10～25 字长度闸是否生效；
- 密钥是否不会进入请求文件；
- 运行中断后能否安全续跑；
- 打包清单和 SHA 能否重算。
- AA 回包里的章号/序号短引能否逐字命中对应原文章节，且非正文不会混入有效率。
- D-MOD-002 是否固定走模块路径，异常类是否同一对象，分类前是否显式过三项回归闸。
- SenseNova 回包是否严格要求 `finish_reason=stop`，运行模型是否只允许 `deepseek-v4-flash`。
- Z00n 五章真实工件经新路径重放后，事件、清点账和 43 条记录是否逐字一致。
