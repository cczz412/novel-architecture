# 不代写，不等于平台一定合规

身份：已拍加固

## 遇到什么

产品不生成书稿正文，后续 Agent 准备在导出页显示“安全发布／低风险”，把某个平台的规则套到全部平台，或把创作证明包做成“保证过检”的绿灯。

## 对的做法

**已拍：**“不代写”是产品内部红线，不是平台合规保证。规则必须按平台和时间分别核对；没有证据的字段保持未知，不能从晋江外推到起点、番茄或其他平台。发布平台选择器、分平台提示和创作证明包都只是设计候选，不是当前能力或法律意见；证明包不保证平台采信或申诉成功。产品永不做“降 AI 率”“保证过检”。CZ 已明确不做“晋江阉割档”。

**加固：**SI-007 P11 找到“正文由人写”仍可能碰到细纲、核心情节等平台边界，且没有可靠数字能证明本产品输出的误判概率。它支持逐平台提示和未知态；P11 提出的严格晋江模式没有被 R14 接受，不能借报告重开。

## 错的做法

显示“人工正文＝合规”或“检测通过＝可发布”。把 2026-08-13 的规则硬编码成永久事实。用一个平台的结论覆盖其他平台。把证明包写成平台背书。接入 humanizer、降 AI 率或保证过检功能。重建已经拒绝的晋江阉割档。把本卡升级成执行票，或把 P11 建议写成现行法律合同。
