# 私人 Skill 先过治理门，再谈公开

身份：已拍加固

## 遇到什么

作者把一次“写得很顺”的手感固化成 Markdown Skill。后续 Agent 准备立即上架社群市场，或因为内容包“不执行本地代码”就允许它联网、调用工具、写真值和读取全部项目材料。

## 对的做法

**已拍：**自拆 Skill 默认是私人、去标识的候选配方。内容插件保持声明式，禁代码、禁联网，`writes_truth` 恒为 false；用户上传内容仍要按提示注入风险处理。公开前要补正反条件、积累多次独立成功、确认权利并经过沙盒和公开流程。R14 把这些写成设计要求／公开前门，不表示公开市场或全部防线已经实现。

**加固：**SI-007 P03 指出，Markdown 虽不执行代码，仍会进入模型上下文形成“语义供应链”风险，关键词黑名单挡不住提示注入；格式校验和上传者署名也不足以支撑公开市场。这个结论支持先私有、后治理，不冻结 P03 的市场规模、审核阈值或下架流程细节。

## 错的做法

“没有可执行代码”就判定安全。允许插件远程引用内容、联网、调用任意工具或直接写真值。上传后自动公开。只做关键词黑名单，不做能力边界和注入防线。把私人配方的成功一次当成公开质量证明。把本卡升级成执行票，或把 P03 的治理形状写成现行市场合同。
