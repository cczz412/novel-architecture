# 没有合适插件时，可以一个也不用

身份：已拍加固

## 遇到什么

插件路由器拿到作者当前任务后，后续 Agent 准备按 15～25 字触发行做关键词匹配，并且无论如何都返回 Top 1／Top 3，认为“装了插件就必须用一个”。

## 对的做法

**已拍：**给人看的短触发行只做人读文案，机器路由要另看适用条件、不适用条件、前置条件和易混项。没有合适组件时，召回 0 个是合法结果；卡牌制仍要求作者知道本次声明使用了什么。组件超过约 20 个后的隐藏路由资料和混合召回只是扩容触发条件，不是当前已经实现的能力。

**加固：**SI-007 P03 发现短触发行同时承担人读摘要和机器路由，会漏掉否定条件、近邻差异和“一个也不用”。这个审查支持人机分离与零命中，不支持把报告里的候选数量、阈值或评测规模写成合同。

## 错的做法

永远返回至少一个插件。只按组件名或触发行关键词匹配。把相似组件全塞进执行包再让模型自己挑。把“0 命中”算系统错误。把 20、28±4、24～32、Top K 或评测样本量写成已拍。把本卡升级成执行票，或自行冻结机器路由字段。
