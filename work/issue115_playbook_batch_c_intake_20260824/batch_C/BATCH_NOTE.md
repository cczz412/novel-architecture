- 28±4、24～32、20～30、1,200～2,300、40～60 等组件数、评测集规模和阈值；4～19 万内容预算；完整 manifest、依赖、冲突和市场字段；具体下架、投诉和维护者退出流程，均未拍。
- 15～25 字只保留 R14 的“人读文案”身份；没有把它继续写成机器路由阈值。
