# M3 工具 Agent A 阶段 0 API 硬外壳

这份候选只证明：保存、适配、机械检查、工具打包和 C3 预览可以离线重放。它不调用模型，不做 Agent 循环，不做语义修补，也不证明任何模型能抽对小说事实。

## 入口

```bash
uv run --offline --locked python work/ccz57_m3_tool_agent_a_zero_api_20260827_r01/self_check.py
uv run --offline --locked pytest -q work/ccz57_m3_tool_agent_a_zero_api_20260827_r01/test_zero_api_shell.py
```

## 这份包读取什么

- 一份明确提供的 current C2 v1 合成责任段；
- 与它同一版本的 current C1 v1 合成章节；
- OpenRouter Chat Completions 或 Ark Responses 的合成回包字节；
- 一份明确登记的运行、模型、上游、思考档、配置身份和允许工具包；
- 现行 C3 字段口径。

## 这份包输出什么

- 不可变的请求／回包原件和 SHA-256 回执；
- 从已保存请求体反查冻结模型、上游、思考参数、配置和工具载荷的请求绑定回执；回执只保存身份与哈希，不复制 Prompt 或正文；
- 与整个 run 绑定的冻结运行身份；同一 run 的后续 Attempt 若提交不同的冻结身份，会在落新 Attempt 前失败。若保存的安全请求 body 与冻结身份不一致，会在消费该 Attempt 时失败，原始证据仍保留；
- 统一 `ProviderTurn`；
- 分层机械检查报告；
- `baseline-r01.1` 四工具的内部 Schema、两种供应商载荷和确定性 SHA；
- 不落盘、不分配 `f...` 编号的 C3 纯函数预览；
- 离线重放报告。
- Python 审计护栏与源码审计回执；重放期间一旦出现 socket、`fork`、`exec` 或子进程事件就立即失败，运行源码也不能导入网络／模型客户端或动态调用路径。

## 内部排障证据和作者界面分开

- `request.raw`、`response.raw`、运行身份、`ProviderTurn`、机械错误码和各类 SHA 是小说辅助产品内部的受限审计证据，用来复查实际请求了谁、返回了什么、为什么停。它们不是作者每天需要处理的内容。
- `request.raw` 只允许保存可以安全落盘的请求 body。`Authorization`、API key、Cookie 和其他凭证不得进入原件、回执、报告或清单。本包没有真实凭证，也没有真实小说正文。
- 作者以后只应看到与自己行动有关的状态，例如本段完成、部分完成、暂时停止、需要确认候选或需要重新授权；Prompt、原始模型回包、工具哈希、内部错误栈不应直接变成作者任务。
- 用户主动报错时，未来应先生成可预览、可撤回的最小支持包，再由用户决定是否提供。默认不上传正文、原始 Prompt／回复或任何凭证。这项产品与隐私设计不在 A 阶段施工范围内。
- A 只给每次 Attempt 和失败留下可关联、不可覆盖、可重放的底账。耗时、Token、缓存、费用、循环次数、停止原因和恢复链要在后续阶段按各自合同补齐；供应商没有返回的数据不能猜成 0。

## 边界

- 机械门通过只写 `mechanical_pass=true`，绝不写成语义正确。
- 工具参数只读供应商原生 tool-call 字段；正文伪造动作不会执行。
- 旧 `content` 回包也必须先经过同一份 HTTP、冻结身份、完成态和截断门，再进入两层 JSON、Schema 与 evidence 检查。
- 原生工具路线和旧 `content` 路线都必须从已保存的 `request.raw` 反查请求身份，不能只相信响应自报模型或调用方临时传入的预期值。
- 一回合超过一个工具、重复 JSON 键、未知工具、不可见工具、错 revision、截断或模型身份漂移都会失败关闭。
- 请求身份与供应商外壳失败会同时留下两层原因：稳定的父级原因供后续停止记录和作者状态翻译使用，具体诊断码供内部排障使用；不会把几十种工程细码直接推给作者。
- 固定负例会真实重放坏供应商外壳、坏 content JSON、Schema 失败、证据不定位、过期章节版本和截断，不靠手写结论冒充覆盖。
- C3 只允许现行字段：`contract`、`version`、`chapter_revision_ref`、`text`，以及可选的 `quote`、`seg`。
- 因果边需要 M4 分配正式 `f...` 端点后才可能进入现役 writer；A 阶段不创建关系对象。
- A 阶段不做思考档自动路由。后续若因语义错误申请升档，不能在当前 run 里静默改配置，必须另建可追踪运行；具体升档触发和父子运行合同留给 B／D。

小说辅助产品目前还缺少语义诊断、局部修复、版本合并和作者确认能力，所以作者还不能把真实章节交给这份 A 阶段硬外壳后直接拿到可信事实账。这些属于后续 B／C／D，不在 #176 写集内。
