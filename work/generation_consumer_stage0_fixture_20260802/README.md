## 这个虚拟故事到底是什么

✅ 它要有**真实小说的剧情逻辑**，但不用写成小说正文。

你可以直接理解成：我们先做一部小说的“后台数据库”。人物会撒谎、误会、换地点、得到物品、欠下承诺，伏笔也会在后面触发和回收；只是这些内容不用文采描述，而是一条条结构化记录。

它不是新闻纪实，也不是干巴巴地随机造几十条事实。要是人物没有目的、秘密和因果关系，检索器就算全答对，也证明不了它能处理真实小说。
