## 二、低门槛切入机制（任意章可重入）

### 2.1 章节出口快照 exit_snapshot（加在 chapters 表，与 exit_state_refs 并存）
exit_state_refs 存 ID 供机器校验；exit_snapshot 存渲染文本供人读。固定八项，缺项写"无变化"：

| 字段 | 来源 | 示例(第18章出口) |
|---|---|---|
| debt_now | ST-01 当前valid | 欠款520万(含疑似伪造80万已提异议) |
| deadline_left | ST-02 推算 | 距拍卖剩9天 |
| mall_status | ST-03 | 夜市营业中，流水未回第7章峰值 |
| tenancy_roster | ST-04 群组 | 七家长约在手，未回流3家 |
| conflict_axis | storyline/战争标签 | 主线周野vs赵(W1程序拖延)；副线二叔待收口 |
| protagonist_position | 主角目标态 | 用程序异议拖时间，等账本与录音拼真相 |
| open_obligations | OB-*未discharged | 商户长约(14章)、联合经营30天(9章) |
| live_hooks | HK-* open | 800万中X万来源不明(18章发现) |

纪律：快照只引 `is_public=true` 的 WF-* + 当前 states；禁引 FF-*；字段数固定；与 exit_state_refs 做一致性校验（数字须反查 valid ST-* 行）。

### 2.3 三层分层（低门槛不剧透）
- L1 公开主线层(reader_baseline)：欠款/期限/营业/商户去留(states全)、敌我关系、周野在查父亲死(只到"在查")、能力规则。任意章裸用。
- L2 进行中悬念层(PRED-*/HK-*)：当前预测看到啥坏结局(本章内自解释)、外部资金不明(反复提"来路不明"永不给答案)。
- L3 隐藏反转层(FF-*+未reveal的CE链)：父亲不干净担保、赵指使车祸证据、二叔自担刑责。严禁进快照。
- 防剧透是现有隔离的免费副产品：exit_snapshot 取不到 FF-*。

## 三、下沉可信纪律（可写进修改单）

> 所有钱数、证据、合同、流水须可核查、不得为爽点篡改；夸张仅限情绪与围观反应（标 EN-*），不进事实层；角色"见过世面"须用县城方式表达，禁堆术语。

### 3.1 易飘设定压回地面
- 能力：严格只在编号关键物品(欠条/合同/存折)触发，只给一个条件结果不解释因果，读者理解为"开盖验货"。
- 赵万海七日前置局：靠信息差(早知批文/早识审批人)+钱铺路+本地人脉，非全知；须有失手、有赌错。
- 许清禾：专业体现为县城银行难处(拉存款任务、怕不良率、被领导压人情贷)，穿平价衣骑电动车，禁 KPI/边界风险术语。

### 3.2 赵万海褶皱防洗白
不给他"其实心地好"镜头；善意只服务自我叙事("老街早该拆我换新房")；仍下狠手仍赚差价；褶皱只现于酒桌红眼说"我也是老街长大的"。可恨不变，人性褶皱只做"他信自己故事"。

### 3.3 见过世面角色下沉化
- 不说术语："风险敞口"→"这钱收不回你担得起吗"；"尽调"→"我先去他厂里蹲两天"。
- 用县城方式办事：托熟人牵线、去常去澡堂谈事、红白喜事当谈判场。
- 把世面写成吃过亏：周野吹牛赔过钱、清禾被上级拿捏过。
