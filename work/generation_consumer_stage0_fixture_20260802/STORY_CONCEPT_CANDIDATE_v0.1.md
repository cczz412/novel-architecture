## 一句话故事

在大城市混得一败涂地的周野回县城参加父亲葬礼，二叔联合亲戚逼他用三十万元卖掉父亲留下的老商贸城；他从合同上看见签字后的灭门下场，只能在银行拍卖前的三十天内救活这座负债八百万的破市场，并查清父亲之死、伪造债务、家族背叛和县城首富抢地之间的真相。

第一屏同时交代葬礼、亲戚逼迫、家产争夺、特殊能力、全家危机和主角反抗，不铺垫他在大城市的上班与返乡过程。

## 能力｜七日后果

主角碰到会改变命运的东西时，可以看到这个选择七天后的一个结果。

示例：

- 摸到合同：看到签字后的下场；
- 摸到商场钥匙：看到当晚发生火灾；
- 摸到妹妹手机：看到她被人骗走；
- 摸到银行催款单：看到商场三天后被查封；
- 摸到许清禾递来的文件：看到她因帮助自己被开除。

只保留三条故事规则：

1. 每件东西只能看一次；
2. 只能看到结果，看不到过程；
3. 改变选择后，未来也会改变，而且未必变得更好。

第三条负责持续制造剧情：主角阻止商场着火，可能反而逼反派提前绑走妹妹。能力给的是预警，不是自动答案。

## 阶段 0 必须单独钉住的能力边界

🔥 “七日后果”看到的是**当时条件下的一条结果预测**，不是已经发生的世界事实。

后续结构化时至少要分开：

- 真实世界已经发生的事件；
- 周野合法看到的条件预测；
- 其他人物知道、误信或完全不知道的内容；
- 主角改变选择后已经失效的旧预测；
- 真正属于后续章节、任何人都不该提前取得的事实。

如果把预测和真实未来放在同一张表里，评测器就无法区分“能力允许主角知道”与“检索器非法偷看未来”。

“会改变命运的东西”也要由故事 Agent 列成有限清单，并给出触发章和对象编号，不能让编包器临场猜哪些物品算重要。

## 为什么整本书能保持一条主线

所有冲突都围绕老商贸城：

- 二叔逼卖，因为被债务和儿子的赌债控制；
- 银行拍卖，牵出伪造债务；
- 商户闹事，是反派煽动；
- 食品中毒，是为了搞臭商场；
- 妹妹被利用，是为了偷公章和商业计划；
- 许清禾被停职，是因为帮助周野延缓拍卖；
- 父亲死亡，是因为发现土地规划和多年产权、债务问题；
- 赵万海抢夺的最终目标，是低价拿下老街和未来物流枢纽地块。

剧情推进方式固定为：

```text
反派出招
  → 周野反击
  → 家人或盟友关系变化
  → 商场状态变化
  → 父亲真相推进一步
```

## 六个长期角色

### 1. 周野｜主角

曾是房地产销售，擅长看人、谈生意和制造场面，但在大城市创业失败。回乡时，所有人都认为他只是混不下去了。

成长线：失败者 → 家里的主心骨 → 商户认可的老板 → 县城有头有脸的人。

### 2. 王秀兰｜母亲

开头只想卖掉商场、还清欠款、保住儿女。她阻止周野争斗，后来偷偷卖房替他还债，再发现丈夫死亡疑点，最终亲自站出来对抗亲戚，成为商场最稳的人。

她承担家庭情感和选择，不是只负责哭。

### 3. 周小满｜妹妹

县城主播，嫌哥哥没出息，也觉得家里的破市场丢人，却是团队里最懂流量的人。

变化线：看不起哥哥 → 帮忙直播救商场 → 被男友诱骗泄露商业计划 → 兄妹决裂 → 独自找到反派证据 → 重新成为哥哥最重要的搭档。

### 4. 许清禾｜女主

周野的高中同学，现在是银行风险经理。她回来的初始任务不是帮周野，而是查封并拍卖周家商贸城。

变化线：债权人与欠债人 → 怀疑账目造假 → 暗中延期 → 因周野隐瞒能力而翻脸 → 被陷害停职 → 与周野共同翻案。

她每帮周野一次，都要损失一部分事业或名声。

### 5. 周建国｜二叔

开头是最大的家族敌人：逼侄子卖祖产、联合亲戚分家，还可能参与伪造债务。但他不是纯坏种。

后续揭开：儿子欠下赌债；赵万海抓住了他的把柄；他嫉妒哥哥，却不知道对方真的会杀人；他曾想提醒哥哥，又临阵退缩。

变化线：家族敌人 → 反派棋子 → 被全家抛弃 → 交出关键账本 → 为自己的选择付出代价。

### 6. 赵万海｜长期反派

县城最大开发商，平时捐款、修路、资助学生。开头会主动借钱给周野，还表示以后把他当亲侄子。

真实目标是低价拿下整条老街。他不只派人动手，更擅长拆掉周野身边的关系：收买二叔、利用妹妹男友、控制银行内部人员、挖走商户、制造舆论、挑拨母亲，甚至先给周野救命钱，再逼他公开屈服。

## 前十章节奏

### 第 1 章｜葬礼逼签

能力出现。周野拒绝卖商场；摸到商场钥匙后，又看到母亲将在当晚燃气爆炸中死亡。

### 第 2 章｜当场救母

周野赶回商场关掉煤气，在后厨发现人为割开的管道。二叔反咬他自导自演，妹妹直播却拍到可疑人逃跑。

### 第 3 章｜三十天死期

银行通知三十天内还不上八百万就公开拍卖。赵万海愿意替他还钱，条件是商场转到自己名下。周野从支票上看到自己未来跪在赵万海面前，于是当众撕掉支票。

### 第 4～6 章｜第一次翻身

周野发现市场里一家不起眼的卤肉店会突然爆火，借妹妹直播和自己的销售能力办县城老字号夜市。反派制造食品中毒，许清禾准备查封商场，周野必须在直播镜头前证明有人栽赃。

这不是独立案件，而是反派争夺商场的第一招。

### 第 7～10 章｜第一次大兑现

夜市爆火，商场三天流水破纪录。周野交上第一笔欠款，暂时挡住拍卖，准备退租的商户开始回头。

庆功时，他收到父亲生前定时发送的录音：

> “小野，商场不能卖。”
>
> “赵万海等这块地，已经等了十五年。”

到这里完成能力兑现、救母、阻止首轮拍卖、赚到第一笔钱、商户态度反转、许清禾怀疑银行账目、长期反派锁定和父亲死亡主线启动。

## 四场持续升级的战争

### 第一场｜保住商场

三十天拍卖倒计时。周野从交不起水电费，到重新聚拢商户。

### 第二场｜亲戚内斗

父亲股份、母亲隐瞒、妹妹背叛和二叔账本逐步爆开。最难打的不只是外人，也是自己家里的人。

### 第三场｜县城商业战争

赵万海的新商场开业抢走客流。周野用夜市、本地直播、农产品、电商和物流，把老商场转成县城本地生活中心。

### 第四场｜父亲死亡真相

周野发现父亲不是单纯因为一块地被害，而是掌握了赵万海多年侵吞商户产权、伪造债务的证据。经济利益、家族恩怨和死亡悬念合并。

这四场是同一矛盾不断扩大，不是四个互不相干的新故事。

## 读者体验方向

场景使用县城商铺、欠债、亲戚、拆迁、婚姻、父母、直播、饭店和熟人社会；命运可以夸张，但主角每次胜利都要有看得见的结果：

- 银行暂时不封门；
- 欠款数字下降；
- 商户重新回来；
- 母亲不再被亲戚欺负；
- 妹妹重新在人前认哥哥；
- 曾经看不起他的人改变称呼和态度；
- 赵万海第一次公开失态。

节奏目标是：前 100 字让人停下，前 3 章完成一次兑现，人物关系让人继续追，同一场家族和商场战争保证剧情不断线。
