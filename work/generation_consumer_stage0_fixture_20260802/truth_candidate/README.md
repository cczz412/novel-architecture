# 30章干净故事真值候选｜阅读说明

## 故事走向

这份候选把《回县城奔丧，我看见了所有人的下场》压成一部完整的30章后台数据库，不写小说正文。

周野在父亲葬礼上拒绝三十万元低价转让，随后必须在银行拍卖期限内处理八百万元债务、恢复商场经营、维持商户阵营并追查父亲死亡。前9章完成第一轮经营兑现：夜市复业、首笔三十万元还款，以及固定事件——七家商户撤回退租书并签下三十天联合经营承诺。第10～20章把父亲录音、赌债控制、母亲卖房、妹妹泄密、许清禾合规代价和二叔账本并入同一条主线。第21～30章以合作社交易、债务重组、直接行动人证据和公开调查收口。

本部结算结果是：老商贸城免于本轮拍卖；确认债务调整为四百万元、进入二十四个月履约；一百八十万元伪造担保被剔除；高强对父亲死亡和燃气破坏负直接责任；赵万海授权有限暴力但没有要求致死；父亲有签署边界不清担保的有限过失但没有个人获利；许清禾被长期降职并异地调岗。第30章只保留 `HK-EXTERNAL-FUND`：六十万元外部资金来源不明，没有编造幕后答案。

## 四条主要故事线

1. **`SL-MALL`｜保住商贸城**：八百万元债务、三十天拍卖、首笔还款、争议款冻结、联合缴存与二十四个月重组。
2. **`SL-FAMILY`｜周家分化与重组**：母亲从求和到站队；妹妹从轻视、泄密和决裂到独立取证；二叔从赵方棋子到承担责任的证人。
3. **`SL-COMMERCE`｜县城联合经营战**：卤肉店支点、食品栽赃、七家留场、十八家分成、二十六家合作社和本地替代供应。
4. **`SL-FATHER-TRUTH`｜父亲死亡与债务造假**：定时录音、债务编号异常、隐藏账本、壳公司、高强备份、直接责任和掩盖链。

## 六名核心角色变化

- **周野**：失败返乡者 → 临时接管人 → 商户认可的经营负责人 → 接受理事会监督的合作社经理。他最大的变化不是能力升级，而是学会解释风险、让出单人控制并用交易组织别人。
- **王秀兰**：倾向卖场和卖房求平安 → 主动撤回转让立场并交出原始产权资料 → 负责现金复核 → 在真相公开后与周建国结束家庭往来。
- **周小满**：轻视哥哥 → 直播协作 → 被何涛利用造成泄密 → 与哥哥决裂 → 独立取证并以双授权回归。她的主动站出改变了证据持有和兄妹阵营。
- **许清禾**：银行债权执行人 → 怀疑债务异常 → 坚持合法保全 → 被移出案件并停岗 → 长期降职并异地调岗。她保留银行职业，但失去县城风险经理原岗位和原有上升通道。
- **周建国**：家族敌人和赵方棋子 → 赌债控制暴露 → 失去代理权并交账本 → 正式作证并接受调查。他的证词印证赵万海授权有限暴力，但没有听到致死命令。
- **赵万海**：以开发整合自居的强势控制者 → 第9章商户分化局部失败 → 转向供应、银行和舆论反扑 → 第28章争地与债务主局失败。他允许高强使用伤害性手段逼迫交出账本，但没有下达致死命令。

## 四场战争的不同赢法

| 战争 | 主要赢法 | 结构化结果 |
|---|---|---|
| 保商场 | 拖延＋程序 | 拍卖从进行中变为有限暂缓，再变为本轮撤回；债务余额和营业状态连续更新。 |
| 亲戚内斗 | 分化＋证据转移 | 母亲和妹妹主动站队；周建国失去代理权、交出账本并承担调查。 |
| 县城商战 | 交易＋组织 | 7家承诺、18家分成、26家合作社；周野让利并接受双签与理事会监督。 |
| 父亲真相 | 承受＋公开 | 高强直接责任明确，掩盖链公开；王秀兰与周建国永久结束家庭往来。 |

## “七日后果”能力链

共 6 次预测，均使用独立 `PRED-` 记录，不复制成世界事实：

- 合同：拒绝签字，旧结果失效；代价是必须独自面对债务和拍卖。
- 主钥匙：阻止燃气爆炸；新后果是发现人为破坏并进入长期证据链。
- 赵方支票：拒绝收购；新后果是现金危机迫使周野靠夜市和商户交易求生。
- 食品封签：不销毁样品；新后果是公开对抗扩大，但也保住复检和复业条件。
- 周小满手机：周野避免公开夺机，预测仍部分实现；方案泄密与兄妹决裂通过另一条路径发生。
- 许清禾回执：拒绝非法交付；开除预测失效，但她仍因合规保全付出长期降职和异地调岗的代价。

长链不只依赖能力。`CHAIN-MALL-RESCUE` 从第1章跨到第9章；`CHAIN-SISTER` 从第15章跨到第25章；`CHAIN-FATHER` 从第10章跨到第28章；`CHAIN-XU` 从第17章跨到第29章。商业战争另有不靠能力的 `CHAIN-COMMERCE`。

## CZ 已拍的三个测试真值

三个原待拍问题已经按推荐项写入 R02：

- 赵万海授权有限暴力，但没有要求致死；
- 父亲存在有限过失，但没有个人获利；
- 许清禾被长期降职并异地调岗，职业代价持续存在。

`open_decisions` 已清空，章节里的 `decision_refs` 已移除。三项结论进入世界事实、人物认知和终局状态，但没有被伪装成新的系列 Hook。
