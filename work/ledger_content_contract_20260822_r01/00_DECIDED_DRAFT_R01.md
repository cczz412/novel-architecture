## 四、户口三分怎么落进七本（ADD-038 已拍）

安排住规划账，定义住实体／设定账，变化住事实账——一条只存一处，别处用稳定 ID 指。落到七本：

- 六本设定账每条＝「定义卡＋当前读取面」：定义（这个人是谁）作者可直接编辑；「现在怎样」是影子＋锚，必须指回事实账 f-ID 或作者签字，不是第二事实库；
- 位置、持有、伤势这类可现算的状态不强制落条目；已确认的知情／误导才是硬记录（ADD-038／042）；
- 地点／势力／物品同构：一种登记、带类型（ADD-039），三本字段表长得像；
- 检查器、时间线、执行包全是投影，不为它们另开「当前状态」真值表。

### 5.1 人物账（P0，建议第一本施工）

一句话用途：按故事时间回答「第 N 章时这个人受没受伤、穿什么、和谁什么关系」，答案全部来自已确认事实，没记录就明说（AE-M10-N01 原文）。

谁写：作者（人物卡直接编辑＝签字）＋M4／M5 确认事实后的投影更新；谁读：M7、M9、M10、M11。

人物卡（定义）：

| 字段 | 类型 | 人话 |
| --- | --- | --- |
| id | str | CH- 号；所有引用只认 ID，改名一键全换（K7 已拍） |
| canonical_name | str | 正名；人称、名字都是渲染层的事 |
| aliases | list[obj] | 别名（名、故事内有效区间、证据锚） |
| role_tag | str 或 null | 主角／男配一二三……是变量不硬编码 |
| profile | str | 作者可编辑的背景卡；能帮识别，不能替书稿补证据 |
| visibility | enum | AUTHOR／READER_RELEASED；作者锁定真相走 N17 |
| destiny_ref | str 或 null | 指规划账「人物命运」条目（户口已拍：长线真值住规划账） |

状态时间线（变化读取面）：

| 字段 | 类型 | 人话 |
| --- | --- | --- |
| ch_ref | str | 属于哪个 CH- |
| state_key | str | 多值状态键：injury:left_arm、outfit、location、alive……断左臂与中毒不互顶（ADD-032 第 6 条已拍样式） |
| value | str | 该键的值 |
| story_time | obj | 起锚必填，止锚开着＝当前值；锚坐标已拍：章 revision ref 三元组＋可选故事序（C11 回验机制复用，插章改版锚不漂） |
| evidence_refs | list | f-ID 或 AUTHOR_ATTESTATION；空不许入账 |

查询语义三条硬规矩：as-of 第 N 章查该键当时的值；没记录明说，不编（AE-M10-N01／N02）；不拿最新状态冒充历史时点。死亡复活保留两个时间点、作者单独签字（M5-C04）。

关系：先用轻量关系条目（CH×CH、kind、story_time 区间、证据）；重要、不对称、要独立历史的才升独立对象（R14 已拍）。知情边（知道／怀疑／误信／不知）字段级留 T3——v1 合同只留位不定字段，不抢跑。

### 5.7 长线账 ✅ 户口已拍：长线真值住规划账，长线账＝读取面

R14 户籍：存卷纲、故事线、人物命运、伏笔、灵感与预计时机，主要使用方 M8。但工程现状是：故事线／伏笔真值住规划账（字段表已冻结），长线读取面已实现为只读投影，灵感（M8-N04／N06）和人物命运还没家，卷对象字段规划账合同明说空缺不猜。

→ 户口已拍（2026-08-22，选 A：长线真值全住规划账，长线账在户籍上标为按长线视角取数的读取面）。要新定字段的只有三样：卷对象、人物命运条目、灵感条目（灵感带 placements[] 多实例：一个灵感安放三处，ADD-030 第 5 条）。

**预计时机（expected_at）三种锚形态（CZ 2026-08-22 对话输入，已随题 1 一并拍板）**：长线条目落点不定死章节，靠映射慢慢对齐——

1. 章槽锚：挂在计划章槽（S- 号）附近；写快写慢改槽位映射，条目不动窝；
2. 故事时间锚：挂在故事内时间（「故事内一年后」「九月初十大典」）；到没到点靠已确认事实的故事时间对照判断——规划账现有字段表没有这个锚，要新加；
3. 模糊锚：只说「本卷内」「三卷内」；对账时只提醒、不报警。

配套语义：条目永远住账不动窝，写章取料带走的是引用；写完由对账边标「兑现／未兑现／改挂新落点」；「先加两章铺垫再挂后面」＝插新槽＋改挂，必要时登记承接。

## 七、取件码扩到十本（候选条款）

现状 AE-M11-N01 只保事实／规划／章节三账。扩展形状照 C11 revision ref 同族：{ledger_name, entry_id, rev, sha}——拿有效码取回该条目该版本，过期或无权被拒并说明原因。已拍（2026-08-22）：条目改判（confirmed→retired）后，旧码仍取旧版，回执标「此条已改判／退役」——历史可回是全仓一贯纪律，标明身份就不误导。

## 八、简装／精装与题材包接缝

- 合同定的是条目形状，不定文件布局：简装＝轻文件也每条带全信封；升格（条数／引用过阈值→正式结构）只换存法不换形状，模块取法完全不变（AE-AW-N03）；
- 题材包条目：source_identity=pack_prefilled＋pack_ref＋confirm_status=candidate；作者可改可删，不选包一切照常（AE-AW-N04）；
- 设定路由（AE-AW-N02）：新设定进哪本账由路由建议＋作者改判；十本都装不下时提议开新账——改户籍名单是产品票，不是运行时行为。
