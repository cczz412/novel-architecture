# 修订十一：新逻辑句四件套立柱（依 D-LOGIC-001，共识核①）
- **四账分立不合并**：A 跨章因果链／B 故事内触发器／C 读者承诺·未兑现事项／D 世界规则条件逻辑。不合并理由（四窗口盲拆独立撞车）：B 触发前尚未发生，是待机监听器；C 读者视角是独立状态轴（事件发生完读者账可能仍未还）；D 是可复用规律，B 通常盯一次性条件；A 与 C 不混——隐藏因果读者不知道，不能自动算成读者承诺。
- **单一事实源**：同一原始事实只存一处，其余账本用 ID 引用；B 触发后只在 A 记发生结果（A 写 ←B-ID）；C 的兑现事件写在 A，C 只改状态并链接 A；具体应用只在 A/B 引用 D，不重抄规则。交叉节点不重抄事实，只存组合变化＋引用各拥有节点。
- **与既拍件对接（对齐关结果）**：B＝D-HOOK-002「hook 作者工具」的结构落地（故事内事件/时间/条件锚，不锚章节号；待/已触发/取消三态；触发未处理＝挂账态不得静默遗忘）；C＝修订一三态债的读者视角账，入账门槛沿用（跨章存在＋不回应读者会明显失望才进长期债）；D＝06:07 必答题定论「规则语义单列」的账本落地。
# 修订十二：A 类跨章因果链基线（收编 X01 七字段）
- **七字段基线**：`A-ID｜故事线｜Δ状态变化｜←直接因｜→后续用途｜态｜证据锚`。
- 字段分寸（带负面清单）：Δ＝「前态被哪件事改成后态」，一条只放一个可消费变化，不做场景复述；←直接因＝真正使 Δ 发生的近因（可挂多个父节点），不是「前一章发生了什么」的时间邻接；→后续用途＝以后哪条线会读取此状态或它限制哪些选择，不写泛泛「推动剧情」；证据锚＝章号＋10～25 字原文短引，无锚记录无效。章号不另设字段（证据锚已含）；人物/地点/时间不单列，只在改变因果时写进 Δ／因／用途。
- **主图与防漏账分离**：因果主图走事件级合并（薄）；逐章覆盖反查表只作防漏账，与主图分离（X01 实证＋方法复盘弯路撞车：逐章扫描只配当防漏账）。
- **态字段**：基线 开／收，收编 X04 **态「废」**（被后文证伪＝标记作废不删条，与账序只增不改／改判开新条同构）；「存疑」（单方陈述）作判定值候选。
- **未决口（不冻）**：薄账（事件级约 80 条）vs 逐章底账取舍，待弱模型流水线实测——「先密候选→核锚→再压薄」路线下逐章底账可能是中间工件而非交付物。
# 修订十三：伸缩／折叠／转线机制（共识核②③④⑤＋择优件）
- **双距离刻度，线内为主**：折叠程度由故事线内步距（沿有向因果路径的 Δ 步数）决定；全书章距只作导航／观察截面／显示顺序，不决定丢不丢细节；交叉口取相关各线中最小线内距离，防沉睡支线被主线进度误折叠。
- **折叠＝视图层操作**：只改显示不删底账，原子记录保留可展开（与 T7 底账/视图分离、D-T8-001 视图回提补丁协议同构）。收编 X03 **AF 聚合折叠**（多章真聚合：宏节点＋「覆盖:A起—A止」，非逐章加标签）＋**\[推链\]标注**（接线本身是分析者选择，须单独标注）。
- **折叠安全四条（保核清单，共识核④）**：①段内节点全「收」，未收部分另挂成 C 类；②宏节点保留最早根因／最大转折／最终结果；③跨故事线出口全保留，不得藏「后来被另一条线读取」的端口；④证据包至少保留起／转／落三锚，展开可回原节点。判定标准＝「删掉后后续因果断不断线」，不是「重不重要」。
- **极限压缩预算跟开放因果口走，不跟章数线性**：压缩视图只留四种节点（仍「开」的节点／高扇出节点／故事线交叉口／已收束宏节点）；四窗口实测均落两三千字量级（2465／约2759／骨架1447／2156）；照 X03 诚实声明入稿：千章必压到固定字数不能无条件保证，看未收束大转折与未兑事项数。
- **转线续写包模板（收编 X02）**：因何而来／当前情景／可续动作／必验问题／对主线用途 五栏——直接服务 14:26 转线题判据（转线不重读前文）。
- **续写约束列（收编 X04）**：故事线索引带「当前续写约束」列（如「不能写成默认情侣」「不能把可疑写成事实」），直接服务防续写幻觉。
- **档位不冻**：LΔ 显示档位候选＝0-1／2-5／6-20／21-50／50+（X02×X04 独立撞车），X01 变体 0-2／3-6／7-15／16+ 留档对照；最终分档点由多本梯度数据长出（14:26 口径），本稿不预冻。
