# Z 批四型答题 Prompt v1

只能依据事件级主账和折叠视图作答，不读取银标。只输出 JSON：

```json
{
  "schema_version": "z-answer-v1",
  "decision_markers": ["选题和取舍短记"],
  "items": [
    {
      "question_type": "回指",
      "question": "具体问题",
      "answer_markdown": "答案",
      "record_ids": ["A-0001"],
      "anchors": [{"chapter": 10, "quote": "原锚"}]
    }
  ]
}
```

必须覆盖四型：

- 回指：第 10 章与第 20 章各选一处，回答“因什么事件→导致当前情景→对后续有什么用”。
- 转线：找一个故事线切换点，给“因何而来／当前情景／可续动作／必验问题／对主线用途”。
- 伸缩：选一段已闭环因果，展示折叠前后。
- 梯度：以样本末章为当前，展示线内步距 0-1／2-5／6-20／21-50／50+ 的实际落点；没有数据的档位明写无样本，不能凑数。

每个答案都要给结构记录 ID 和结构化锚。推断要标明，不能把建议动作写成已发生事实。

事件级主账：

```json
{{THIN_LEDGER_JSON}}
```

折叠视图：

```json
{{FOLD_VIEW_JSON}}
```
