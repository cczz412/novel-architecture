## 本轮想改变的判断

判断小说辅助产品的抽取能力，应该继续采用“一次调用直接交付”，还是拆成“生成候选—机械检查—证据核对—定向补抽—候选修复—停止”的 Agent 管线；同时判断哪些环节应由程序、同一模型、独立模型或人工承担。

## 如果不调查，会卡住什么

当前抽取模块读取一段小说材料，能够一次输出事实候选和证据片段，但还没有证据说明一次输出失败后应该怎样补漏、回查和修复。小说辅助产品还缺少一套可测量的迭代生成与纠错候选管线，因此作者把章节材料交给产品后，仍无法知道模型漏了什么、哪些错误可以自动修、什么时候必须停下来请人判断。
