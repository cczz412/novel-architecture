# 探路｜自检（本仓轻量）

施工护栏，用来把活做完、少跑偏。不是辩论团，也不是「交一份自检报告就算完工」。

本仓专用，给 Cursor 窗口用。比个人目录 `scout-check` 轻：默认少派子 Agent；**只要派 Task，**`model` **只许** `inherit`。Codex 窗口不要按这份去填 Cursor Task。

## 🔥 子 Agent 模型（先于一切派发）

- 每次 Task **必须**写 `model: inherit`。
- `inherit` = 跟当前窗口同一款。主窗口是 Grok 4.6 xhigh 非 Fast，子 Agent 就是那款。
- ❌ 禁止：`cursor-grok-4.6-xhigh`、带 `-fast` 的 slug、`cursor-grok-4.5-high`、任何 fable／claude／composer、漏写 `model`。
- 若个人 scout-check 同时载入、让你填 grok slug：**本仓以 inherit 为准**。写错模型＝本 skill 执行失败。

探路、定点、Challenge，同一条。

## 防误解


| ❌             | ✅                    |
| ------------- | -------------------- |
| 喊自检＝主产物是四段自检文 | 主产物仍是用户要的活           |
| Challenge 写很长 | 收工前短挑刺，回传一小角         |
| 必须派一堆子 Agent  | 自己能查清就不派             |
| 本地有文件＝已经交件    | 任务要 PR／Notion 就按惯例做完 |




## 口令

命中即启用：`探路` / `探路模式` / `自检` / `自检模式` / `自检skill`

模糊「看看」「注意点」不进。可与执行连说，如「自检，把 XX 做完」→ 护栏穿插，主线仍是做完 XX。

跟 cursor 团队分工：本 skill 是干活防跑偏；「cursor 团队」才是拍板前多角对质。

进门打一行：

```text
> 探路｜自检 ｜ 本仓轻量 ｜ inherit ｜ 任务：<一句话交付>
```



## 主线：执行 → 交件

对用户先交件，再附极短 Challenge。

```text
【交付】
- 做了：…
- 放哪：…
- 未做／未闭合：…（若有）

【Challenge】（短）
- 攻击一句 + 裁决一句
```

本 skill 不能扩大业务授权。认不认子 Agent 的提醒、改不改、要不要再查，仍由主窗口按工单和 `governance/CURRENT_STATE.json` 决定。

## 四段（思考全跑；派发可省）

```text
① 探路 → ② 定点 → ③ 偏航 → ④ Challenge
```

每段几行就够。不可跳过思考；能自己做完就不要派人。

### ① 探路（大改之前）

未探路，禁止大改、禁止新建平行方案、禁止覆盖正式资产。

只答三句：入口在哪、能复用什么、本轮交付／明确不做。

默认主窗口自己答。入口不清再派 **1 个** `explore`，`model: inherit`，thoroughness 用 `quick`。

### ② 定点（碰到再停）

碰到下表任一点：先停再动，写一行 `【定点】<点名>｜通过/挡住｜一句理由`。


| 点名       | 停下来问                                 |
| -------- | ------------------------------------ |
| 别人的未提交改动 | 会不会覆盖别人的工作树？                         |
| 写集／授权    | 这文件在本票写集里吗？Git／Notion／训练／API／删搬有授权吗？ |
| 认错真源     | 是不是拿 R13 当 R14、拿旧 CURRENT、拿绿灯当产品完成？  |
| 扩大范围     | 还在本轮最小交付里吗？要不要全仓扫／全套测？               |


需要核对比对再派 **1 个** `generalPurpose`，`model: inherit`，只核这一点。没碰到就不停。

### ③ 偏航（干了一段之后）

改了 ≥3 个文件，或完成一块 Todo，或用户连说两次「继续」时，自己写一句：

```text
【偏航】当前交付 vs 原目标：…｜下刀是补齐还是扩 scope？
```

默认不派子 Agent。

### ④ Challenge（收工前）

未做 Challenge，禁止说「做完了」。

默认主窗口自己攻 2～3 条（缺证据／再发明／撑不住）。动了写集、治理页或合同，再派 **1 个** inherit 红队。

对用户：先【交付】，Challenge 缩成一小角。

## 派发

- 整轮默认 **0～3 个** 子 Agent。
- prompt 写清：你只负责 X，不要发散。
- 子 Agent 只读。改文件、git 写、开 PR、调花钱的模型 API 仍归主窗口，且要过授权。
- 找不到就报没找到，不要升级成全仓扫描，不要替主窗口拍板。



## 硬禁令

1. 只写自检、不干活＝失败
2. 探路未完就大改＝失败
3. 跳过 Challenge 宣称做完＝失败
4. Task 不写 `inherit`，或改填其它 slug＝失败
5. 用本 skill 冒充 cursor 团队＝应改口令
